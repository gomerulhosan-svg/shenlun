# 广东申论备考方向（最终版 v7：9 套省考 + 2 套选调，经真人得分卷核验）

> 做法：先按 2023 → 2024 → 2025 → 2026 顺序做 9 套省考，再做 2024、2025 两套选调。每套**先完整作答、再对参考答案和高分卷**，每做完一套修订一次方向（v1 → v6）。最后拿仓库里前人整理的 **55 份真人得分卷分析**逐条核验，把站不住的结论改掉，得到 v7。
> 各年作答和逐题复盘见 `2023/` `2024/` `2025/` `2026/` `选调/`；核验过程见 `选调/方向核验_真人卷.md`。
> 参考答案按你的要求当作标准，用作**要点来源**；但真人卷显示"逐字对上参考答案"只相当于 80—83.5 分的水平，所以它不是满分的形态（见第四节第 6 条）。

## 一、先说结论（给没时间看全文的你）

1. **广东申论不是写作文，是"找要点 → 归类 → 压缩"的信息处理。** 参考答案和高分卷里，自己编的字基本只有小标题，其余几乎都是材料原话压缩。
2. **题型已经固定**：2024—2026 年 6 套省考一/二卷，加上 2025 选调，都是 **概括(20) + 问题对策(30) + 议论文(50)**；2024 选调只是把第二题换成"只要对策"。
3. **小题拉分的地方不在"找没找到点"，而在三件事**：条数不能压缩；对策要写到工具（专项资金、先抢救后申请、无人机、一网通办这一级）；问题要写出表现（"缺运营管理和复合型人才"，而不是"缺乏人才"）。
4. **大作文最要紧的是"题干落点处处可见"**：开头、每一句观点句、结尾都要点到题目关键词。分两大段、三段还是四段，真人卷里都到过 87—90 分，段数本身不决定分数。
5. **你真正要练的是限时和手写。** 我做题没有时间压力，能随时回看材料；我的命中率不代表你在考场上的表现。省考申论 **150 分钟**，选调 **120 分钟**。

## 四、最终备考方向（v7，按优先级）

### 1. 问题＋对策题（30 分，近 3 年 7 套都考）

**问题侧**
1. **按"问题"拆，不按"说话人"拆**：一个人讲两件事算两条，三个人讲同一件事算一条。
2. **条数可以更细，不能更粗**：一级条数 ≥ 材料里互不重复的问题数。（真人卷：八问九策 90；六问六策 82—89；四问四策加泛话 80—84.5；只写三条 81.5。）
3. **每条写出表现词**：写"缺运营管理和复合型技术人才"，不写"缺乏人才"；写"补贴远远不够"，不写"资金匮乏"。（2026 一卷：四个字一条的 80、81.5；带表现的 84.5。）
4. **回材料确认它是不是"现状"**：已经整治好的、材料明说"并非孤岛"的，不能写成问题。（2026 县镇 81 分卷把已严打的"故意破坏古树"当成现状。）
5. 分清三种句子：问题句（写）、背景/道理句（不单列）、建议句（放到对策，别倒推成问题）。

**对策侧**
6. **一一对应问题，写到工具级**：专项资金、先抢救再申请、一网通办、无人机巡查、数字档案、校企联合培养、强校帮扶弱校……不要只写"加强、完善、推动"。（2026 县镇 87—90 分卷的对策全是这一级。）
7. **工具的来源顺序**：本题材料里别人提的建议 → 同卷其他材料里现成的做法（2025 选调可以借材料 2 的"标准海"、产业园选址，材料 5 的智能化养殖平台）→ 从问题反推。**自己补的每类最多一条**，不张冠李戴（把 A 园区的做法写到 B 园区头上会扣分）。
8. **格式外壳跟题干走**：题干是"汇报"、材料按镇走的，就按镇写问题和建议。（2024 二卷唯一的 88 分卷就是这样写的。）
9. *（待验证）* 纠偏类对策后面补一句正面的"立"（"破论资排辈"之后加"按岗位职责、业绩、贡献分配"）。

### 2. 概括题（20 分）

1. **分条来源优先级**：题干给的分类词（"下乡/返乡/兴乡"）＞ 材料自带的小标题或框架 ＞ 材料段落（一段 ≈ 一条）。
2. **同段并列动作逐个圈出**：一段里有几个动词就圈几个；字数不够时先砍数字和例子，再把专有名压成 2～5 字泛称（"联合基金会""联合高校"），**不整项删掉动作**。（2024 选调三份作答都丢了同段的"高素质农民培育"。）
3. **优先搬**：排比句、重复强调的句子、原文小标题（"视人才为珍宝"）、段首段尾总结句。
4. **审清问的是什么**：做法 / 表现 / 作用 / 问题 / 原因。材料里的目的句可以用作小标题；要不要把效果当尾巴写进去，证据有矛盾，字数宽裕时可以带 4～6 字。
5. **别写残、写空、合得太狠**。真人卷里第一题基本不拉分，只有这三种情况会丢分；多写一两条有依据的不吃亏。

### 3. 大作文（50 分）

**第一步：找落点、定方向（3 分钟）**

| 话题类型 | 例子 | 分论点写什么 |
|---|---|---|
| 双对象关系型 | "关系广东**长远发展**和**民生福祉**的重要工程" | 两个落点都要显性出现。可以两大段各写一个落点（段内再用材料框架分层），也可以写四段，但**每句观点句都点明它属于哪个落点** |
| 单一关系型 | "绿色发展是高质量发展的**底色**""关键在""头号工程" | 写"X 对 Y 起什么作用"。拆法看材料在讲哪一边：材料给的是 X 的做法，就按 X 的几个方面拆；材料在讲 Y 的需要，就按 Y 拆 |
| 任务型 | "做好创新大文章""海洋强省建设""时代新人" | 写"怎么做"。材料里有官方框架（讲话原文的"有理想、敢担当、能吃苦、肯奋斗"，省委全会的并列成分）就优先用 |

**第二步：材料—分论点映射（5 分钟）**
- 每则材料写一句"它讲哪一块"。**每块材料至少露一次脸**。材料块超过 5 个时，两两合并成 3～5 段。（2023 县级 78.5 分卷一材料一段，写不完，材料 8、9 没用上。）
- **分论点的主语必须和题目主体一致**。讲另一个主体的材料（比如"党和社会怎么支持青年"）放进开头、结尾或段内一句，不单独成段。

**第三步：套骨架写**
- **开头**（约 120 字）：引语 → 背景 / 数据 → 短板（靶子）→ 总论点（预告几个方面）。
- **分论点段**（3～4 段，每段约 200 字）：观点句（段首，含落点）→ 一句道理 → 材料例子 2～3 个 → 一句小结。**例子多了不加分**（真人卷里例子最多的一份只有 83 分）。
- **结尾**（约 80 字）：回扣落点，加一两句展望。
- **材料外的例子只用来补一句"联系实际"，不能替代材料。**（用材料外例子替代材料的卷子是 81.5、82 分。）
- **字数按答题纸的格子控制，不靠估算**。超长会扣分：真人卷有一份两大段写得很满的只拿 82.5，另一份写到 1100 多字只拿 80。
- 标题可以落在上层目标（2025 省市最高的两份，标题都落在"高质量发展"上），但近目标要在开头和至少一句观点句里出现。

### 4. 公文题（乡镇卷、行政执法卷）

- **发言提纲**：标题 + 开头一句 + 分条（按主体或按做法）+ 结尾一句。
- **汇报 / 调研报告**：标题 + 称呼 + 问题 + 建议；材料按镇、按村走的，按镇、按村写。
- **公开信 / 倡议书**：标题 + 称呼 + 开头（缘由）+ 分条 + 结尾号召 + **落款单位 + 日期**。
- **工作简报**：（报头）+ 标题 + 导语 + 分条成效 + 结尾。
- 格式多写不扣分的说法**没有真人卷证据**，按上面写全即可。

### 5. 限时

**省考：150 分钟**（据两次网络搜索，2026 年省考公告写的是 12 月 7 日 16:15—18:45；官网被本环境的网络代理挡了，没能直接打开原文核对）

| 环节 | 时间 |
|---|---|
| 读材料 + 标注（主体 / 做法 / 问题 / 建议 / 金句） | 35～40 分钟 |
| 第一题 概括 | 15 分钟 |
| 第二题 问题对策 | 25 分钟 |
| 第三题 找落点 + 映射 + 提纲 | 10 分钟 |
| 第三题 成文 | 55～60 分钟 |
| 检查 | 5 分钟 |

**选调：120 分钟**（2024 选调题本注明：阅读材料参考 30 分钟，作答参考 90 分钟）

| 环节 | 时间 |
|---|---|
| 读材料 | 30 分钟 |
| 第一题 | 12 分钟 |
| 第二题 | 18 分钟 |
| 作文提纲 | 8 分钟 |
| 作文成文 | 48～50 分钟 |
| 检查 | 2～4 分钟 |

两张表都**没有经过限时验证**，第 5、6 周模考时按你的实际速度调整。选调的作文时间更紧，手写要能到每分钟约 20 字。

### 6. 自己对答案的方法

1. **先双向核版本**：做题前，拿题干专有词回材料找；对答案前，拿参考答案的专有词回材料找。**找不到出处的那一点不计分**。（2024 选调题目 PDF 的材料是拼错的，要用答案 PDF 后附的材料；2025 选调第二题的参考答案是按另一版材料写的。）
2. **先定判分口径再数**：参考答案里两条说同一件事的合并成一点；同样的写法给同样的判定。
3. **用"要点命中表"**：

| 参考要点 | 写了吗（✓ / 半 / ✗） | 没写是因为（没找到 / 找到没写 / 归类错 / 颗粒度粗 / 审题偏） |
|---|---|---|

4. **参考答案按"80—85 分档"看**：它告诉你要点在哪里，但不是满分形态。真人卷里有两份第二题和机构答案逐字相同，分别拿了 80 和 83.5。
5. **改规则的门槛**：两分以内的差别按阅卷浮动处理；**三套不同卷子出现同样的现象才改方法**。只在一套卷子、一两个要点上出现的，记下来，先不改。

## 七、诚实说明

- 我做题没有时间压力，还能随时回看材料。
- 选调的 A、B、C 三份作答出自同一个作者（Claude），不是三份独立卷，所以"按方向做"和"对照组"的差别只能当弱证据。实际上两套选调里，按方向做的 A、B 比对照组 C 只多 1～2 个要点，处在判分噪声的量级。
- 真人卷分析是前人整理的，我抽查了其中几条关键的（87 分四段式、2023 县级 78.5 分写不完、2024 二卷 88 分按镇写、第二题照搬机构答案拿 80 和 83.5），都和合集原文一致；其余没有逐条复核。
