## 一、这是什么，怎么用

### 1.1 这是什么

押题缓存的第 0 步：先按主线把原料备齐，一条线一个包，只摘原句、少下结论。后面建本质动作图谱、出"壳"训练题、备作文，都从这里取料。

| 文件 | 主线 | v2 登记概率（转述各包 0.3 节） | 行数 |
|---|---|---|---|
| 母料_A.md | 以全面深化改革开放推动高质量发展（大湾区作牵引） | 22% | 882 |
| 母料_B.md | 科技创新和产业创新深度融合，建设现代化产业体系（含实体经济、教育科技人才） | 22% | 789 |
| 母料_E.md | 推动城市高质量发展，建设现代化人民城市 | 10% | 871 |
| 母料_F.md | 推动海洋经济高质量发展 | 10% | 722 |
| 母料_D.md | 完善基本公共服务制度体系，扎实推进共同富裕 | 8% | 910 |

五条合计 72%。C（百千万、县域，偏县镇卷）和"其他"（绿色、文化、安全等）本轮没有建包【实证：目录里只有这五份】。登记概率是主观概率，只为考后对账【假说】。

每个包的结构相同：

| 节 | 内容 |
|---|---|
| 零 | 这条线是什么：一句话定义、边界（哪些事归相邻线）、登记概率、最硬的理由和反证 |
| 一 | 作文题眼候选，按可能性排序，写了来源类型和为什么像题眼 |
| 二 | 材料一候选：总书记原话，每段不超过 300 字 |
| 三 | 广东实际论据：带数字的事实，按子题分组 |
| 四 | 四侧原料，只摘原句不归纳：A 做法／表现，B 问题／短板，C 对策，D 作用／意义 |
| 五 | 壳候选：能套问题一、问题二的具体事项，每个壳写了出处原句、适合哪题、有没有问题现场、是否当过小题对象；末尾一节是"选例因子"（约束、转化、可复制、一石多鸟） |
| 六 | 缺口（查过哪里、还缺什么）和给 DeepSeek 的补查请求 |

口径：「」里是原句，后面〔〕是出处（从仓库根算起的相对路径｜材料本身的日期）；不加「」的是转述或编者的判断。标〔补〕的是第二轮独立查漏补进来的，原来的排序没动。`tools/`、`toolsE/`、`toolsF/` 是编包时的脚本和底稿，后面用不着。

### 1.2 怎么用

| 后面要做的事 | 从哪里取 | 注意 |
|---|---|---|
| 建本质动作图谱 | 四 A 侧、C 侧抽"动作"；五 看动作落在哪件具体事上；各包"选例因子"一节（A 5.13、B 5.12、E 5.8、F 5.7、D 5.10）给"约束—转化"这一维；D 包末尾附录、F 5.7 末尾的"揭底用的本质动作"可以当起点 | 几条线共有的动作（如"存量换新用途"）放图谱的公共层，不要每条线各建一份（见 3.5） |
| 出问题一（20 分，做法／表现／作用） | 五 选壳 → 四 A 侧、三 论据编单则正面材料；问"作用"用四 D 侧 | 标了"独特禀赋"的例子只当成效用，不当可推广的做法（B 包 5.12 的建议，A 包 5.13 意思相近） |
| 出问题二（30 分，问题＋对策） | 五 里"问题现场：有"的壳 → 四 B 侧编座谈或调研现场，四 C 侧定答案要点 | 问题现场是五个包共同最薄的地方（2.3）；"没有"的只能合成，合成的在命题说明里标"示意" |
| 备作文 | 一 题眼、二 材料一、三 论据；四 D 侧的传导链写"为什么"；选例因子节里"一石多鸟"的例子 | 同一篇母文件常被几条线分段用，先熟读这几篇（3.2） |
| 考后对账 | 零 的登记概率和反证 | — |

用原句之前：照〔〕回原文件看一眼上下文。`check_quotes.py` 只保证原句逐字在那个文件里，不核日期，也不核〔〕外面的转述对不对【实证：读过脚本】。

建议的先后：图谱和训练题先做 A、B（各 22%），再 E、F，D 最后【弱推断：只按登记概率排】。
