# 09 按年汇编：题干 · 答案 · 逐句解析

2020–2026 年广东申论 16 套卷，每年一个文件。`.md` 在 GitHub 上可以直接看，`.pdf` 适合下载后看。`广东申论2020-2026_按年汇编.zip` 里是同一批文件（README、7 个 .md、7 个 .pdf），解压后是一个文件夹。

## 收了什么

| 年份 | 卷 | 小题 | 大作文 |
|---|---|---|---|
| 2026 | 省市卷、县镇卷 | 2 + 2 | 2 |
| 2025 | 省市卷、县镇卷、选调卷 | 2 + 2 + 2 | 3 |
| 2024 | 一卷、二卷、选调卷 | 2 + 2 + 2 | 3 |
| 2023 | 县级卷、乡镇卷 | 2 + 5 | 1 |
| 2022 | 县级卷、乡镇卷 | 2 + 5 | 1 |
| 2021 | 县级卷、乡镇卷 | 2 + 5 | 1 |

乡镇卷是五道小题，没有大作文。

## 每套卷里有什么

1. **题干**：试卷的作答要求（每道题的题干和「要求」），照原卷录入，原卷的笔误也保留。
2. **小题**，每道题四节：
   - 答案：能直接抄到答题卡上的答案，字数在上限以内。
   - 考场上的思路：第一人称，按拿到卷子的顺序写抓了哪些词、每段材料是什么事、哪几件事并成一条、在哪里犹豫过、字数怎么分。
   - 逐条解析：每个要点先写「现实里是一件什么事」「为什么归成这一条」；答案里的每个分句再写来源（材料几第几段第几句的原话）、怎么改的、为什么这么改、不这么写会怎样、以后遇到怎么办。
   - 压缩与成本：材料多少字压到多少字，按什么次序砍的，特意留了哪些低频词，全题自造几个字。
3. **大作文**，三节：
   - 考场上的思路：读题、看小题占了哪几则、翻材料定几个面、标签句形怎么来、每段怎么填、标题怎么起、超字删了什么。
   - 作文。
   - 逐句解析：按标题、开头、各段、结尾分块，每块先说这一处要做什么，再逐句写来源、怎么改的、为什么、以后遇到怎么办。

解析里的「材料几第几段」指原卷给定材料的自然段。材料原文在仓库根目录同年份的真题 PDF 里，也可以看 `08_小题重写/samples/<套>/material.txt`。

## 同一道题出现两次

- 2026 省市卷和县镇卷的问题一是同一道题（材料逐行相同），两份答案逐字相同，解析只差材料编号。
- 2024 一卷和二卷的问题一是同一道题（题干逐字相同，材料二几乎相同），两份答案逐字相同，解析里的段号和个别说法不同。

两份都收了。

## 重新生成

在仓库根目录运行：

```
python3 09_按年汇编/tools/build.py     # 写 7 个 .md
python3 09_按年汇编/tools/to_pdf.py    # 写 7 个 .pdf（要用 Playwright 和 Chromium，字体用文泉驿正黑）
python3 09_按年汇编/tools/pack_zip.py  # 打压缩包
```
