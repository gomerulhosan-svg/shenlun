## 0 判定口径

- **命中**：采分点的本质动作，也就是"谁对什么做了什么"，能在某个一级条目的定义、判别规则或常见形态里找到同一件事。动词和对象都对得上。
- **近似**：方向对，但缺了让这个点成为采分点的那一层。常见有三种情况：
  - 只落到一个很泛的大类；
  - 动词对得上，对象不在该条目写明的范围里（如厂区绿化对 H11 自然生态系统）；
  - 这个点单独成立，靠的是一个具体限定（如"运营管理人才"、"财政之外的钱"、"宣传渠道"），而清单里没有这个限定。
- **未命中**：两份清单里都找不到方向一致的条目。
- 侧别：
  - 问题一只对 A 侧（H01–H25）判；
  - 问题二的问题侧只对 B 侧（Q01–Q16）判，对策侧只对 C 侧（H01–H25）判；
  - 作文分面先对 D 侧（L01–L18）判，D 侧没有才往其他侧找，表里写明落在哪一侧。
- 通用清单用同一套口径判：
  - 问题侧按"反过来是哪一项"判，如"资金缺口"对"加大资金投入"；
  - 通用项名字太泛、只能当大类兜底的，最多算近似。
- 采分点来自各卷 `对齐.json`：
  - 同一编号的原词份（pool）和近似份（near）合成一个点，票数取两者之和；
  - 同一编号但 `what` 或 `note` 写明是不同内容的，分成两个点，如县镇"宣传《条例》"和"宣传渠道"、省市"非财政资金"和"金融信贷"；
  - 类别照抄 `class`（必答、可选、个案）。
- 终稿答案条目（`Q1.md`、`Q2.md` 的"答案"一节）另外判一遍，按条判，一条里有两半的按主干判，另一半在理由里写明。
- 同一个点能挂几个动作时，"图谱动作"一栏写主挂，括号里写加挂。判定按主挂最好的那一个。

### 1.4 读数

- **小题采分点**：
  - 三题合计 99 个点，图谱命中 62/99（63%），通用清单命中 18/99（18%）。
  - 只看必答点（49 个），图谱命中 37/49（76%），算上近似 49/49（100%）；通用清单命中 9/49（18%），算上近似 36/49（73%）。
- **差距最大的是问题一（A 侧）**：图谱命中 17/31，通用 1/31；只看必答，图谱 11/13，通用 0/13。
  - 通用清单是一套政府工作腔，对"一家工厂的绿体现在哪"几乎无话可说，只有"克服技术难题"一处命中。
  - 图谱能把能源、产品、办公、供应链、回收五面都落到具体动作上（H01、H07、H05、H24、H06）。
  - 图谱唯一吃亏的是景观面：H11 的对象写成了自然生态系统，§7.1 对"绿色工厂"也不路由到绿化。必答的"植被加绿墙"和"乡土阔叶树种"只算近似，而这一面是 10/10 份都写了的。
- **问题侧（B 侧）**：
  - 图谱命中 17/32（53%），通用 7/32（22%）；只看必答，图谱 10/16，通用 3/16。
  - 这是三侧里两份清单差距最小的一侧。人才、资金两类，通用清单反推就能命中。
  - 县镇问题侧是图谱最弱的一格，命中只有 4/12。
  - 图谱多赢在这几处：评价考核、交易规则、配套设施（Q09、Q11）；因地制宜、半路退出（Q12）；积极性不高（Q05 的"收益低、没人管"）；深山难护（Q10 的"分布广、客观难管"）。
  - 两边都落不准的是执行层卡点："重建设、轻运营"，"专业服务公司少、不能全流程"，"保护性破坏（好心办坏事）"，"审批流程繁琐、错过黄金时间"，"巡山危险"，"台风受损"。图谱 §8 第 3 条已经自认这块是盲区，这次在两套卷的问题侧都应验了。
- **对策侧（C 侧）**：
  - 图谱命中 28/36（78%），通用 10/36（28%）；只看必答，图谱 16/20，通用 6/20。
  - 图谱的优势在"具体到哪一种工具"：钱分财政（H19）和非财政（H18）；监管分数字手段（H16，原词有无人机）和执法（H22）；增收走生态旅游（H14）；服务走培育服务商（H09）；规划走"有计划、分步骤、分类指导"（H20）。

  - 两边都缺的是这几层：流程再造（简化申请手续、先抢救后申请）；园区对周边的能源互济和设施共享；全链条服务；讲好文化故事。
- **作文分面**：
  - 图谱 8 个分面里 7 个命中，其中 6 个在 D 侧本身命中。
  - 生态美在 D 侧没有"生态本身"的链，要回到 A 侧 H11 才接得上。
  - 唯一近似的是县镇的"文化兴"：D 侧没有文化链，A 侧也没有文化动作。
  - 通用 7 项命中 4/8，都落在"竞争力、民生、经济、生态"四个大词上；"生态安全屏障""生活方式""文化供给""富民增收"只到近似。

## 6 附：和"方案可行性、选例理由"这个新因子有关的观察（不计分）

用户提出的新因子是：一个目标可以有很多方案，但受钱、人等条件约束，不是每个都可行；有的资源够用，可以转化；选例的理由可能是做得出彩，可能是可复制，也可能是一石多鸟。这次回测里，阅卷高票的对策正好有几处能用这个因子解释，而图谱 C 侧的"首选在前"排序只按病根排，没有考虑可行性：

- **约束下换路**：
  - 省市"自己培养人才"8/9：材料说各地都缺人，光靠引进抢不到。
  - 省市"补贴之外的非财政资金"6/9：材料说财政补贴远远不够。
  - 两处都是材料先给出约束，真人卷自己补出了第二条路。图谱 H18 和 H19 按钱的来源分开，正好接得住后一处。
- **现成资源转化**：
  - 省市"与周边能源互济、设施共享"6/9：园区旁边就有光伏电厂。
  - 县镇"请懂行的人来教"5/8：座谈会已经请了专家。
  - 县镇"表彰奖励"7/8：《条例》已经写了可以表彰奖励。
  - 这类对策靠的是材料里已经在场的资源，图谱没有这个视角。
- **一石多鸟**：
  - 县镇"讲古树故事＋结合旅游，让群众靠保护致富"8/8：同一个动作既治"积极性不高"，又给保护筹了钱。
  - 图谱里只有 Q05→H14 的对应，没有标出这是"一策打多病"。
- 如果要把这个因子写进图谱，最自然的位置是 C 侧 §4.1 对应表：在每个病根的对策组合后面加一栏"材料里的约束或现成资源"，排序时把"约束下还能做、材料里已有资源、一策打多病"的动作往前提。
