# 动作卡｜改革开放（训练版）

> 训练版，背这张；判别规则和出处见研究版 `12_答题方法/图谱_改革开放.md`。2026-09-29。

**核心逻辑**：要干成"对内理顺规矩、对外开大门、湾区三地连通"；靠政府放管服护、市场破壁反卷、要素钱主体到位、先试后推、开放五件事、湾区六联通、借专业力量（H01–H25）；卡在制度成本和扰企、壁垒内卷、要素资金预期、开放能级、跨境差异和改革碎片化（Q01–Q20）；带来降成本稳预期、激活力畅循环、引资源拓市场、促融合强辐射（L01–L20）。

## H 动作表（A 做法＝C 对策）

| 编号 | 名称 | 一句话 | 标准表述 | 约束画像 |
|---|---|---|---|---|
| H01 | 审批精简放权 | 少批、快批、往下放 | 推行告知承诺、容缺后补和并联审批，压缩项目落地周期 | 耗权、时；缺权→改方式、借试点 |
| H02 | 政务服务集成 | 一件事一次办、免申即享 | 推进"高效办成一件事"，跨部门集成办理 | 耗技、钱；缺→复用省级平台、先一窗受理 |
| H03 | 政企沟通闭环 | 有事找得到、有回音 | 畅通企业诉求反映渠道，推行首接负责、分级办理和提级调度 | 耗人，几乎不花钱；缺人→商会搭桥、12345 |
| H04 | 规范执法、包容审慎 | 少扰企、给新业态留空间 | 推行涉企行政检查"亮码入企""综合查一次"和非现场执法 | 耗技、人；缺人→非现场、信用分级 |
| H05 | 清欠护权、平等护企 | 钱和产权有人护 | 建立健全清理拖欠企业账款长效机制，规范大型企业付款期限 | 耗钱、权；缺钱→先立规、分期、置换 |
| H06 | 破除壁垒、统一市场 | 拆地方保护和隐性门槛 | 全面清理妨碍统一市场和公平竞争的政策文件，落实公平竞争审查 | 耗权、动地方利益；阻力大→先清本地文件 |
| H07 | 整治内卷式竞争 | 拼价格变拼质量 | 引导企业从拼价格转向拼质量、拼创新 | 耗权、人；取证难→标准抬门槛、行业自律 |
| H08 | 要素市场化配置 | 地人数据按市场流动 | 深化要素市场化配置改革，健全土地混合利用、弹性供给规则 | 耗地、权；缺指标→改供地方式；缺权→借试点 |
| H09 | 盘活存量资源 | 闲置低效的再用起来 | 盘活用好低效用地、闲置房产、存量基础设施 | 耗时、人，钱少；本身是缺地缺钱的换路 |
| H10 | 降本减负 | 政府少收、改付钱方式 | 实施降成本行动，健全涉企收费长效监管 | 耗财政钱；缺钱→清费、分期、补改投 |
| H11 | 金融助企融资 | 金融的钱到企业 | 健全小微企业融资协调机制和融资增信制度 | 耗金融额度；缺抵押→信用、应收账款作押 |
| H12 | 壮大经营主体 | 各类企业平等长大 | 对各种所有制企业一视同仁、平等对待 | 耗权、场景；缺钱→引民资、开放场景 |
| H13 | 试点首创推广 | 先试后推 | 形成一批首创性制度成果并在全省复制推广 | 耗权、时；缺授权→小切口、复制成熟经验 |
| H14 | 对标规则、扩大准入 | 外资进得来、营得了 | 稳步扩大规则、规制、管理、标准等制度型开放 | 耗国家事权；缺权→平台压力测试、地方立法 |
| H15 | 招商引资提质 | 拼优惠变拼生态 | 由拼优惠转向拼产业生态和营商环境 | 耗配套、服务；优惠用完→以商招商、场景招商 |
| H16 | 外贸拓市场与入境消费 | 拓新市场，客流变消费 | 以展促贸、多元开拓国际市场，发展跨境电商＋海外仓 | 耗钱、人；外需受阻→新兴市场、出口转内销 |
| H17 | 通关监管便利 | 少报少查快放 | 实现一次申报、一次查验、一次放行 | 耗海关授权；缺设施→组合港、前置货站 |
| H18 | 企业出海服务 | 出去有人帮 | 健全企业出海全链条服务和海外综合服务体系 | 耗专业人手；缺人→机构入驻、抱团出海 |
| H19 | 规则机制软联通 | 资格认得出，人钱数据过得去 | 系统梳理两地规则差异、形成衔接清单，找最小可行规则先行突破 | 耗权、时；缺权→单边认可、备案先行 |
| H20 | 跨境民生融通 | 港澳居民办事像本地 | 完善港澳居民在粤医保和社保政策 | 耗钱、医教资源；缺→借港澳资源、设专窗 |
| H21 | 涉外法治协作 | 纠纷能解 | 完善涉港澳商事纠纷解决机制 | 耗立法权、律师；缺→小切口立法、引港澳律师 |
| H22 | 开放合作平台 | 试验田，差异互补 | 推进横琴、前海、南沙、河套等重大平台建设 | 耗平台资格、钱地；无资格→联动发展区、飞地 |
| H23 | 区域协同联动 | 跨区建机制、带腹地 | 健全跨区域产业协作和利益共享机制 | 耗协调、时；协调不动→联席会议起步、飞地 |
| H24 | 基础设施硬联通 | 桥路口岸通道 | 推进基础设施互联互通 | 耗钱多、时长；来不及→用足现有设施 |
| H25 | 借力专业力量 | 政府搭台行业唱戏 | 发挥行业协会、专业服务机构作用，实行"政府搭台、行业唱戏" | 耗协调、少量服务费；本身是缺人的换路 |
