# 回测打分 · 第 2025 轮 · 打分员 A

## 〇、口径

- **测试集**：2025 省市卷问题二（科研成果转化，n=4 份真人卷）、2025 县镇卷问题二（科技赋能农业，n=7 份）。采分点取自 `08_小题重写/2025省市/对齐.json`、`2025县镇/对齐.json` 的 `问题二.points`，内容和问题侧、对策侧的判断参照同目录 Q2.md，县镇另参照 过程.md 问题二的矩阵表。只读了这几份文件，没碰 samples/、_pool/ 和 2024 三卷。
- **侧别**：两份 JSON 都没有 `side` 字段，一律按 note 判。note 写"对策：……"的归对策侧，其余归问题侧。县镇 四-p13-3i 的 note 是"只在对策侧出现，问题侧 0/7"，归对策侧（建立国家级标准）。
- **个案**：JSON 里 class＝个案的点（含 0 票点）单列在第二节，不进覆盖率。省市 3 个，县镇 4 个。
- **进覆盖率的点**：共 37 个。省市 19 个（问题 7、对策 12；必答 12、可选 7），县镇 18 个（问题 10、对策 8；必答 13、可选 5）。必答合计 25 个。
- **票数**：写成"x/n"，照抄 JSON 的 papers 数。note 里写了"含近合计"的，一并注出。
- **判定**：H＝命中，本质一样。N＝近似，方向对，但缺关键的一层。M＝未命中。组合几条时，要求每一层都在其中某一条里找得到，两个泛类拼不出它们都没有的那一层。
- **通用清单在问题侧的读法**：把条目反过来读成"X 不足 / 不完善"（例：强化人才支撑 → 人才支撑不足），再拿去对问题侧的点。
- **层的判法**：用任务给的执行层环节清单，再加模块〇·1 的换主题法。换掉主题名词后这句话照样成立、而且说的是"事情怎么做成"，判执行层；缺的东西本身就是这个主题要交付的内容（装备、科研供给），判主题层。

给新因子的初步观察：票数最高的两条"换路"对策都在县镇卷，而且形态相同：**本地某种能力不足，而另一类主体手里同样的能力闲着、被规则挡在门外，于是改规则、放它进来，或者把几方现成的力量拼起来**。模块的约束画像按"缺钱、缺人、缺地"这些资源类型组织，只能找到同类资源的替代品，找不到"让另一类主体补位"这一路；"被规定挡在门外"也没有对应的 C 侧动作（见 X17）。省市卷的两条（平台替代中介、特派员用现成的人）属于"缺人 → 用平台或现成队伍替代"，模块的 C11 在思路上已经有了，只是没有写到人手以外的场景。
