# 执行层模块·乙（政策视角）｜第 2025 轮盲建

## 〇、先说清楚

**这是什么**：五条主线共用的"执行层"问题—对策库。执行层 = 事情怎么做成的通用环节，换一个主题照样会碰到。某个主题特有的卡点（某项技术不成熟、某类指标难核算之类）不放这里，归各主线图谱。

**这一份的视角**：政策视角。先从 2019–2024 年省政府工作报告里"清醒看到/清醒认识到"那一段、为基层减负和整治形式主义、营商环境、"高效办成一件事"、基层治理、"百千万工程"决定、2024 年中央一号文件、三中全会决定里，找官方自己承认的执行层毛病和官方给的解法；再到 2020–2024 年广东省考真题材料里找"当事人怎么说"。

**怎么用**（考场三步）：
1. 读材料，碰到抱怨、困难、"但是""可惜""没想到"，按各条"判别规则"归到 B 侧病根。一句话可以同时归两条。
2. 按第三部分对应表，从 C 侧取对策，方案照样列全、不排权重。
3. 每条对策看"约束画像"：材料里如果写了缺钱、缺人、缺地、缺技术、缺权限、缺时间，就把"缺这种资源时"那一栏的替代路径写进去；材料里有闲着的资源，就用"能转化的富余资源"那一栏。

**取材边界**：只用 2024-12-31 及以前发布的材料；真题只用 2020–2024 年（县级卷、乡镇卷、2024 一卷、二卷、选调卷），2024 年三卷（行政执法）不碰。没有读任何 2025、2026 年的卷子、溯源文件和报告。

## 一、B 侧：执行层病根（25 条）

### B01 统筹协调不畅
- **定义**：一件事要几个部门、几级政府或几个主体合着办，没人牵头或各管一段，职责有交叉、有空白，利益谈不拢。
- **判别规则**：材料出现"在不同部门之间来回跑""散落在各部门""没有统一窗口""重复对接""各自为政""同质化竞争""出于自身利益不愿配合"。
- **材料里常见的样子**：
  1. 「以往，职称和职业资格业务散落在各业务部门」（真题22·县级卷·材料三〔8〕，服务问题一）
  2. 「以前办理企业证照、缴纳税费时，要在不同部门之间来回跑」（真题21·县级卷·材料二〔8〕，服务问题一）
  3. 「省级与市级开发系统提出的数据对接需求存在重复，造成开发费用高」（真题24·一卷·材料八〔6〕，服务问题二）
  4. 「过去“一城一港” 建设模式下，港口出现同质化竞争激烈、公共资源配置不优等问题」（真题20·县级卷·材料六）
  5. （示意）"这事归哪个部门管，谁也说不清。"
- **答题标准表述**：① 部门协同不够，职责边界不清，存在多头管理、推诿扯皮；② 统筹协调机制不健全，上下级、部门间衔接不畅，重复对接、各自为政。
- **出处**：
  - `09_按年汇编/2022年广东申论_题干答案与逐句解析.md`｜2022 年省考县级卷材料三｜「以往，职称和职业资格业务散落在各业务部门，不管是内地人员还是港澳人员，都面临线上网站分散查询不便、线下信息获取渠道少、没有统一对外服务窗口等难题，而现在这些问题都不存在了。」
  - `10_选材因子/溯源结果/页面快照/_cache_2024二卷/gdzz_jueding_baiqianwan.txt`｜2022-12-08｜「省成立“百县千镇万村高质量发展工程”指挥部，强化统筹协调、政策制定、督促落实等职责。」（官方用设指挥部来对治这一条）

### B02 办事流程繁琐
- **定义**：群众、企业或基层办一件事，要多跑、多交材料、多过几道审批，耗时长、成本高。
- **判别规则**："跑了好几趟""排队取号、交资料""前后花了几天""手续多""写本子""跑镇里跑县里走程序""反复申请"。
- **材料里常见的样子**：
  1. 「由于要排队取号、交资料，跑了好几趟，前后花了 3 天时间才注册成功」（真题20·县级卷·材料三〔6〕，服务问题二）
  2. 「花费大量时间“写本子”“打听情况”」（真题24·选调卷·材料四〔4〕，服务问题二）
  3. 「跑镇里跑县里走程序」（真题21·乡镇卷·材料九〔3〕，服务问题五）
  4. （示意）"证明要开好几份，到底要哪些材料没人说得清。"
- **答题标准表述**：① 办事流程繁琐，环节多、材料多，群众企业多头跑、反复跑；② 审批和申报程序复杂，办事效率不高，制度性交易成本高。
- **出处**：
  - `09_按年汇编/2020年广东申论_题干答案与逐句解析.md`｜2020 年省考县级卷材料三｜「小朱说，2018 年，他在惠城区行政服务中心注册一家公司，由于要排队取号、交资料，跑了好几趟，前后花了 3 天时间才注册成功。」
  - `10_选材因子/第三轮/01_成品/政府工作报告/政府工作报告_2024.md`｜2024-01-23｜「深化营商环境综合改革，开展涉企违规收费整治，降低经营主体制度性交易成本。」

### B03 权责不匹配（小马拉大车）
- **定义**：基层担的事多、责任重，权限、编制、钱、物跟不上；上级事务层层压到乡镇和村。
- **判别规则**："工作特别多特别杂""什么都压到镇里""没有专项资金，也不知道怎么推进""非常需要上级指导支持""要报县里批""借调"。
- **材料里常见的样子**：
  1. 「感觉工作特别多特别杂」（真题23·乡镇卷·材料四〔10〕，服务问题四）
  2. 「村里有加强规划的意思，但没有规划专项资金，也不知道怎么推进规划工作，非常需要上级指导支持」（真题24·二卷·材料五〔7〕，服务问题二）
  3. （示意）"上面千条线，下面一根针。"
  4. （示意）"这个权限在县里，我们只能层层打报告。"
- **答题标准表述**：① 基层权责不对等，任务重、权限小、资源少，"小马拉大车"；② 上级事务层层下压，基层承接能力和资源保障不足。
- **出处**：
  - `10_选材因子/溯源结果/页面快照/_cache_2024二卷/gov_cn_yihaowenjian2024.txt`｜2024-02-03｜「加强乡镇对县直部门派驻机构及人员的管理职责，加大编制资源向乡镇倾斜力度，县以上机关一般不得从乡镇借调工作人员，推广“街乡吹哨、部门报到”等做法，严格实行上级部门涉基层事务准入制度，健全基层职责清单和事务清单，推动解决“小马拉大车”等基层治理问题。」
  - `10_选材因子/溯源结果/页面快照/_cache/补查_三中全会决定全文_gov.txt`｜2024-07-18｜「健全乡镇（街道）职责和权力、资源相匹配制度，加强乡镇（街道）服务管理力量。」

### B04 资金保障不足（缺口大、来源单一、难持续）
- **定义**：钱不够，或者只有一条来路；建设时有缺口，建成后运行没来源。
- **判别规则**："经费缺口""没有专项资金""经济基础薄弱""投入大、周期长""融资直摇头""主要来源于……正寻找其他资金来源""光靠……收入"。
- **材料里常见的样子**：
  1. 「在建设经费上仍存在较大的缺口，村里压力非常大」（真题24·二卷·材料五〔10〕，服务问题二）
  2. 「为保障积分制一直运行下去，我们正寻找其他资金来源渠道」（真题23·乡镇卷·材料三〔14〕，服务问题三）
  3. 「说起融资却直摇头」（真题23·县级卷·材料六〔7〕）
  4. 「研制创新药需要大量资源和研发资金持续投入，过程漫长，业内许多公司很难承受」（真题24·一卷·材料八〔9〕，服务问题二）
  5. 「以前光靠山林池场这些租金，村集体一年收入也就 1 万多」（真题23·乡镇卷·材料五〔4〕，服务问题五）
- **答题标准表述**：① 资金投入不足，建设经费缺口大，基层财力薄弱；② 资金来源单一，过度依赖财政或集体收入，缺乏可持续的多元投入保障机制。
- **出处**：
  - `10_选材因子/溯源结果/页面快照/_cache/2024_政府工作报告_eastmoney.txt`｜2024-01-23｜「房地产、金融等领域还存在风险隐患，部分市县财政收支矛盾突出。」（"清醒认识到"一段）
  - `09_按年汇编/2024年广东申论_题干答案与逐句解析.md`｜2024 年省考二卷材料五｜「调研组发现，像 J 镇这样以自然保护区为主要功能的零工业镇，在这次建设乡村振兴示范带时，尽管上级部门有安排专项资金，但因地处偏僻，村集体经济不发达，经济基础薄弱，历史欠账较多，在建设经费上仍存在较大的缺口，村里压力非常大。」

### B05 要素紧张与资源闲置
- **定义**：要用的地、设备、机械、场地一时拿不到；手上已有的厂房、校舍、古建、劳动力、文化资源却闲着没用上。两件事常常同时出现。
- **判别规则**："很难请到挖掘机""没有合适的场地""受到规划制约（用地）""闲置了好久""常年无人居住""未能进行更有效，更充分利用""地多钱少/钱多地少/人多没资源"。
- **材料里常见的样子**：
  1. 「现在全县都在复耕复种，很难请到挖掘机」（真题22·乡镇卷·材料四〔8〕，服务问题四）
  2. 「发现这几间厂房闲置了好久」（真题23·乡镇卷·材料五〔4〕，服务问题五）
  3. 「目前未能进行更有效，更充分利用，更别说转化为资产了」（真题24·二卷·材料五〔9〕，服务问题二）
  4. 「我们村的地是不少，但资金短缺；塘尾村没有合适的养殖场地，不过比较有钱；羊角村没什么自然资源，劳动力比较多」（真题23·乡镇卷·材料五〔6〕，服务问题五）
- **答题标准表述**：① 要素保障不足，用地、设备等资源供给紧张；② 存量资源盘活不够，闲置资产和文化资源未有效利用、未转化为发展资本。
- **出处**：
  - `10_选材因子/第三轮/01_成品/政府工作报告/政府工作报告_2020.md`｜2020-01-14｜「加强对存量资金的清理，盘活各类闲置资源资产。」
  - `10_选材因子/溯源结果/页面快照/_cache_2024二卷/gov_cn_yihaowenjian2024.txt`｜2024-02-03｜「鼓励以出租、合作开发、入股经营等方式盘活利用农村资源资产，增加农民财产性收入。」

### B06 人手力量不足
- **定义**：事多人少、地方大，现有人员覆盖不过来，只能突击干。
- **判别规则**："力量有点不够""光靠镇村干部哪里排查得过来""外出务工的人较多，联系核实花的时间多""今天要全部干完""一个人管几块"。
- **材料里常见的样子**：
  1. 「辖区这么大，总感觉我们力量有点不够，风险隐患光靠镇村干部哪里排查得过来」（真题23·乡镇卷·材料四〔17〕，服务问题四）
  2. 「河西村外出务工的人较多，联系核实花的时间多，进度会较慢」（真题22·乡镇卷·材料四〔8〕，服务问题四）
  3. （示意）"村里只剩老人小孩，想找人干活都难。"
- **答题标准表述**：① 基层工作力量薄弱，人手不足，难以做到全覆盖；② 专职人员少、任务重，工作只能突击推进，难以常态化。
- **出处**：
  - `09_按年汇编/2023年广东申论_题干答案与逐句解析.md`｜2023 年省考乡镇卷材料四｜「〔17〕“说到隐患排查，辖区这么大，总感觉我们力量有点不够，风险隐患光靠镇村干部哪里排查得过来……”小潘摇摇头说。」
  - `10_选材因子/溯源结果/页面快照/_cache_2024二卷/gdzz_jueding_baiqianwan.txt`｜2022-12-08｜「各地级以上市要强化责任担当，推动资源下沉，加强要素保障。」

### B07 专业能力不足
- **定义**：干事的人缺经验、没培训、不懂技术；或本地缺专业人才、缺技术服务。
- **判别规则**："新来的……还没经过培训""操作不当""太缺乏经验""没有成熟有效的办法""普遍没有专业技术""缺乏专业的……人才""不知道怎么办/怎么推进"。
- **材料里常见的样子**：
  1. 「由于新来的护林员还没经过培训，操作不当把仅有的两台风机弄坏了」（真题21·乡镇卷·材料五〔5〕，服务问题二）
  2. 「自己还是太缺乏经验了」（真题23·乡镇卷·材料四〔6〕，服务问题四）
  3. 「第二是之前没有封闭式管理经验，没有成熟有效的办法」（真题20·乡镇卷·材料二〔12〕）
  4. 「镇里缺乏专业的电商人才」（真题20·乡镇卷·材料四〔21〕，服务问题三）
  5. 「大坪镇种植户多，普遍没有专业技术」（真题22·乡镇卷·材料五〔10〕，服务问题五）
- **答题标准表述**：① 队伍专业能力不足，新手未经培训即上岗，经验缺乏、方法不多；② 本地专业人才和技术服务供给不足。

## 二、C 侧：执行层对策（24 条）

约束画像四栏的意思：**消耗**＝这条对策主要花什么（钱/人/地/技术/权限/时间）；**缺这种资源时**＝替代路径；**能转化的富余资源**＝材料里常见的闲着的东西，可以拿来用；**一石多鸟**＝顺带能解决哪几条病根。

### C01 建统筹协调机制
- **标准表述**：成立专班或联席会议，明确牵头部门和责任分工，定期研判调度，推动部门联动、上下协同。
- **对应病根**：B01、B03、B11
- **约束画像**：
  - 消耗：权限（牵头方要有协调权）、时间（开会研判）。
  - 缺这种资源时：缺权限→提请上级领导挂帅或由上级指挥部统筹；用"街乡吹哨、部门报到"把县直部门拉进来；跨镇的事找邻镇对口负责人直接协商（22 乡镇老张的做法）。缺时间→每周固定研判一次代替临时开会，能线上会商就线上。
  - 能转化的富余资源：熟悉情况、协调能力强的老干部；已有的例会、工作群。
  - 一石多鸟：一次联合会商同时解决几个部门的事，少了重复对接和重复检查，顺带减负（B20）。
- **出处**：
  - `10_选材因子/溯源结果/页面快照/_cache_2024二卷/gdzz_jueding_baiqianwan.txt`｜2022-12-08｜「省成立“百县千镇万村高质量发展工程”指挥部，强化统筹协调、政策制定、督促落实等职责。」
  - `09_按年汇编/2022年广东申论_题干答案与逐句解析.md`｜2022 年省考乡镇卷材料四（服务问题四）｜「第二天，根据领导要求，老张协调党政办、自然资源、农林水等部门负责人一起充分讨论了开展这项工作将会面临的困难、需要注意的事项，并提出每周定期研判推进情况和存在问题。」

### C02 流程再造，"高效办成一件事"
- **标准表述**：推行一窗受理、一网通办、一次办成，精简材料和环节，推行告知承诺、并联审批，提供帮办代办。
- **对应病根**：B02、B01、B14、B15
- **约束画像**：
  - 消耗：技术（系统平台）、钱（建设运维）、权限（跨部门授权、数据调用）。

## 四、约束速查：缺什么 → 往哪条路走

把 C 侧各条"缺这种资源时"一栏收拢，考场上材料一写"缺 X"，直接查这张表。

| 缺什么 | 替代路径（照样列全，不排先后） | 见 |
|---|---|---|
| 缺财政钱 | 政府出一点、集体筹一点、社会资本投一点、银行贷一点、帮扶方补一点、乡贤捐一点；以奖代补、先建后补；以工代赈；企业赞助、消费券；运营收益反哺；知识产权质押等金融工具 | C04、C08 |
| 缺人手 | 发动群众和党员；志愿者、网格员、社会组织；公益性岗位；村民自治（门前三包、村规民约）；数字化替代部分巡查；上级派驻人员归乡镇统筹 | C06、C03、C21 |
| 缺专业能力 | 以老带新；专家、科技特派员、农技员下沉或远程会诊；购买服务；高校"三下乡"揭榜领题；上级编指引、办培训；争取上级培训班落地本地 | C07、C11 |
| 缺地、缺场地、缺设备 | 盘活闲置厂房、校舍、零散土地；出租、入股、合作开发；村与村抱团（有地的出地、有钱的出钱、有人的出人）；邻镇调剂、租赁共享、应急征用调度 | C05、C22 |
| 缺技术、缺系统 | 先做不需要系统的：清单化、一次告知、告知承诺、线下一窗；依托省级现成平台；统一需求防重复开发 | C02、C14 |
| 缺权限 | 提请上级统筹或授权；"街乡吹哨、部门报到"；联合执法；扩权赋能要配套培训和人员，保证接得住 | C01、C03、C17 |

## 五、这一份（政策视角）自己看到的缺口

1. 官方文件讲执行层，多站在政府内部讲（统筹、考核、减负、容错），对**合作方和市场主体这一层**讲得少：供应商不愿开放数据、承包方质量、利益怎么分、合作违约，这些在真题里出现过（24 一卷数据端口、23 乡镇三村按比分成、21 乡镇民宿五五分成），本模块只散落在 B01、B14、C05、C08 里，没有单列"利益联结/合作机制"一条。
2. **时间和时序**没单列：农时、季节窗口（寒潮前盖膜、复耕抢工期、春节前后）、审批周期、"来不及"。政策文件几乎不讲，真题材料里经常出现（"不误农时""没来得及全部盖上"）。
3. **产权和法律合规**没单列：管护主体不明往往是产权不清，拆迁占地、土地流转、集体资产入股都卡在这里。官方有"明确管护主体""理顺产权关系"一类表述，本模块只并进了 B08、C08。
4. **舆情和信息发布**、**邻避和群众反对**只在 B13 里带过。
