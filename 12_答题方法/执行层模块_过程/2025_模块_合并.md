## 〇、先说清几件事

### 1. 执行层和主题层怎么分（甲的换主题法，乙同意）

把材料里那句话的主题名词换掉（柚子换荔枝、积分制换垃圾分类、科研经费换养老补贴），这句话还成立，就是执行层，进本模块；换掉就不成立，就是主题层，归主线图谱。

- 「镇里缺乏专业的电商人才」：换成别的主题，"缺专业人才"照样成立 → 执行层（B13）。
- 「规模偏小，抗风险能力不强」：任何承接主体都可能这样 → 执行层（B18）。
- 「创新药投入大、周期长」「深加工未开发」「精准治疗科研力量薄弱」：离开主题就不成立 → 主题层，不收。

合并时按这条规则，把乙的两处带主题的例句剔掉了（见第七节第 1 条）。

### 2. 考场三步和病根口诀

考场三步（乙）：
1. 读材料，碰到抱怨、困难、"但是""可惜""没想到"，按各条"判别规则"归到 B 侧病根。一句话可以同时归两三条。
2. 按第三节对应表，从 C 侧取对策，方案列全、不排权重。
3. 看对策的"约束画像"：材料写了缺钱、缺人、缺地、缺技术、缺权限、缺时间，就把"缺 X →"那一栏的替代路径写进去；材料里有闲着的资源，就用"富余"那一栏；能一石多鸟的点出来。

病根口诀（甲，出自本项目答案）：
- 答·2024一卷Q2 第 81 行：「材料只说缺、没给解法的，先反写最短的动作，再问病根是不懂、不愿、没钱还是没人，人才类补「引进」。」
- 答·2021乡镇Q2 第 68 行：「先认病根再挑办法——不懂技术配培训，不熟环境配以老带新，不愿干配考核，没钱配投入，已经治过没治住配回头看。」

对到合并后的编号：**不懂** → B01 / B02 / B12 / B13；**不愿** → B03 / B04 / B21；**没钱** → B10；**没人** → B11；**权小事多** → B06；**供需不对路** → B09；**治过没治住** → B16；**有东西没用起来** → B17（和 B03 的"推广不开"）；**会出事** → B23 / B24 / B25。

### 3. 合并怎么标

- 每条第一行"**合并**"：写明并了甲哪条、乙哪条；只并进来一半的写"（部分）"，并说另一半去了哪。
- "**归属**"：共有＝甲、乙都单列了对应条目；甲独有 / 乙独有＝只有一方单列（另一方至多有零星例句）；"共有，含甲独有子项"＝主体共有，某个子项只有一方写了。
- 编号全部重排。第五节有对照表，甲、乙原编号都能查到落在哪条。

### 5. 约束画像怎么读

- **消耗**：这条对策主要花什么（钱、人、地、技术、权限、时间）；"主耗"花得多，"次耗"花一点。
- **缺 X →**：缺这种资源时的替代路径，括号里是出处。标〔补〕的，是允许范围内没找到原句的常识补充，考场可以写，但分量轻，不当采分主干。
- **富余**：能转化的富余资源。
- **一石多鸟**：顺带解决哪几条病根（合并后编号）。

### 第一组　人心

#### B01　组织方认识不到位

- **合并**：甲B01。乙没有单列；乙把「以前没有充分认识到积分的意义……」放在乙B10（方法脱离实际），把「多一事不如少一事」放在乙B19（激励保障不足），合并后这两句归本条。
- **归属**：甲独有。
- **定义**：负责推动的干部或组织方自己没弄清"为什么做、做到什么程度"，不重视，照转文件、走过场，有畏难情绪。
- **判别规则**：主语是干部或组织方，不是群众；材料出现"以前没认识到/不够重视/效果不太好""文件要吃透""多一事不如少一事""嫌工作多、杂"。和 B21 的分界：B21 是干了没回报、怕担责，本条是没弄明白为什么干。和 B22 的分界：B22 是政策本身在执行中走样。
- **材料里常见的样子**：
  1. 「以前没有充分认识到积分的意义，不够重视，实施效果不太好。」（乡23 材料三〔10〕）
  2. 「作为组织方，肯定得自己先明白为什么要进行积分制。」（乡23 材料三〔11〕）
  3. 「大家都劝陈书记多一事不如少一事。」（乡21 材料九〔3〕）
  4. 新干部说「感觉工作特别多特别杂」，领导回「小麦啊，你要提高思想觉悟」。（乡23 材料四〔10〕〔11〕）
  5. 领导交代「县里的文件要吃透，做好安排，确保安全」，反过来说明这一步最容易缺。（乡20 材料三〔16〕）

#### B02　群众知晓不足（宣传引导不足）

- **合并**：甲B02 群众知晓不足 ＋ 乙B12 宣传引导不足（认知不到位）。
- **归属**：共有。
- **定义**：群众、企业对政策、风险、规矩、好处不知道、不理解、存侥幸，对后果判断错；或者外面的人不知道本地的资源和产品。
- **判别规则**：问题出在"不知道"，不是"不愿意"（不愿意归 B03）；材料出现"意识不强""以为……不会有问题""需不需要……（到处打电话问）""不知道/不了解政策""知道的人太少""知名度不高"。「现在年轻人都不愿学，觉得过时」这类"看法"句，乙归认知、甲归意愿，合并后放 B03，两条都可以挂。
- **材料里常见的样子**：
  1. 「第一是群众防范意识不强。」（乡20 材料二〔12〕）
  2. 「起火的原因是村民以为焚烧秸秆应该不会发生多大的问题」（乡21 材料五〔6〕）
  3. 「有个村民两个月前去过湖北，现在需不需要居家隔离？」（乡20 材料二〔10〕，群众不清楚政策口径）
  4. 「我们这里山清水秀，物产丰富，知道的人太少了，有点可惜。」（乡21 材料三〔7〕）
  5. 「但五田柚子在市外的知名度并不高，主要集中在本市销售。」（乡20 材料四〔20〕）
- **答题标准表述**：①宣传引导不到位，群众风险防范意识、参与意识不强，对××政策知晓度低。②对外推介不够，××知名度不高、影响力小。

#### B03　参与意愿不足、推广不开

- **合并**：甲B03 参与意愿不足 ＋ 甲B22 示范推广不开 ＋ 乙B13 群众参与不足（部分：顾虑、观望、不肯学、思想没转变）。乙B13 里"不同意、不愿配合"那几句归 B04。
- **归属**：共有，含甲独有子项（"推广不开"只有甲单列）。
- **定义**：群众或经营主体不信任、观望，或者自己没有劲头，不愿参与、不肯学、不肯先试，变成"政府干、群众看"；好做法、好技术因此停在一家一处，加上成本高、门槛高、推广机制不配套，推不开。

#### B04　利益协调困难

- **合并**：甲B04。乙没有单列；乙把「这几户人家都不同意」放在乙B13（群众参与不足），合并后按甲的判别规则（背后有具体得失）归本条。
- **归属**：甲独有。
- **定义**：事情涉及拆迁、占地、改用途或收益分配，有人的利益会受影响，因而不同意、不配合。
- **判别规则**：背后有具体的得失；材料出现"要拆迁/占用/搬迁""不同意""不愿配合""吃了闭门羹""阵痛""补偿""分成"。
- **材料里常见的样子**：
  1. 「广场周围有几间房子要拆迁，几分田要占用，还有个小作坊要搬迁，这几户人家都不同意，一时很难解决」（乡21 材料九〔3〕）
