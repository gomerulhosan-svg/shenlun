# 执行层模块·甲（盲建，第 2026 轮）

五条主线共用。答"问题 / 短板 / 困难 / 烦恼 / 对策 / 建议"类题时，先用主线图谱找主题层卡点，再用本模块过一遍"事情怎么做成"的各个环节，把执行层卡点补齐。

- 视角：案例视角。从 2020–2025 年县级卷、乡镇卷、县镇卷、省市卷、一卷二卷、选调卷里问题类和对策类小题的材料、本项目答案（08_小题重写/*/Q*.md）和对齐数据（对齐.json）归纳，再往上抽象。
- 规模：B 侧"执行层病根"25 条，C 侧"执行层对策"25 条，另附病根 → 对策对应表、约束速查、富余资源转化表。
- 每条至少引一处允许范围内的原句；所有原句都用脚本在源文件里逐字核对过（核对脚本和清单：scratchpad/exec/2026/verify.py、quotes.tsv、q2–q5.tsv，未命中 0 条）。

## 〇、读法和约定

**1. 执行层和主题层的分界。** 本模块只收"换一个主题也会遇到"的卡点。下面这些归各主线图谱，这里不收：销售渠道窄、价格被压、品牌建设、产业链短、深加工比例低、三产融合不够、关键核心技术落后、产业聚集度不高、硕博培养占比低、近岸海域污染等。边界上的处理：
- "缺专业人才"收（本地服务能力，哪个主题都缺）；"硕博占比低、缺顶级科研人才"不收（教育、科技主题）。
- "照抄照搬、不结合本地"收（方法是否科学）；"技术水平和发达国家差距大"不收。
- "知名度低"只收"信息没传到"这一环；品牌怎么打造归产业主线。

**2. 答题规矩。** 方案照样列全，不排权重。问题条用"答题标准表述"起句，后面接材料原词；对策条按第三节对应表配。约束画像用来挑载体：材料里说缺钱，就写替代路径里的那个载体，不空写"加大投入"。

**3. 文件缩写。**

| 缩写 | 文件 |
|---|---|
| 汇20 … 汇25 | `09_按年汇编/20XX年广东申论_题干答案与逐句解析.md`，L 为该文件行号 |
| 答·<卷>Q<n> | `08_小题重写/<卷>/Q<n>.md`（本项目答案） |
| 齐·<卷> | `08_小题重写/<卷>/对齐.json`（本项目对齐数据） |
| 报20XX | `10_选材因子/第三轮/01_成品/政府工作报告/政府工作报告_20XX.md` |

**4. 日期。** 真题材料和本项目答案写卷年（允许范围内的文件没有记具体考试日期）；材料段自带日期的另注。政府工作报告写发布日期：报2019 = 2019-02-02，报2020 = 2020-01-19，报2022 = 2022-01-24，报2023 = 2023-01-18，报2024 = 2024-01-27，报2025 = 2025-01-19，都早于 2025-12-06。

**5. 出处标签。** 格式为 ［卷年+卷别 材料几〔段〕｜文件 行号］。对齐证据写成『必答 6/7』，意思是 7 份高分卷里有 6 份写到这个点（对齐.json 里 class=必答）；『弱共识』是零真人卷的套，上一版和机构答案两票都有；『有 n=1』是只有 1 份真人卷的套里这份卷写到了。

## 一、B 侧：执行层病根（25 条）

### B01 多头分散、责任不清
- **定义**：一件事要几个部门、几级、几方一起做，但没人牵头，口子散，各管一段，信息和责任在接口处掉下来。
- **判别规则**：材料里出现"散落在各部门 / 找相关部门要发函 / 省市各提一遍需求 / 重复开发"，或者出事以后才追责（"处分了不少人"），归这条。如果是同一件事环节太多，归 B02；如果只是数据不通，归 B16。
- **材料里常见的样子**：
  1. 「职称和职业资格业务散落在各业务部门，不管是内地人员还是港澳人员，都面临线上网站分散查询不便、线下信息获取渠道少、没有统一对外服务窗口等难题」［2022县级卷 材料三〔8〕｜汇22 L84］
  2. 「以前调阅一些文件，找相关部门，一般需要发函，有时几天才能拿到」［2021县级卷 材料二〔11〕｜汇21 L80］
  3. 「省级与市级开发系统提出的数据对接需求存在重复，造成开发费用高」［2024一卷 材料八〔6〕｜汇24 L174］
  4. 「虽然过火面积不是很大，但是处分了不少人」［2023乡镇卷 材料四〔8〕，例会 2023-02-21｜汇23 L1246］
- **答题标准表述**：①部门职责分散、协同联动不够，多头管理、重复建设；②责任分工不明确，责任落实不到位。

### B02 手续繁琐、来回跑
- **定义**：办一件事要交的材料、跑的窗口、过的环节太多，时间耗在程序上。落到一线执行者身上，就是反复申报、填报、"写本子"。
- **判别规则**：跑了好几趟 / 排队取号 / 交资料 / 盖章 / 在不同部门之间来回跑 / 写本子、打听情况 / 跑镇里跑县里走程序。
- **材料里常见的样子**：
  1. 「由于要排队取号、交资料，跑了好几趟，前后花了 3 天时间才注册成功」［2020县级卷 材料三〔6〕｜汇20 L86］
  2. 「以前办理企业证照、缴纳税费时，要在不同部门之间来回跑」［2021县级卷 材料二〔8〕｜汇21 L74］
  3. 「需要不断申请各类计划项目，花费大量时间“写本子”“打听情况”」［2024选调卷 材料四〔4〕｜汇24 L2366］
  4. 「跑这家跑那家，反复做工作，跑镇里跑县里走程序」［2021乡镇卷 材料九〔3〕，座谈会 2021-03-02｜汇21 L1230］
- **答题标准表述**：①办事流程繁琐、环节多、耗时长，群众和企业来回跑；②事务性负担重，申报填报挤占主业精力。

### B03 门槛卡人、兜底有缝
- **定义**：政策本身的准入条件、覆盖范围定得窄，有能力干的进不来，真困难的够不着。
- **判别规则**：规定只允许某类主体 / 必须是…… / 按政策不能…… / 受益人主要是…… / 被排除在外 / 缺乏普惠性。和 B04 的区别：B03 是规定本身卡人，B04 是规定有了但没落下去。
- **材料里常见的样子**：
  1. 「但相关申报规定，项目牵头申报单位必须是本地科研院所、高等院校和事业单位」「但很多时候却不知道怎么参与，或者被排除在外了」［2025县镇卷 材料四〔4〕｜汇25 L1130］
  2. 「根据政策他们一家是不能进入福利院的」［2020乡镇卷 材料五〔4〕｜汇20 L1198］
  3. 「年薪制、协议工资制的受益人主要是项目团队负责人、引进的高端人才以及获得“帽子”的青年人才」［2024选调卷 材料四〔6〕｜汇24 L2370］
  4. 「缺乏对职业早期青年人才的普惠性稳定支持」［2024选调卷 材料四〔3〕｜汇24 L2364］
- **答题标准表述**：①准入门槛设置不合理，有能力的主体被排除在外，参与渠道不畅；②政策覆盖面偏窄，部分困难对象没有纳入保障。
- **对齐**：齐·2025县镇 问题二，"被排除在外"『必答 7/7』。

### B04 政策悬空、落地走样
- **定义**：上级政策已经出了，执行单位没出细则、执行打折或者加码设限，政策停在纸面上。
- **判别规则**：上面"出台了 / 鼓励 / 要求"，下面"还没出台具体办法 / 实际执行中未能落地 / 约束性条件较多 / 政策稳定性不足"。
- **材料里常见的样子**：
  1. 「现在主要是政策落地的问题，部分高校和科研机构还没有及时出台具体实施办法」［2025省市卷 材料五〔7〕｜汇25 L108］
  2. 「“破四唯”的政策要求在实际执行中未能完全落地落实」［2024选调卷 材料四〔5〕｜汇24 L2368］
  3. 「有些高校对兼职、离岗创业创新等方面约束性条件较多、政策稳定性不足」［2024一卷 材料八〔7〕｜汇24 L176］
- **答题标准表述**：①配套细则缺位，政策落实"最后一公里"不畅；②政策执行打折扣，附加限制多，稳定性不足。
- **对齐**：齐·2025省市，"部分高校和科研机构未及时出台具体实施办法，四份都写进问题侧"『必答 4/4』；齐·2024一卷，"高校约束多 / 政策执行受限 / 执行不力"『必答 4/4』。

### B05 宣传传达不到位
- **定义**：该知道的人不知道。群众和企业不清楚政策、不知道怎么参与，一线干部没吃透；对外，好东西没人知道。
- **判别规则**：问询电话多 / "需不需要……？" / 不知道怎么参与 / 知道的人太少 / 知名度不高。品牌建设本身属主题层，这里只收"信息没传到"。
- **材料里常见的样子**：
  1. 「有个村民两个月前去过湖北，现在需不需要居家隔离？」［2020乡镇卷 材料二〔10〕｜汇20 L1106］
  2. 「但很多时候却不知道怎么参与」［2025县镇卷 材料四〔4〕｜汇25 L1130］
  3. 「知道的人太少了，有点可惜」［2021乡镇卷 材料三〔7〕，日记 2020-09-21｜汇21 L1154］
  4. 「但五田柚子在市外的知名度并不高」［2020乡镇卷 材料四〔20〕｜汇20 L1186］
- **答题标准表述**：①政策宣传解读不到位，群众和企业知晓度低，不知道怎么参与；②宣传推介不足，对外知名度不高。

### B06 钱不够、来源单一
- **定义**：建设或运行经费有缺口，而且基本靠一个口子（财政、上级专项、某项租金）。
- **判别规则**：经费缺口 / 没有专项资金 / 光靠…… / 正在找其他来源 / 资金匮乏 / 压力很大。
- **材料里常见的样子**：
  1. 「尽管上级部门有安排专项资金，但因地处偏僻，村集体经济不发达，经济基础薄弱，历史欠账较多，在建设经费上仍存在较大的缺口，村里压力非常大」［2024二卷 材料五〔10〕｜汇24 L1238］
  2. 「村里有加强规划的意思，但没有规划专项资金」［2024二卷 材料五〔7〕｜汇24 L1232］
  3. 「资金这方面，主要来源于村集体经济收入和乡贤捐赠。为保障积分制一直运行下去，我们正寻找其他资金来源渠道」［2023乡镇卷 材料三〔14〕，调研 2023-02-21｜汇23 L1224］
  4. 「以前光靠山林池场这些租金，村集体一年收入也就 1 万多，镇里急，我们也急」［2023乡镇卷 材料五〔4〕｜汇23 L1276］
  5. 「研发资金匮乏的短板需要金融活水的赋能」［2024一卷 材料八〔10〕｜汇24 L182］
- **答题标准表述**：①资金保障不足，建设（运行）经费缺口大；②资金来源单一，过度依赖财政和上级专项，难以持续。
- **对齐**：齐·2024二卷，"建设经费缺口"『必答 6/7』、"缺规划专项资金"『必答 5/7』；齐·2024一卷，"研发资金匮乏 / 缺口"『必答 3/4』。

### B07 成本高、回报慢
- **定义**：这件事的单位成本太高、见效太慢，单个主体算账不划算，所以不愿投、用不起、不愿管。
- **判别规则**：投入了多少万 / 成本太高 / 很难承受 / 过程漫长 / 收益不高就不愿投入 / 种得多赚得少 / 增加了成本。和 B06 的区别：B06 是没钱，B07 是有钱也不划算。
- **材料里常见的样子**：
  1. 「系统建设先后投入了 500 万」［2022乡镇卷 材料五〔11〕｜汇22 L1244］
  2. 「直接清退养殖塘，不仅成本太高，而且养殖户的生存出路也成问题」［2025选调卷 材料三〔12〕｜汇25 L2132］
  3. 「之前砍伐竹子的经济收益不高，大家不愿意过多投入管理」［2025县镇卷 材料四〔6〕｜汇25 L1134］
  4. 「这既拉长了物流时间，也增加了物流成本」［2020乡镇卷 材料四〔21〕｜汇20 L1188］
  5. 「研制创新药需要大量资源和研发资金持续投入，过程漫长，业内许多公司很难承受」［2024一卷 材料八〔9〕｜汇24 L180］
- **答题标准表述**：①投入大、成本高、回报周期长，经营主体不愿投、用不起；②经济效益偏低，持续投入的动力不足。

### B08 人手不够、覆盖不全
- **定义**：要管的面大、点多，执行力量跟不上，出现没巡到、没排到、联系不上的盲区。
- **判别规则**：辖区大 / 面积大、分布广 / 光靠干部排查不过来 / 力量不够 / 人都外出、联系核实慢 / 没巡到。
- **材料里常见的样子**：
  1. 「说到隐患排查，辖区这么大，总感觉我们力量有点不够，风险隐患光靠镇村干部哪里排查得过来」［2023乡镇卷 材料四〔17〕｜汇23 L1264］
  2. 「Z 市红树林保护区面积大、分布广，有众多的保护小区，监管难度大」［2025选调卷 材料三〔5〕｜汇25 L2118］
  3. 「很难想象仅靠有限的人力、物力而能高效地治理越来越庞大的城市」［2020县级卷 材料一〔4〕｜汇20 L44］
  4. 「河西村外出务工的人较多，联系核实花的时间多，进度会较慢」［2022乡镇卷 材料四〔8〕｜汇22 L1218］
  5. 「对这边地理环境不熟悉，可能没有巡到这里」［2021乡镇卷 材料五〔7〕，日记 2020-12-04｜汇21 L1190］
- **答题标准表述**：①基层工作力量薄弱，人手不足，点多面广，难以全覆盖；②巡查监管力量不够，存在盲区。

### B09 执行能力不足
- **定义**：执行方（干部、从业者、本地机构）会干的人少：缺专业人才，新手没培训，缺经验，不知道怎么推进。
- **判别规则**：缺乏专业……人才 / 人才很难招到 / 新来的没经过培训、操作不当 / 缺乏经验 / 没有成熟有效的办法 / 不知道怎么推进，需要上级指导 / 队伍数量不足、素质不高。如果是服务对象不会用，归 B10。
- **材料里常见的样子**：
  1. 「镇里缺乏专业的电商人才」［2020乡镇卷 材料四〔21〕｜汇20 L1188］
  2. 「特别是提取技术、炮制工艺等方面的人才很难招到」［2025县镇卷 材料四〔14〕｜汇25 L1150］
  3. 「由于新来的护林员还没经过培训，操作不当把仅有的两台风机弄坏了，没来得及修」［2021乡镇卷 材料五〔5〕，日记 2020-12-04｜汇21 L1186］
  4. 「自己还是太缺乏经验了」［2023乡镇卷 材料四〔6〕｜汇23 L1242］；「第二是之前没有封闭式管理经验，没有成熟有效的办法」［2020乡镇卷 材料二〔12〕｜汇20 L1110］
  5. 「也不知道怎么推进规划工作，非常需要上级指导支持」［2024二卷 材料五〔7〕｜汇24 L1232］；技术经理人「这支队伍数量不足、素质也不够高」［2025省市卷 材料五〔4〕｜汇25 L102］
- **答题标准表述**：①专业人才匮乏，本地技术和服务能力不足；②新上岗人员未经培训、经验不足，业务不熟。
- **对齐**：齐·2024二卷，"问题侧写成缺上级指导 5/7"『必答』；齐·2025省市，"技术经理人数量不足、素质不高"『必答 4/4』；齐·2021乡镇，"新护林员未培训 → 岗前培训"『弱共识』。

### B10 对象不会用
- **定义**：服务对象（农户、老人、小微主体）不会用、用不好新技术、新平台、新服务。
- **判别规则**：年纪偏大 / 受教育程度低 / 靠个人经验 / 普遍没有专业技术 / 触网烦恼 / 眼睛不好使。**年龄、学历是画像，不单列成问题条**。问题条写"技能弱、不会用"，画像的用处是提醒对策里必须有培训和手把手。本项目 2025 县镇卷问题二就是这样处理的：「市里改不了年纪也改不了学历，写进“存在问题”就配不出对应的对策」［答·2025县镇Q2 考场思路 L26，2025 卷］。
- **材料里常见的样子**：

  5. 「规模偏小，抗风险能力不强」［2024二卷 材料五〔4〕｜汇24 L1226］；「他们打工所在的厂订单锐减，无法确定复工时间」［2020乡镇卷 材料三〔1〕｜汇20 L1114］
- **答题标准表述**：①风险研判和预案准备不足，应急处置不及时；②抗自然灾害和市场波动的能力弱。
- **对齐**：齐·2024二卷，"抗风险能力不强 7/7"『必答』；齐·2023乡镇 问题四，"出动快、处置快"『有 n=1』。

### B22 一线保障不足
- **定义**：冲在一线的人（镇村干部、护林员、科研人员）防护不到位、负担过重、待遇和生活保障跟不上。
- **判别规则**：一线人员难以得到保护 / 物资省着用 / 工作多、杂、随时待命 / 收入低、生活压力大 / 条件艰苦。
- **材料里常见的样子**：
  1. 「第三是疫情防控初期防控物资稀缺，一线镇村干部难以得到有效保护」［2020乡镇卷 材料二〔12〕｜汇20 L1110］
  2. 「一天就一个口罩，得省着点用」［2020乡镇卷 材料二〔6〕｜汇20 L1098］
  3. 「感觉工作特别多特别杂，除了随时待命，还要不停地做防风、防汛、防寒、防火等各种‘防’的工作」［2023乡镇卷 材料四〔10〕｜汇23 L1250］
  4. 「青年科研人员收入水平相对较低，面临较大生活压力」［2024选调卷 材料四〔6〕｜汇24 L2370］
  5. 「我们在零下30°C 的北方实验场，没有热水，网络不好」［2024选调卷 材料六〔2〕｜汇24 L2384］
- **答题标准表述**：①一线人员防护和安全保障不到位；②基层任务重、负担重，待遇和生活保障跟不上。
- **本项目答案**：答·2020乡镇Q1 要点五「防控物资稀缺，一线干部难以得到有效保护」（2020 卷）。

### B23 利益受损有阻力
- **定义**：推进要拆、要占、要退、要改，碰到具体人的房、地、生计，补偿安置和利益平衡没做好，人家不配合。
- **判别规则**：要拆迁 / 要占用 / 要搬迁 / 几户不同意 / 不愿配合 / 生存出路成问题 / "阵痛"。
- **材料里常见的样子**：
  1. 「广场周围有几间房子要拆迁，几分田要占用，还有个小作坊要搬迁，这几户人家都不同意，一时很难解决」［2021乡镇卷 材料九〔3〕｜汇21 L1230］
  2. 「直接清退养殖塘，不仅成本太高，而且养殖户的生存出路也成问题」［2025选调卷 材料三〔12〕｜汇25 L2132］
  3. 「特别是东潮村的谢阿婆家不愿配合，而且她家撂荒的面积较大」［2022乡镇卷 材料四〔5〕｜汇22 L1212］
  4. 解法一侧反照出的问题：「最大程度减少改造的“阵痛”和清拆的“伤害”」［2021县级卷 材料四〔6〕｜汇21 L116］
- **答题标准表述**：①涉及群众切身利益，补偿安置和利益平衡不到位，推进阻力大；②没有兼顾相关群体的生计，群众配合意愿低。

### B24 资源闲置分散
- **定义**：有资源但闲着；各村、各主体各守一摊，地、钱、人配不到一起；经营主体小、散、弱，带不动。
- **判别规则**：闲置好久 / 废弃 / 想过利用但没利用起来 / 地多钱少、钱多地少、人多资源少 / 规模偏小、带动能力有限 / 模式简单 / 小而不强。
- **材料里常见的样子**：
  1. 「后来我们在清点村集体资产时，发现这几间厂房闲置了好久，于是清理好租了出去；还有一处废弃校舍，租给村民改造成特色民宿」［2023乡镇卷 材料五〔4〕｜汇23 L1276］
  2. 「我们村的地是不少，但资金短缺；塘尾村没有合适的养殖场地，不过比较有钱；羊角村没什么自然资源，劳动力比较多」［2023乡镇卷 材料五〔6〕｜汇23 L1280］
  3. 「服务带动周边片区农户的能力有限」［2024二卷 材料五〔4〕｜汇24 L1226］；「加工企业规模小而不强」［2025选调卷 材料四〔5〕｜汇25 L2156］
  4. 「此外，五田镇的柚子产业还是简单的“龙头企业+合作社+农户”」［2020乡镇卷 材料四〔21〕｜汇20 L1188］
- **答题标准表述**：①资源资产闲置，利用率低，没有转化为资产和收益；②经营主体小散弱、各自为战，缺乏整合联动。
- **对齐**：齐·2024二卷，对策侧"扩规模 / 集群 / 整合"『必答 5/7』。

### B25 规划滞后、要素紧
- **定义**：规划旧、不管用，地、海、林等要素卡住项目。
- **判别规则**：受到规划制约 / 规划是十多年前的 / 没有规划专项资金 / 土地已高强度开发 / 用地用海用林。
- **材料里常见的样子**：
  1. 「但土地使用、道路建设、产业布局等都受到规划制约，影响了工作进展」［2024二卷 材料五〔6〕｜汇24 L1230］
  2. 「村里的规划还是十多年前的一个简单规划。已经不能适应目前高质量发展要求」［2024二卷 材料五〔7〕｜汇24 L1232］
  3. 「40 年来，顺德区超过 50%的土地被高强度开发，远超国际公认 30%的警戒线」［2021县级卷 材料四〔1〕｜汇21 L106］
  4. 「加强项目用地用海用林、市政配套、环评审批、资金落实等方面统筹，确保重大项目按时落地实施」［报2019 L167，2019-02-02］
- **答题标准表述**：①规划滞后，不适应发展需要，制约项目布局；②用地（用海）等要素保障不足。

## 二、C 侧：执行层对策（25 条）

每条的"约束画像"分四栏：**消耗**（钱 / 人 / 地 / 技术 / 权限 / 时间，写主要的）｜**缺时替代**｜**可转化的富余**｜**一石多鸟**。替代路径尽量挂材料原句；标"通用"的是允许范围内没找到直接原句、按常识补的，用的时候自己掂量。

### C01 统筹牵头、压实责任
- **标准表述**：①建立部门联动协调机制，明确牵头部门和责任分工，定期研判调度，形成合力；②压实责任，对推诿失职严肃问责。
- **对应病根**：B01、B04、B14、B16
- **约束画像**
  - 消耗：权限（统筹调度权）、时间；基本不花钱。
  - 缺时替代：协调不动时，提请党委政府主要领导挂帅、列为头号工程，如「顺德区委果断将村级工业园改造定为“头号工程”」［2021县级卷 材料四〔5〕｜汇21 L114］；本级协调不了的向上反映，由上级对接，如「我们已经把这个情况跟县里反映了。县里对接了农产品流通企业、电商平台和物流渠道。」［2020乡镇卷 材料四〔12〕｜汇20 L1170］。缺人时从相关部门抽人组专班（通用）。
  - 可转化的富余：各部门手里已有的人、数据和项目资金，统筹打包，如「建立涉农资金统筹整合长效机制」［报2019 L139，2019-02-02］。
  - 一石多鸟：一次统筹同时减重复建设（省钱）、加快落地、补上信息断点。
- **引证**：「老张协调党政办、自然资源、农林水等部门负责人一起充分讨论了开展这项工作将会面临的困难、需要注意的事项，并提出每周定期研判推进情况和存在问题」［2022乡镇卷 材料四〔4〕｜汇22 L1210］；「每当企业遇到困难，当地党政领导都会召开现场办公会，推动制度和政策落实，为企业解决问题」［2025省市卷 材料八〔4〕｜汇25 L148］；「对典型案例以及重大事故隐患挂牌督办、依法查处、追责问责、公开曝光」［报2025 L117，2025-01-19］。

### C02 流程再造、一窗通办
- **标准表述**：①精简材料和环节，推行一窗受理、一网通办、"高效办成一件事"、告知承诺；②保留线下渠道，提供适老化服务和帮办代办。
- **对应病根**：B02、B01、B10、B25
- **约束画像**
  - 消耗：技术（平台）、权限（跨部门数据和审批权）；钱中等。
  - 缺时替代：缺平台先做线下一窗受理、内部流转，推行「推进项目审批告知承诺制」［报2020 L126，2020-01-19］；审批多头就整体办一次，如「全面推行养殖用海整体论证，实施海洋牧场项目“标准海”供应」［2025选调卷 材料二〔6〕｜汇25 L2090］；老人不会用就换简便方式，如「现在用身份证一刷健康码信息就有了」［2021县级卷 材料二〔3〕｜汇21 L64］、「“粤省事”平台上线全国首个移动端适老化老年人服务专区」［同卷 材料二〔2〕｜汇21 L62］。
  - 可转化的富余：已经沉淀的政务数据，如「这些数据每交换一次，可能就有 1 个市民少跑一次办事窗口，少盖一个章」［2020县级卷 材料一〔4〕｜汇20 L44］。
  - 一石多鸟：便民，减少基层重复录入，数据还能给 C19 用；遇到突发能快速上线新功能：「依托此前 4 年多的改革积累，才得以在短时间内上线多项功能」［2021县级卷 材料二〔15〕｜汇21 L88］。
- **引证**：「现在‘粤商码’就像企业的身份证，从工商、税务到社区，所有数据都在一个码里，基本上所有涉企业务，足不出户就能办理」［2021县级卷 材料二〔8〕｜汇21 L74］；「健全“高效办成一件事”重点事项清单管理机制和常态化推进机制」［报2025 L123，2025-01-19］。

### C03 放宽门槛、补齐兜底
- **标准表述**：①按能力而不是按身份设准入条件，支持有能力的企业和社会主体牵头或参与；②政策够不着的困难对象一户一策，落实低保、补贴等兜底，争取社会帮扶。
- **对应病根**：B03
- **约束画像**
  - 消耗：主要是权限（改规定），钱少。
  - 缺时替代：本级无权改规定的，向上反映、申请试点（通用）；兜底缺财政钱的，找社会力量，如「还可以试试和爱心企业联系，请求他们结对帮扶」［2020乡镇卷 材料五〔2〕｜汇20 L1194］、「现在有社会爱心人士帮助他们」［同卷 材料五〔5〕｜汇20 L1200］。
  - 可转化的富余：被挡在门外的主体自己的能力，如「事实上，当地不少企业都有一定的科研能力，也有开展农业科技的创新热情」［2025县镇卷 材料四〔4〕｜汇25 L1130］。
  - 一石多鸟：放开申报门槛，同时补上"研究力量不足"，也接住了企业的参与热情。
- **引证**：「放宽申报规定，支持企业牵头申报“揭榜挂帅”项目和专项资金」［答·2025县镇Q2 L13，2025 卷］；「落实低保、残疾人补贴，争取爱心人士帮助；协调在镇上安排住房，方便生活和上学」［答·2020乡镇Q4 L6，2020 卷］；「年薪制、协议工资制覆盖无“帽子”青年人才」［答·2024选调Q2 L10，2024 卷］。
- **对齐**：齐·2025县镇，"对策：让企业能牵头 / 参与申报"『必答 7/7』。

### C04 细化落实、督导到底
- **标准表述**：①督促指导相关单位结合实际及时出台实施细则，保持政策稳定，跟踪问效；②执行者先吃透政策，逐级传达到每个经办人。
- **对应病根**：B04、B05
- **约束画像**
  - 消耗：时间、权限。
  - 缺时替代：人手少时，拿先出台单位的办法当模板、以点带面（通用）；督导不能变成新负担：「严控面向基层的督查、检查、考核总量，切实为基层松绑减负」［报2025 L124，2025-01-19］。
  - 可转化的富余：上级已经出台的政策文件本身。
  - 一石多鸟：督导时顺带收集执行中的新问题。
- **引证**：「下一步，我们将加强督促和指导，推动他们及时出台相关规定」［2025省市卷 材料五〔7〕｜汇25 L108］；「及时把上级决策部署、工作传达给村干部，力求让每个干部都弄清楚」［2021乡镇卷 材料九〔4〕｜汇21 L1232］；「老张立马组织农办同志学习相关政策文件，掌握具体工作要求，认真梳理工作重点和工作难点」［2022乡镇卷 材料四〔3〕｜汇22 L1208］。
- **对齐**：齐·2025省市，"对策：督促指导 / 推动及时出台规定"『必答，合计 4/4』；齐·2024一卷，"对策：落实 / 统一执行 / 完善高校转化政策"『必答 4/4』。

### C05 精准宣传、上门做工作
- **标准表述**：①用群众听得懂、看得到的方式（方言、广播、短视频、顺口溜、上门讲）宣传解读政策，解疑答惑；②对心存顾虑的对象多次上门，借助亲属做工作。
- **对应病根**：B05、B11、B23
- **约束画像**
  - 消耗：人、时间；钱很少。
  - 缺时替代：缺人就用村支书、党员、乡村新闻官、志愿者，如「文明实践所的很多活动都是由志愿者服务队来开展的」［2022乡镇卷 材料一〔8〕｜汇22 L1156］；缺专业就请专家合作，如「唐书记还和农科院技术人员合作，拍摄了许多果木嫁接、花卉种植、病虫害防治等农业技术相关短视频」［2021乡镇卷 材料三〔6〕｜汇21 L1152］。
  - 可转化的富余：本地能人的影响力、亲属关系网、村规民约，如「村规民约已经编成了顺口溜，发到朋友圈了」［2021乡镇卷 材料三〔8〕｜汇21 L1156］。
  - 一石多鸟：乡村新闻官一套视频同时"促进农产品销售""推广农业技术""推介乡村旅游"［答·2021乡镇Q1 L6–L8，2021 卷］。
- **引证**：「悬挂着大量用方言写的横幅」［2020乡镇卷 材料二〔8〕｜汇20 L1102］；「于是，一边打电话做她几个孩子的思想工作，一边继续上门找谢阿婆。经过多次耐心沟通，谢阿婆终于同意让村里代耕撂荒耕地」［2022乡镇卷 材料四〔6〕｜汇22 L1214］；「也要加大宣传力度，为科研人员解疑答惑」［2025省市卷 材料五〔7〕｜汇25 L108］。
- **对齐**：齐·2025县镇，"对策：宣传引导、转变观念"『必答 6/7』；齐·2022乡镇，"做孩子的思想工作 → 发动家属协助劝说"『弱共识』。

### C06 示范带动、先试后推
- **标准表述**：①先选点试行，用看得见的效益做典型，以点带面；②党员干部带头参与，说到做到，对首批试行的给补贴。
- **对应病根**：B11、B13、B18
- **约束画像**
  - 消耗：时间（要等效益出来），少量钱（试点补贴）。
  - 缺时替代：缺钱用积分、荣誉代替现金（见 C15）；等不及就借用外地和身边的现成经验，如「后来我们去了解其他地方是怎么做的」［2023乡镇卷 材料三〔10〕｜汇23 L1216］、「我们村的老黄跟他情况差不多，人家现在种了 50 多亩柚子」［2020乡镇卷 材料五〔7〕｜汇20 L1204］。
  - 可转化的富余：已有的先行户和党员。
  - 一石多鸟：试点既验证方法（防 B18），又打消顾虑（B11）。
- **引证**：「把陈伯家品种改良的效益当作典型宣传，给试种农户补贴，在全镇推广种植新品种」［答·2022乡镇Q5 L5，2022 卷］；「有些村民和党员们一起参加了几次防电信诈骗宣传活动，每个人拿到 20 分，兑换了茶杯」「慢慢地大家都参与进来了」［2023乡镇卷 材料三〔9〕｜汇23 L1214］。

### C08 降本分摊、共享托管
- **标准表述**：①用政府补贴加规模化推广把单价降下来，让一般用户用得起；②推行设备共享和社会化托管服务，单户做不了的交给集中服务。
- **对应病根**：B07、B08、B10、B15
- **约束画像**

- **引证**：「当然，如果大面积推广，再加上政府补贴，单价自然会降低，一般农户也用得上」［2022乡镇卷 材料五〔11〕｜汇22 L1244］；「主打“保姆式”托管，可为种植水稻、玉米、辣椒、番薯的农户或农业经营主体提供农业生产单环节、多环节、全程托管等服务」［2024二卷 材料六〔9〕｜汇24 L1258］；「发展农业生产托管社会化服务」［报2024 L68，2024-01-27］。

### C09 利益联结、兼顾各方
- **标准表述**：①设计让受影响群体也能受益的方案，补偿安置方式多种可选；②吸纳当地群众参与、就业，按比例分成，把阻力变成参与力。

### C10 盘活闲置、抱团互补
- **标准表述**：①清点闲置资产和资源，通过出租、改造、入股盘活；②相邻村和各主体按各自优势出地、出钱、出力，联合经营，按比例分成，把规模做上去。

### C16 容错兜底、风险分担
- **标准表述**：①建立容错纠错和风险补偿机制，用好保障措施，消除后顾之忧；②推广保险，完善临时救助等兜底，出了损失及时理赔救助。

### C17 长效管护、以用养管
- **标准表述**：①建立长效管护机制，明确管护主体、责任和经费，设备定期检修；②建成的设施、整治的成果交给村集体或专业团队运营，用经营收入反哺管护。

- **对齐**：齐·2024二卷，"长效 / 常态化管理 7/7，各卷自拟"『必答』；齐·2021乡镇，"风机没修 → 及时检修"『弱共识』。

### C18 补齐设施、配足储备
- **标准表述**：①完善网络、道路、物流等基础设施和公共配套；②配足关键设备和应急物资，留有备用，一时紧缺的跨部门、跨区域调剂。

### C19 摸清底数、共享信息
- **标准表述**：①全面排查，逐户、逐地块核实，建立台账和动态监测；②打通部门和层级之间的数据端口，建统一的共享平台。
- **对应病根**：B16、B01
- **约束画像**

### C20 搭台对接、按需供给
- **标准表述**：①先摸清需求再供给，建立需求清单；②搭建供需对接平台（揭榜挂帅、科技特派员、农超和农企对接），让服务、成果、产品对准需要。

### C21 因地制宜、民主定规
- **标准表述**：①深入调研，征求群众意见，民主制定符合实际、可操作的方案和标准；②分类施策，不搞一刀切，不层层加码。

  - 一石多鸟：民主定规，既提高可行性，又增加群众认同；设计得好还能省钱，如「合理设计种养品种及其空间配置比例等，争取以最小的成本来实现效益的最大化」［2025选调卷 材料三〔13〕｜汇25 L2134］。

- **标准表述**：①政府、企业、学界合作制定标准，发挥行业协会自律作用；②规范操作程序，执行和监督分开，全过程公开，接受监督。

### C23 依法监管、联动治理
- **标准表述**：①依法依规执法，该责令整改的责令整改；②网格巡查、平台上报和信用约束结合，打击假冒，维护权益。
