> 条数：H 动作 25 个；Q 病根 20 个；L 作用链 20 条；省报事项 2025 年 58 项、2024 年 67 项。

## 使用说明

- A 侧（做法、表现）和 C 侧（对策）共用 H 池。材料里读到一个具体做法，先按“判别规则”落到某个 H 的某个形态，再用“做法腔”概括；题目要对策时，换成“对策腔”。一个做法可以挂两个 H，按主次写。
- B 侧只放主题层的卡点（这件事为什么难），流程手续、重建轻管、方法不科学、一线安全这类执行层问题不放。
- D 侧作用链写成“起点动作 → 中间机制 → 结果”。标“作文”的可以直接做分论点或论证链，标“小题”的用在意义、作用、成效、启示类题。
- “反推”：官方文件只写了对策、没有直接写问题的，从对策句倒推它要解决的卡点，标“反推”。
- 约束画像三栏：消耗——做这件事要花什么；换路——缺了这项资源怎么绕开；可转化——手里哪类富余资源能拿来用。

## 一、A/C 共用动作池（H01–H25）

### H01 关键核心技术攻关

- 一句话：把产业链上被“卡脖子”的技术点列成清单，集中力量、换组织方式去啃。
- 定义：政府统筹，企业、高校、院所联合，针对某项具体的芯片、软件、装备、零部件、材料等技术短板开展攻关，目标是自主可控或国产替代。
- 判别规则：材料里出现“攻关、突破、卡脖子、国产替代、打破国外垄断、揭榜挂帅、赛马、军令状、重大专项、新型举国体制、大兵团、项目经理人”，而且对象是一项具体技术或产品 → H01。对象是“从0到1”的科学问题 → H02；是把已有成果推向市场 → H05；讲的是“领军企业牵头组团”这种组织方式 → 同时挂 H04①。
- 常见形态：①重大科技专项和工程（“广东强芯”、核心软件攻关、“璀璨行动”、省重点领域研发计划、重大技术装备攻关）；②揭榜挂帅、赛马制、军令状、“一技一策”；③新型举国体制、“大兵团”作战、争取国家重大项目、联合港澳力量；④项目经理人制、“业主制”、“板块委托”等组织管理方式改革；⑤国产化替代攻坚和验证应用（仪器设备、操作系统、基础软件、零部件）。
- 标准表述：做法腔——聚焦“卡脖子”技术，实施重大科技专项，推行“揭榜挂帅”“赛马”等机制，集中力量突破一批关键核心技术。对策腔——要梳理产业链关键技术短板清单，采取“揭榜挂帅”“赛马制”等方式组织攻关，推动企业、高校、院所联合攻坚，加快实现自主可控。
- 约束画像：消耗——大额、长周期研发资金，顶尖团队，试错时间。换路——钱不够就省市联动、企业配资、揭榜分担；人不够就联合国家队和港澳力量、柔性引才；时间紧就先挑能快速突破的，战略性的提前部署。可转化——龙头企业的真实订单和应用需求、国家实验室和大装置的平台能力、港澳科研力量。
- 出处：

### H02 加强基础研究和原始创新

- 一句话：往源头投钱投人，把“卡脖子”背后的科学问题先搞清楚。
- 定义：面向前沿和产业底层原理的研究投入和组织，包括稳定投入、长周期评价、多元投入、从应用中提炼科学问题。
- 判别规则：出现“基础研究、原始创新、从0到1、源头创新、前沿研究、自由探索、长周期评价、稳定支持、联合基金、科学问题” → H02。讲实验室、大装置等“平台”本身 → H03；讲具体技术攻关 → H01。
- 常见形态：①十年“卓粤”计划、基础与应用基础研究重大项目；②1/3以上省科技专项资金投向基础研究，稳定支持和竞争性支持结合，长周期评价；③省市、省企联合基金，引导社会资金、捐赠多渠道投入；④从产业需求中凝练科学问题（市场导向的应用性基础研究）；⑤基础学科、交叉学科建设和拔尖人才培养（和 H16 交界）。
- 标准表述：做法腔——实施基础研究十年行动计划，将三分之一以上省级科技专项资金投向基础研究，建立稳定支持和长周期评价机制，推动更多“从0到1”的原创成果涌现。对策腔——要加大基础研究投入，完善稳定支持和竞争性支持相结合的投入机制，扩大联合基金规模、引导社会资金投入，从产业需求中凝练科学问题，从源头和底层解决关键技术问题。
- 约束画像：消耗——长期稳定的财政资金、能坐冷板凳的科研人才、大型科研平台。换路——财政有限就建联合基金，引企业和社会资金；评价周期短就改长周期、分类评价；本地力量弱就借国家实验室和港澳高校。可转化——企业研发投入、社会捐赠、高校学科积累。
- 出处：
  - 「深入实施十年“卓粤”计划，完善竞争性支持和稳定支持相结合的投入机制，持续将1/3以上的省科技创新战略专项资金投向基础研究。」〔10_选材因子/第三轮/01_成品/政府工作报告/政府工作报告_2025.md｜2025-01-15〕
  - 「完善稳定支持和长周期评价机制，扩大省市、省企联合基金规模，鼓励更多社会资金投入。」〔10_选材因子/第三轮/01_成品/政府工作报告/政府工作报告_2024.md｜2024-01-23〕
  - 「迫切需要我们加强基础研究，从源头和底层解决关键技术问题。」〔10_选材因子/溯源结果/页面快照/_cache_2024一卷/材料四_求是_加强基础研究实现高水平科技自立自强.txt｜2023-07-31〕

### H03 建设高能级创新平台

- 一句话：搭大平台，把分散的科研力量集中到能出大成果的载体上。
- 定义：建设和运营国家和省级实验室、重大科技基础设施、科学城、技术创新中心、制造业创新中心等科研和产业共性技术平台，并推动开放共享。
- 判别规则：出现“实验室、大科学装置、科学城、创新中心、研究院、新型研发机构、共建共享、平台开放” → H03。平台功能是中试、概念验证 → H05①；是产业园区 → H12。
- 常见形态：①国家实验室、省实验室、全国重点实验室；②重大科技基础设施建设和共建共管共享；③科学城、创新合作区联动（光明、松山湖、南沙科学城，河套、横琴）；④国家技术创新中心、制造业创新中心、产业创新中心、企业技术中心（每个集群至少一家）；⑤高水平大学、新型研发机构、高水平创新研究院。
- 标准表述：做法腔——高标准建设实验室体系和重大科技基础设施集群，布局一批制造业创新中心和技术创新中心，推动大科学装置共建共管共享。对策腔——要围绕重点产业集群布局一批技术创新中心、制造业创新中心等共性技术平台，推动重大科研设施和仪器向企业开放共享，让大平台产出大成果。
- 约束画像：消耗——巨额建设资金、土地、高端团队、运维费用。换路——自己建不起就争取国家布局、省部院合作、共建联合实验室；装置用不满就开放共享、按机时服务企业。可转化——大装置机时、高校实验室设备、龙头企业研发中心可以开放成公共平台。
- 出处：
  - 「推进大湾区国际科技创新中心、综合性国家科学中心建设，健全光明科学城、松山湖科学城、南沙科学城等联动发展机制，推动重大科技基础设施共建共管共享。」〔10_选材因子/第三轮/01_成品/政府工作报告/政府工作报告_2025.md｜2025-01-15〕
  - 「发挥鹏城、广州国家实验室引领作用，分类别推动省实验室建设，争取更多全国重点实验室在粤布局。」〔10_选材因子/第三轮/01_成品/政府工作报告/政府工作报告_2025.md｜2025-01-15〕
  - 「每个战略性产业集群至少建设一家省级技术创新中心、产业创新中心或制造业创新中心。」〔10_选材因子/第三轮/01_成品/政府工作报告/政府工作报告_2022.md｜2022-01-20〕

### H04 强化企业科技创新主体地位

- 一句话：让企业出题、牵头、出钱、用成果，科研围着企业需求转。
- 定义：推动项目、资金、人才、平台等创新资源向企业集聚，由企业特别是科技领军企业牵头组织产学研攻关，并对企业研发给予普惠支持。
- 判别规则：出现“企业牵头、创新联合体、企业出题、需求方出题科技界答题、企业研发中心、研发投入、研发费用加计扣除、高新技术企业、以企业为主的产学研合作” → H04。政府统一组织的重大专项 → H01；企业数量梯度培育 → H13。
- 常见形态：①科技领军企业牵头组建体系化、任务型创新联合体，牵头承担重大科技项目；②企业当“出题人”“答题人”“阅卷人”，“需求方出题、科技界答题”；③普惠支持：研发费用加计扣除、高新技术企业所得税优惠、高企树标提质；④企业主导的产学研深度融合，共建研发机构和企业技术中心；⑤国有企业科技创新机制、原创技术策源地、多元化投入和中长期激励。
- 标准表述：做法腔——支持科技领军企业牵头组建创新联合体，建立“企业出题、科研机构答题、市场阅卷”的项目形成机制，推动创新资源向企业集聚。对策腔——要强化企业科技创新主体地位，让企业在技术攻关中“唱主角”，落实研发费用加计扣除等普惠政策，推动企业主导的产学研深度融合。
- 约束画像：消耗——企业研发资金和人员、政府项目经费、高校院所的合作意愿。换路——中小企业无力自建研发就加入联合体、用共享平台、“先使用后付费”；企业不敢投就用加计扣除、补助、风险补偿降成本。可转化——龙头企业的市场需求和应用场景、高校院所闲置的成果和人员。
- 出处：
  - 「加强产学研深度融合，梯度培育创新型企业，支持科技领军企业牵头组建体系化、任务型的创新联合体。」〔10_选材因子/第三轮/01_成品/政府工作报告/政府工作报告_2025.md｜2025-01-15〕
  - 「发挥企业“出题人”“答题人”“阅卷人”作用，支持领军企业牵头承担重大科技项目。」〔10_选材因子/溯源结果/页面快照/_cache_2024一卷/材料二_省政府网_全省高质量发展大会聚焦产业科技.txt｜2024-02-19〕
  - 「要全力支持企业做创新的主角，推动创新资源向优质企业集聚，政产学研协同发力，攻克“卡脖子”技术，锻造“撒手锏”技术，研发更多“根技术”，让企业把腰杆子挺起来。」〔10_选材因子/溯源结果/母文件_2025.md｜2024-02-18〕

### H05 打通科技成果转化链条

- 一句话：给实验室成果搭桥，让它过验证、过中试、过放大，走进生产线。
- 定义：围绕“成果—验证—中试—产业化”各环节的平台、权益、交易和服务安排。
- 判别规则：出现“成果转化、产业化、概念验证、中试、小试、熟化、孵化、赋权、单列管理、尽职免责、专利许可、先使用后付费、技术转移、技术交易、沿途转化、临门一脚、最后一公里” → H05。给新产品找第一个用户或场景 → H06；知识产权保护维权 → H19。
- 常见形态：①概念验证中心、中试平台、中试验证平台（小批量试生产、工艺验证）；②职务科技成果赋权、单列管理、尽职免责、提高科研人员转化收益；③专利转化运用、盘活存量专利、“先使用后付费”许可给中小微企业；④技术交易市场、科技孵化育成体系、技术转移机构；⑤“有组织科研+有组织成果转化”、省内沿途转化。
- 标准表述：做法腔——布局建设概念验证中心和中试平台，深化职务科技成果赋权改革，推行“先使用后付费”许可，打通科技成果转化“最后一公里”。对策腔——要完善概念验证、中试验证平台体系，赋予科研人员职务成果所有权或长期使用权，建立尽职免责机制，盘活高校院所存量专利，推动更多成果在本地转化落地。
- 约束画像：消耗——中试场地、设备、用地和能耗指标、工程化人才、转化资金。换路——单个企业建不起中试线就建公共中试平台、按次服务；科研人员不敢转就赋权加尽职免责；中小企业买不起专利就先使用后付费。可转化——高校院所沉睡专利、闲置厂房改中试基地、科研人员的技术和时间。
- 出处：
  - 「推进粤港澳大湾区国家技术创新中心建设，布局一批概念验证中心和中试平台，打造“有组织科研+有组织成果转化”于一体的科技创新枢纽。」〔10_选材因子/第三轮/01_成品/政府工作报告/政府工作报告_2024.md｜2024-01-23〕

### H11 强链补链延链、提升产业链韧性

- 一句话：盯着一条链找断点、弱点，补上、加粗、拉长。
- 定义：以产业链为单位的组织和攻坚：链长制、链主带动、产业基础再造、强链工程、围绕断点补链招商。
- 判别规则：出现“链长、链主、产业链、供应链、补链强链延链、断链、配套、零部件、基础材料、工业母机、韧性、安全稳定、保链稳链” → H11。讲攻克链上某项技术 → 同时挂 H01；讲园区和集群 → H12。

### H13 优质企业梯度培育和大中小融通

- 一句话：大企业“顶天立地”、中小企业“铺天盖地”，一层层往上育。
- 定义：按企业成长阶段分层培育（个体户—小微—规上—专精特新—单项冠军—链主—领军），并推动大中小企业供需对接、协作融通。
- 判别规则：出现“专精特新、小巨人、单项冠军、链主、领军企业、小升规、个转企、上市培育、梯度培育、大中小融通、民营企业、国企重组” → H13。企业在研发上的主体作用 → H04。
- 常见形态：①“十百千万”：科技领军企业、链主企业、制造业单项冠军、专精特新；②“个转企、小升规、规转股、股上市”；③大中小企业融通协作（链主开放供应链、配套对接）；④国企战略性重组、打造现代产业链龙头，民营经济支持；⑤企业家培训、现代企业制度、企业家精神。
- 标准表述：做法腔——实施优质企业梯度培育计划，推动“个转企、小升规、规转股、股上市”，形成“链主”企业引领、单项冠军攻坚、专精特新筑基的发展格局。对策腔——要完善优质企业梯度培育体系，加强对中小企业创新支持，推动大中小企业融通发展，让“企业之树”汇聚成“产业之林”。

### H14 先进制造业和现代服务业融合

## 五、自评：最可能漏的方向

1. 执行层、微观层的做法。政策文件说的是省级抓手，腔调偏宏观。试卷材料如果写的是某个市、某个园区、某家企业的具体服务动作（专员上门、政策“免申即享”、平台共享仪器、校企“订单班”、“工业上楼”、共享工厂、科技特派员），判别规则能接住一部分，但做法腔要现场改写，容易丢细节分。
2. B 侧命中率。官方直认的问题少，20 个病根里有 7 个是“反推”。试卷问题题多半写成具体场景（企业说融资难、人才留不住、中试收费贵、数据不共享、政策兑现慢、平台建了没人用），其中一部分属于本次规则排除的执行层问题，这块最可能漏分。
3. 县镇和农业方向。科技产业融合落到县域、乡镇时，常见的是县域特色产业科技赋能、农业科技、农机和种业、农产品精深加工、专业镇数字化。本图谱只在 H12④、H23⑤ 带了一笔，农业科技基本没收。
