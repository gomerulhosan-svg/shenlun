# 2026省市卷 · 材料一清单句假说检验

题目：围绕"绿色发展是高质量发展的底色"写议论文（题干原话即材料一第三段首句）。

## 一、材料一清单句（逐字）

1. 清单句 A（第二段，"十五五"部署）："持续深入推进污染防治攻坚和生态系统优化，加快建设新型能源体系，积极稳妥推进和实现碳达峰，加快形成绿色生产生活方式。"（4 项）
2. 清单句 B（第三段，高质量发展定义）："高质量发展，就是能够很好满足人民日益增长的美好生活需要的发展，是体现新发展理念的发展，是创新成为第一动力、协调成为内生特点、绿色成为普遍形态、开放成为必由之路、共享成为根本目的的发展"（5 项，新发展理念）
3. 清单句 C（第三段末）："坚持把绿色低碳发展作为解决生态环境问题的治本之策，加快形成绿色生产方式和生活方式，厚植高质量发展的绿色底色"（3 项）
4. 次要：第一段"大力推动生态文明理论创新、实践创新、制度创新"（与材料对应性弱，判为背景句）。

## 二、盲预测（只凭清单句，未看任何答案）

以清单句 A 为骨架，用 B 的"满足人民美好生活需要"补一项：

| 预测分论点 | 来源 | 分配材料 |
|---|---|---|
| P1 污染防治+生态修复，筑牢绿色本底 | A 第1项 / C 第1项"治本之策" | 材料六（治水、矿山、红树林、生物多样性）；材料二第五段（污染防治数据） |
| P2 建设新型能源体系、发展绿色低碳产业，培育新动能 | A 第2、3项合并 | 材料四（淘汰落后产能、新能源产业）、材料五（零碳园区，绿电直连） |
| P3 形成绿色生产生活方式 | A 第4项 / C 第2项 | 材料三（绿色工厂＝生产方式）、材料八（碳中和全运会＝生活方式） |
| P4 回应群众对好环境的期待，增进民生福祉 | B 首句"满足人民日益增长的美好生活需要" | 材料七（J村、绿美点） |

- 开头结尾料：材料二（总书记广东考察讲话、美丽广东总述、2024 年成绩）。
- 困难：
  - A 的"积极稳妥推进和实现碳达峰"是半空项，没有独立材料撑，只能并进 P2（材料五零碳园区勉强沾边）。
  - 材料五是"问题—对策"型小题材料，放进议论文的哪一段不确定；可能只作 P2 的补充或"要破解难题"。
  - P4 不来自清单句 A，而来自清单句 B 的首句；B 的五大发展理念五项里只有"绿色""共享"有材料，其余三项（创新、协调、开放）是空项——若按 B 拆会失败。
  - 材料七题眼句"推动绿色发展是满足人民日益增长的优美生态环境需要的必然要求"，更像是材料自带的分论点句，而非从材料一推出。

## 四、判定：【部分成立】（偏向成立）

- 盲预测的 4 个方向（生态治理、产业/能源、绿色生活方式、民生）与高分卷的主流四分法（产业—生态—民生—生活方式）基本一一对上：多数四段卷命中 3 个"一致"＋1 个"部分一致"。
- 但 4 个方向里只有 3 个真正来自材料一清单句 A（污染防治攻坚→生态；新型能源体系→产业/能源；绿色生产生活方式→生活方式）；"民生"一项来自清单句 B 的首句，更直接地来自材料七自己的首句。清单句 A 的"碳达峰"是空项，"生产"方式一半被产业段吸收。
- 高分卷的实际操作是"材料四、六、七、八一则一段＋段首用该则首句的判断句"，顺序是产业在先，不按清单句 A 的顺序；只有 83 分（p4-7）一份的开头预告几乎就是清单句 A 的改写。
- 我的材料分配有两处偏：把材料三放进"生产生活方式"，把材料五放进"产业"，而高分卷几乎不用这两则小题料（三偶作产业例子）；"生产生活方式"段实际只靠材料八。
- 结论：这张卷上清单句是一个好用的"方向校验器"，但真正决定段落的是"大作文专用材料各一则＋其首句"。
