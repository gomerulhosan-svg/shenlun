# 2023县级 · 材料一清单句假说检验

作文题：围绕"把广东制造业这份厚实家当做优做强"，自拟题目，写策论文（800–1000字）。

## 一、材料一清单句（逐字）

材料一没有典型的"坚持……植根……顺应……"式多项部署清单，只有下面几句带并列结构的话：

1. "关键在于推动高质量发展的谋划、担当与作为。"（三项，但都是态度词，是空项）
2. "坚持制造业当家，高水平谋划推进现代化产业体系建设，把制造业这份厚实家当做优做强，在新的高度挺起广东现代化建设的'脊梁'。"（省委全会；第三项就是题干主题，是自指，不能拆出分论点）
3. "广东要把推动制造业高质量发展摆在必争必胜的关键地位，以制造业高质量发展承载时代机遇、履行时代担当。"（定位句，没有可拆的项）

其他材料里的清单式或统领句（因为材料一不够用，所以补找）：

- 材料二末段（专家的问题清单）："关键核心技术受制于人的局面尚未根本改变，破解'卡脖子'问题需要继续努力，资源要素配置协同亟待优化，产业基础能力有待进一步提高。"
- 材料三首句："制造业当家，质量是基础。"
- 材料四首句："追求质量、打造品牌，擦亮广东制造金字招牌，是广东制造的优良传统。"
- 材料五首段："以培育战略性产业集群为牵引，推进产业链补链、延链、固链、强链，促进数字经济和实体经济深度融合"
- 材料六："科技是第一生产力、人才是第一资源、创新是第一动力。"
- 材料八："以深汕特别合作区为代表的大平台，是广东推进区域协调发展和制造业高质量发展的重要支点。"
- 材料九末句："推动有为政府和有效市场'双向奔赴'"

## 二、盲预测（只根据清单句）

严格只用材料一：句 2 拆出来的"现代化产业体系"算一项，其余全是空项或自指，**材料一最多给一个分论点（产业体系/集群）**。要凑出 3–5 个分论点，必须转用材料二末段专家的问题清单（三项：核心技术、资源要素配置协同、产业基础能力），再加上各则材料的首句。

预测分论点：
1. 夯实质量品牌基础，筑牢产业基础能力（对应材料二"产业基础能力"、材料三首句、材料四首句）
2. 以集群化、数字化建设现代化产业体系（对应材料一句 2 的"现代化产业体系"、材料五首段）
3. 攻关核心技术，强化创新和人才支撑（对应材料二"卡脖子"、材料六"第一生产力/资源/动力"；材料七青年人才也可以放这里）
4. 优化资源要素配置：区域协同＋营商环境（对应材料二"资源要素配置协同"、材料八、材料九）

材料分配：
| 材料 | 分配 |
|---|---|
| 材料二 | 开头料（发展历程）＋问题清单，用作全文骨架来源 |
| 材料三 | 分论点 1（质量） |
| 材料四 | 分论点 1（品牌），也可能独立成段 |
| 材料五 | 分论点 2（集群、数字化） |
| 材料六 | 分论点 3（科技创新、金融、知识产权、人才） |
| 材料七 | 分论点 3（人才），也可能独立成"人才"段 |
| 材料八 | 分论点 4（区域协调、大平台） |
| 材料九 | 分论点 4（营商环境），也可能独立成段 |

困难：
- 材料一的清单句几乎都是空项：句 1 三项全空，句 2 三项里一项自指题干、一项只是"坚持"。只靠材料一，能落地的只有"现代化产业体系"这一个方向。
- 材料三到九每则开头都有自己的主题句（质量、品牌、集群、创新、人才、区域、环境），数量是 7 个，多于 5，得两两合并；合并方式（质量＋品牌？人才单列？区域＋环境？）清单句决定不了。
- 真正能当骨架的是材料二专家的问题清单，但它是"问题"不是"部署"，也不在材料一。

## 四、判定：【不成立】

材料一只有态度词（"谋划、担当与作为"）和自指题干的一句（"坚持制造业当家……做优做强"），能拆出的具体项只有"现代化产业体系"一个，而四份高分卷没有一份拿它当分论点。四份高分卷的骨架都是**按材料顺序一则（或两则）一段**：质量（三）、品牌（四）、集群（五）、创新（六）、人才（七）、区域（八）、环境（九），分歧只在怎么合并。真正起"清单"作用的是**材料二末段专家的问题清单**（核心技术／资源要素配置协同／产业基础能力），四份卷都在开头引了它，84.5 分那份还专门给它写了一段；不过它只用来定靶子，并不按项拆分论点。我的盲预测命中率不低（4 个预测里 3 个基本对上），但那是靠材料三到九的首句和材料二的问题清单得来的，**不是靠材料一**。
