                    <p class="f_center"><img src="https://nimg.ws.126.net/?url=http%3A%2F%2Fdingyue.ws.126.net%2F2019%2F05%2F17%2Fe53b7805a5684d61b852007d05f21103.jpeg&thumbnail=660x2147483647&quality=80&type=jpg"/><br/></p><p>5月17日上午，“中华民族文化创意产品设计大赛”在文博会主场馆深圳会展中心的非遗馆开赛，面向广大公众征集优秀文化创意设计作品。</p><p>作为第十五届文博会的重要活动之一，该大赛由广东省少数民族文化创意产业协会、澳门中华民族文创学会主办，深圳市金雅福设计创意有限公司承办。</p><p><strong>多方助力创意产品设计大赛</strong></p><p>广东省少数民族文化创意产业协会会长肖俊华，澳门中华民族文创学会理事长丁潇，广东省少数民族文化创意产业协会顾问、金雅福集团董事长黄仕坤，鼎翰文化总经理黄新，广州利美文化科技有限公司总经理杜志国，连山壮族瑶族自治县壮瑶风采文化发展有限责任公司总经理钱清华，连南瑶族自治县名瑶工艺坊创始人唐买社吊，连南醉美瑶绣坊传承人房春花等出席，为此次大赛剪彩。</p><p class="f_center"><img src="https://nimg.ws.126.net/?url=http%3A%2F%2Fdingyue.ws.126.net%2F2019%2F05%2F17%2F5599f8cde61242f880092bd47a9a5771.jpeg&thumbnail=660x2147483647&quality=80&type=jpg"/><br/></p><p>在致辞中，广东省少数民族文化创意产业协会会长肖俊华表示，广东省少数民族文化创意产业协会的宗旨是开展与民族文化相关的业务咨询、政策研究、会员交流等活动，进一步弘扬中华民族文化。而举办本次比赛，则意在借助文化产品推广少数民族特色文化，着力打造一批富有少数民族特色元素的标识性品牌文创产品。</p><p class="f_center"><img src="https://nimg.ws.126.net/?url=http%3A%2F%2Fdingyue.ws.126.net%2F2019%2F05%2F17%2Fdf2632c878e6406d8a1c36b0cd40be39.jpeg&thumbnail=660x2147483647&quality=80&type=jpg"/><br/></p><p><strong>大赛意在引发文创产品设计风潮</strong></p><p>据介绍，大赛将结合全国各地的优秀创意设计人才资源、先进的生产工艺技术，立足于中国各民族传统的优秀文化资源、非物质文化遗产技艺、山地旅游资源等，以“实用性、时尚性、创意性、文化性”等设计理念，引发标识性文创产品设计新风潮。</p><p class="f_center"><img src="https://nimg.ws.126.net/?url=http%3A%2F%2Fdingyue.ws.126.net%2F2019%2F05%2F17%2F4dc14dee2f3e40cfb2281381cf3252ca.jpeg&thumbnail=660x2147483647&quality=80&type=jpg"/><br/></p><p>广东省少数民族文化创意产业协会秘书长苏沫琪（左一）介绍本次大赛的参赛要求及活动情况。<br/></p><p>作品征集内容包括旅游商品及产品设计、特产产品包装设计、民族服饰设计三大类别。其中，旅游商品及产品设计类包括银饰、蜡染、刺绣、竹器、玉石、木器、书法、剪纸、布艺、玩具、玉器、木器、银器、刺绣、茶具、手工制品等文化旅游纪念工艺品，特产产品包装设计类包括水果、农产品、山地特产、小吃、茶等特产品种。</p><p>大赛以团队或个人为参赛单位，参赛对象可以是文化创意机构、品牌设计公司、民间手工艺创作公司，也可以是国内外院校、独立设计师等等。大赛将邀请国内外创意设计领域知名专家、学者及设计大师担当专业评审。</p><p><strong>未来还将举办民族文创产业发展论坛</strong></p><p>承办方金雅福集团表示，本次大赛只是开端，未来还将陆续开展作品评审、获奖公示及作品展览、系列峰会论坛暨颁奖晚会、产业化培训扶持等系列活动，全面展示和培育一批富有民族特色的文化创意成果。</p><p class="f_center"><img src="https://nimg.ws.126.net/?url=http%3A%2F%2Fdingyue.ws.126.net%2F2019%2F05%2F17%2Fee234fa67fe94896b6970e82868ae791.jpeg&thumbnail=660x2147483647&quality=80&type=jpg"/><br/></p><p>其中，民族文创产业发展论坛将以“传承文化、创新发展”为宗旨，届时将邀请国内外知名专家、学者围绕民族文化资源的价值转换与民族文化创意产业发展等热点议题展开深入探讨，助力文化创意产业扬帆远航。</p><p>大赛获奖的优秀作品将在国内各民族院校、产业园及澳门等地进行巡展，让更多人了解传统民族文化与现代设计工艺结合诞生的文化创意成果。大赛获奖作品，可入驻澳门金沙城中心的创意廊进行展示与销售。</p><p>深圳晚报 记者易芬 通讯员 范建华 文/图</p>

  function getOffset(el) {
    var rect = el.getBoundingClientRect()
    return {
      left: rect.left + window.pageXOffset,
      top: rect.top + window.pageYOffset,
      width: Math.round(rect.width),
      height: Math.round(rect.height),
    }
  }

      return false
    }
