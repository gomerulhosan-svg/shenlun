### （二）第 8 号会话的通道实测

#### 本轮可用的检索通道

> 本节按主会话要求单列。会话2 本轮也在用其中第 1 条通道，两边独立记录可交叉验证。**要点：这两条通道都不消耗 WebSearch 配额**，本会话的 WebSearch 在约第 10 次调用时即报「已用满 200/200」——说明该计数器是**会话级共享**的，不是每会话一份。所以本轮的全部检索量实际是靠下面两条通道撑起来的。

#### 通道一：360搜索（so.com）——本轮最高价值发现

**URL 模板**

```
https://www.so.com/s?q=<urlencoded 查询词>[&pn=<页码>]
```

- `q` 用标准 URL 编码即可（Python 里 `urllib.parse.quote(q)`）。**不要手工编码**——我一开始手写 `%E6%8D%82`（「捂」）而不是「撂」，导致查询词错误、返回 0 结果。
- `pn` 从第 2 页开始带（`pn=2` 即第二页），首页不用带。
- **不需要 Referer，不需要 Cookie，不需要登录**。普通浏览器 UA 即可（本项目 `_tools/fetch.py` 的默认头就够）。
- 请求间隔无特殊要求，本轮未做限速。

**怎么解析返回**

返回是普通 HTML，一条结果 = 一个 `<li class="res-list" ...>`。按它切分：

```python
blocks = re.split(r'<li class="res-list"', raw)[1:]
for b in blocks:
    real_url = re.search(r'data-mdurl="([^"]+)"', b)      # 真实目标 URL（必须用这个）
    title    = re.search(r'<h3[^>]*>(.*?)</h3>', b, re.S) # 标题
    snippet  = re.search(r'<p class="res-desc"[^>]*>(.*?)</p>', b, re.S)  # 摘要片段
```

两个坑：
1. **不要取 `<a href=...>`**——那是 360 自己的跳转链接，不是目标 URL。真实 URL 只在 `data-mdurl="…"` 属性里。
2. `<h3>` 和 `res-desc` 里含标签，取出后要去标签 + `html.unescape`。

**有没有被拦或降级：没有。**

本轮在 360 上跑了 **约 35—40 条查询**（含分页），**全程没有出现验证码，没有被限速，结果质量没有降级**。这一点是本轮和其余通道的关键差别。作为对照，本机同一出口 IP 上的其他通道状况是：

#### 通道二：南方农村报站内全文检索（nfncb.cn）

**URL 模板**

```
https://www.nfncb.cn/s.html?q=<urlencoded>[&fulltext=1][&page=<页码>]
```

- `fulltext=1` 是**全文检索**（默认也是全文），`fulltext=0` 是标题检索。做溯源一律用 `fulltext=1`。
- 页码参数是 `page=N`（第 2 页起带）。**注意是 `page` 不是 `pn`**，和 360 不一样。
- 同样不需要 Referer / Cookie。

**怎么解析返回**

- 结果条数：`re.search(r'为您找到约\s*(\d+)\s*条结果', raw)`。
- 结果列表在 `<dl class="result-list">` 里（**用 `raw.rfind` 取最后一个**，前面还有导航的同名元素）。
- 条目链接形如：`https://www.nfncb.cn/a<数字>/<数字>.html`。

```python
j = raw.rfind('<dl class="result-list">')
for a in re.finditer(r'<a href="(https://www\.nfncb\.cn/a\d+/\d+\.html)"[^>]*>(.*?)</a>', raw[j:], re.S): ...
```

**正文怎么取（这是本条通道最大的坑）**

南方农村报的文章页**不能用普通「转纯文本」的方式取正文**——`to_text` 出来的只有导航和页脚，正文全丢。必须**从原始 HTML 里按 `article-content` 标记切片**：

```python
i = raw.find('article-content')
seg = raw[i:i+60000]
seg = re.sub(r'<script.*?</script>', '', seg, flags=re.S)
seg = re.sub(r'<style.*?</style>', '', seg, flags=re.S)
seg = seg.split('相关阅读')[0]          # 切掉尾部相关阅读
txt = html.unescape(re.sub(r'<[^>]+>', '\n', seg))
```

**有没有被拦或降级：没有。** 本轮跑了 **约 25 条全文检索**（`撂荒 复耕`、`龙眼`、`龙眼蜜`、`土炉 龙眼`、`百香果 深加工`、`农超对接`、`土特产 直播` 等），无验证码、无限速。站内共 40+ 条撂荒复耕报道、数十条龙眼/百香果报道，**但无一条对应本会话 20 段中任何一段**。

**这一条通道的价值**：它解决了交付件第六节自陈的一个缺口——早先 `nfncb_*.txt` 那批快照是空壳，本轮确认南方农村报的站内全文检索**是可用的**，且 `_cache_2022乡镇/nfncb2_百香果_寒潮.txt`（其他会话所存）里就是真实的检索结果，可作为通道可用性的旁证。
