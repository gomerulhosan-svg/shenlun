```
    _核对/抽查_链接核验.md        链接逐条回访的记录
```

## 三个脚本

```
python3 _tools/fetch.py <url> --save out.txt     # 抓页面转纯文本
python3 _tools/fetch.py <url> --check "整段原文"  # 逐字核对，打印 FOUND / NOT_FOUND
python3 _tools/build_parts.py                    # 从 _cache 生成 _parts 骨架
python3 _tools/finalize.py                       # 填判断项，合成 溯源结果_2025省市.md
python3 _tools/build_mu.py                       # 合成 母文件_2025.md
python3 _tools/spotcheck.py                      # 回访所有链接，写 _核对/抽查_链接核验.md
```

`finalize.py` 会先重建 `_parts` 再填判断项，所以可以反复跑，不会越堆越多。
判断项（对应程度、匿名对象识别、补充来源）写在 `finalize.py` 顶部的 `JUDGE` 和 `MANUAL` 两张表里。

**原文一律由脚本从 `_cache/` 拷贝，不经过人手转写**——这是这次唯一保证「逐字」的办法。
`国内模型提示词.md` 里写明不用 WebFetch，原因就在这：WebFetch 会以版权为由拒绝逐字转载正文，
只给摘要；而摘要不能当原文贴。抓原始 HTML 自己转文本，才能做到一个字一个字比对。
