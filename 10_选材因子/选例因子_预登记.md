# 选例因子检验：预登记

2026-09-28 写，在看任何结果之前提交。检验跑完后，结论写在 `选例因子检验.md`，按这里的标准判，不改标准。

## 一、要检验的想法（用户提出）

- 一个目标有很多方案，但不是每个方案都可行。
  - 有条件约束：缺钱、缺人、缺地……
  - 有些资源反而是富余的，可以转化；
  - 也可能有别的因素。
- 往年材料里一个观点只配有限几个例子。这些例子为什么被选出来？可能因为：
  - 做得出彩；
  - 有借鉴意义，别的县市能复刻；
  - 一石多鸟，一个办法同时打到几个目标。
- **用途**：不是给答案里的方案排权重（该列的照样列），而是在编写核心方案、挑例子的时候考虑这些。具体指三件事：
  - 出"壳"训练题；
  - 出仿真卷材料；
  - 选作文论据。

## 二、检验办法

**对比对象。** 同一篇来源报道里，被命题人选进材料的段，对比没被选的段。
- 底表脚本：`10_选材因子/tools/select_pairs.py`；
- 范围：10 套省级卷，2022 县级到 2026 县镇，不含乡镇卷和 2024 三卷；
- 规模：来源文章 136 篇，约 3900 段。

**盲标。**
- 标注员只看到段落原文和这套卷的主题，看不到哪段被选、看不到卷面材料。
- 先由一人从段落里切出"例子"（具体主体＋做法＋结果），并标注；另一人独立再标一遍，算一致率。

**特征。**

| 特征 | 怎么判 |
|---|---|
| 出彩（显式） | 文中写了"首个""首创""率先""第一""唯一""标杆""领先"或国家级荣誉 |
| 出彩（实质） | 0–2，标注员判断 |
| 可复制（显式） | 文中写了经验推广、入选典型案例、写进文件、多地学习、"可复制可推广" |
| 可复制（实质） | 0–2，一般县市在普通条件下能不能照做 |
| 依赖独特禀赋 | 靠特大城市财力、独有资源、国家级平台、巨额投资 |
| 一石多鸟 | 文中写出几类不同的收益：经济、生态、民生、治理、文化、安全、科技 |
| 资源转化 | 把闲置、富余、劣势的资源变成价值 |
| 约束突破 | 明确在缺钱、缺人、缺地、缺技术的条件下想办法 |
| 对照项 | 有量化成效、有人物引语、讲了难点、新事物、主题贴合度 0–2；段长和段在文中的位置由脚本算 |

## 三、预先写下的假设和判定标准

| 编号 | 假设 | 支持的标准 |
|---|---|---|
| H1 | 被选的例子更"出彩" | 在同一篇文章内比较时，被选例子的出彩率高出没被选的；且在主题贴合度 = 2 的例子里仍然成立 |
| H2 | 被选的例子更"可复制"、更少依赖独特禀赋 | 同上，看可复制（实质）和依赖独特禀赋两项 |
| H3 | 被选的例子更"一石多鸟" | 同上，看收益类数 |
| H4 | 被选的例子更多"资源转化"或"约束突破" | 同上 |

**共同标准。**
- 统计：用文章内置换检验（只在同一篇文章里打乱"选用"标签），p < 0.05；
- 效应：差值要到 10 个百分点以上才算"有实际意义"；
- 一致率：两位标注员对这项特征的一致率不到 0.4（kappa），这一项就不下结论；
- 结论分级：【实证】【较强推断】【弱推断】【假说】【已否定】。

**预先想到的混杂，报告里必须检查：**
- 被选段更贴主题；
- 被选段更长、更靠前；
- 被选段更常带数字和引语（命题人要"好改写的材料"，未必是因为出彩）；
- 来源文章误判：只共用套话的文件被当成来源；
- 2024 一卷和二卷共用问题一材料，2026 省市卷和县镇卷共用问题一材料，同一段不能算两次。

## 四、不管结果如何都会做的

- 结果写进 `选例因子检验.md`，支持和不支持都照写。
- 支持的特征，写进出壳、出卷、选论据的规则。
- 不支持的特征，不当成规则用；可以作为"看起来合理但没有数据支持"的备注。
- "条件约束"这一半，数据里只能看出例子有没有写约束。能不能用于"核心方案"的写法，作为设计写进本质动作图谱：
  - 给每个动作标"约束画像"：要不要钱、人、地、技术，能转化哪类富余资源；
  - 训练时出"同一目标、不同约束"的变式题。
