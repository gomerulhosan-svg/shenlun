# 第一阶段独立判断（未读取两份方法时固定）

> 阶段记录：本文封存读取两份方法之前的独立观察，保留当时的“初步”“未读”等时态。后续自主取舍与最终训练建议以[《我的六套写法》](我的六套写法.md)、[《方法逐条复核》](方法逐条复核.md)及[审查入口](README.md)为准；不以本记录覆盖后续结论。

核验：远程分支 claude/relaxed-keller-4ohjye 的树 SHA df26c14046b8a1003bcf7d768d485fa235145a29；本地六份指定真题和高分合集的 Git blob SHA 全部与该树一致。页码均为 PDF 物理页，正文印刷页 = 物理页 - 3。

1. 来源不能三选一。材料提供内容、方向、意义词和案例；题干界定主题及要证明的关系；考生把二者组合成论点。直接摘取可用（24二83.5首篇p128–129，材料3一个段落三个意义）；概括或合并可用（25二86.5材料吗喽p88–89，6和7合为人才、8合为文化组织）；近原句补题干词可用（26一84.5摸鱼p18，材料4/6/7/8）；自主修辞可用（25二89找个事干干p97的流量系列，只有提纲）。不能证明哪种写法本身得分更高。
2. 扣题是全文及段落的论证关系，不等于段首词面A+B。24二83p138–139段首不写百千万/高质量发展，段内明确落到县域发展、共同富裕、公共服务、要素流动。25二86.5p88–89能从产业说明基础设施/生态保护动机、就业吸引人才、收入支持公共文化；26一83宽宽p29–30解释生态根基、产业动能、民生目的。26二89.5p50–51按民生与长远两条展开。直接写两大题干方面亦可，高分不以四点为必要条件。
3. 题型辨识在链条之前。24一围绕高水平科技自立自强，82分p119–120三个“要”均是路径；25一创新主题可按科技/产业/体制拆维度（85+Ha p85–86）；25二产业是乡村振兴关键需保持产业向其他振兴方向；26二需同时覆盖长远和民生，不能漏一头。
4. 小题：按问法取信息；提炼动作/对象/机制；同义合并但保留功能区别；问题要识别成因；对策从明确建议、反推障碍及有材料支持的具体化三处来。例25一82 XYXG p81–82不只写“评价不完善”，保留转化纳入、权重、收益；25二89 p96从竹林运输不便推出基础设施且分清机械与道路；26二90 p44–45按环境能源产品办公原料归类；26一84.5 p17对考核、绿电、服务商、规划各有针对性动作。
5. 不能推出一般考生普遍做不到：没有普通分对照组、分题成绩或官方阅卷评分。可说可迁移能力是准确选材料、按题重组、补中间机制、在字数内覆盖不同要点。高分也存在失误，不把每句话都标准化。例25一82 p84结尾未完，p82考场答案和复盘答案不同；26二p63为了四点惯性硬加第三总结点；不能模仿这些弱点。
6. 样本可靠性：合集排版回忆/提纲混合，非原答卷扫描；分数为合集标签总分。26二p44–49两条90分高度近似不可作独立统计；p41/p45/p48错贴市卷题干，归属以原题正文核对。25一80 p76–77求是拓展非考场正文。
7. 训练初步建议（未看方法）：保留分论点与小题主线，链条在材料上取证、不凭空制造；不要强制四点；每组分论点还需至少展开一个完整论证段，避免只会列点；小题练漏点/并点/具体化+200/300字压缩；需限时成篇和整卷检验，不能只做局部。
