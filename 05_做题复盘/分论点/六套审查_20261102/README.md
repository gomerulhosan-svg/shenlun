## 主要判断

**备考重点基本对，作文训练单位需要从“四句分论点”升级为“有材料依据的分论点，加一段能把关系讲清的论证”。**

1. **分论点来源不是抄材料、用题干、自己写三选一。** 材料供内容，题干定任务，考生做选择、组合和表达。2024二卷83.5分《全面实施“百千万工程”推动广东高质量发展》的三句几乎直接摘自材料3；2026省市84.5分“摸鱼养老等退休momo”的生产方式段则跨材料4不同段落拼接。（PDF物理128—129页、18页）
2. **扣题是完整关系成立，不是每句必须复现同一终点词。** 2024二卷83分写“畅通要素流通，助力城乡一体化发展”，段内再接高质量发展；2025省市82.5分与85+分把高质量发展作为落点，题干及材料支持创新—新质生产力—高质量发展的联系。因此不能仅按词面认定“停在半路”或“修过站”。（PDF139页第4个分论段；79—80页；85—86页）
3. **A→B值得保留，但应补中间机制。** 2025县镇86.5分的文化段写产业收益增长、文化投入条件、公共文化空间与民俗活动，才落到文化振兴。用一个“促进”连接两个名词还没有完成这一解释。（PDF89页文化与组织段；真题材料8）
4. **小题练找全、归并、保留实义、针对原因提措施。** 例如2024二卷83.5分从“整治后平时没人管”提常态化监督；2025县镇89分同时处理砍竹缺机械和交通条件；2026县镇82.5分用后文“保护性破坏”概括前文围栏、铺砖等现象。（PDF132页第二题第1点；96页第二题第3点；40—41页第二题第5点）
5. **高分出现过，不等于我推荐照搬。** 2024一卷82分“创新驱动发展战略”分点过宽，与基础研究有包容；2025县镇90分的组织段从组织带动产业转到产业加强组织，仍需补中间机制。训练要根据题干、事实、推理和篇幅自主判断，不能把分数当成逐句正确性的证明。（PDF119—120页第2、3个分论段；101页组织段）

## 方法调整

- 保留：先认题干任务、核对A/B、兼顾双落点、从材料抽取与压缩、给分论点分配证据。
- 调整：先定关系与证据，再选句式；不把统一换宾语当成完成扣题；不硬性规定四段；不凭空承诺重复或抢材料“不伤分”。
- 补上：每点写明材料在哪里、通过什么过程起作用、与其他段分别证明什么；每组分论点至少展开最难的一段，并持续用完整作文和限时整卷检验。
- 分清：组成关系不等于因果关系。人才振兴属于乡村振兴，并不能代替“产业创造岗位和事业平台，从而吸引人才”的证明。

训练要求可以比样本更严格。例如优先在段首或段内明确回题，便于检查。但这是一种降低失误的练习设计，不能冒充“未写题干原词就必然失分”的评分规律。

## 五周训练安排

六套题均为概括类20分、问题对策30分、大作文50分。继续以这三部分为主，按个人可用时间和完成速度调整投入。

| 阶段 | 主要产出 | 核验重点 |
|---|---|---|
| 前两周 | 六套完成一轮分论点与最难一段，配对应小题 | 关系方向、漏点、空泛概括；每个判断标材料依据。 |
| 第3—4周 | 将局部练习接到完整作文和限时整卷；可每周安排1—2套 | 分论点是否真能展开，小题与作文能否在时限内完成，段落是否重复或失衡。 |
| 最后一周 | 固定已验证流程，保留限时作答，复现自己的易错点 | 不继续堆叠复杂标记和句式；熟题速度不当作新题速度。 |

每轮练习至少交出：题意一句话、若干分论点、每点的材料定位和中间机制、一个完整主体段，以及小题200/300字的实际答案。复盘主要记漏材料、关系不成立、表达不准确或无效重复；不把与某篇高分卷措辞不同当作错误。

限时与篇幅应单独检验。2025省市82分作者明确记录结尾未写完；2026县镇90分“岸上的冷女”自述因担心两点太少又加了总结性分点。这些动作不能因为总分较高就成为训练目标。（PDF84页结尾自述；63页提纲及括注）

## 证据边界

- 页码均为PDF物理页；正文印刷页等于物理页减3。
- 合集是文字整理，含回忆、提纲及复盘补写，不是原始考场答卷扫描。分数为合集标注的申论总分，不是作文或小题单项分。
- 46条是收录条目数，不是46个已验证的独立考生。2026县镇两条90分内容高度相似；部分条目错贴题干，已用真题和正文核对归属。
- 没有普通分对照组、分题成绩或官方阅卷记录，不能据此证明“一般考生普遍做不到”或某种写法必然加减分。
- “第一步”文件与分年证据里的“未读方法”等表述是形成时的历史状态。最终自主选择看《我的六套写法》，综合安排看本页与《方法逐条复核》。
