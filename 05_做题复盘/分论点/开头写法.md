# 开头写法：关系论证题，从引语一路走到结尾

**一句话：** 开头五手。第 1、2、4、5 手固定，只在第 3 手分叉；第 3 手选了哪条线，正文和结尾的口吻跟着定。

**考场上只正着走。** 倒着推要把整棵树装在脑子里；正着走，只要记住五手和第 3 手的一张表。倒推这一步已经在备考时做完了，结果就是这份文件。

**适用范围：** 题干是"A 是 B 的 X""B 关键在 A""A 关系 B"这类关系判断。策论、"做好 A"、"A 的实效和经验"、概念题，另开一份。

文中"我的判断"是推理出来的，没有真卷分数撑着；"核过"是拿真卷查过的。

---

## 总图

```
第 0 手  审题：是不是关系判断？ ── 不是 → 另开
第 1 手  引语（固定）   习近平总书记指出："……。"
第 2 手  道理（固定）   接住引语一个词，说清为什么
第 3 手  广东出场（分叉）看材料给了什么，按顺序问，第一个"是"就停：
           ├─ 两难：有没有"如何在……的同时……"？
           ├─ 短板：有没有点广东的短板？
           ├─ 令  ：有没有给广东派任务？
           ├─ 机  ：有没有机遇、潜力？
           ├─ 转变：有没有"曾经……如今……"？
           └─ 成效：都没有，就写成效
第 4 手  要（固定框）   要[收线词]，广东必须[串]，[第 5 手的主语]。
第 5 手  合（固定）     题干原句，谓语前加"正"。
正文     每段四手：分论点 → 道理 → 例子 → 收尾
结尾     三手：画面 → 回收 → 收线＋扬
```

第 3 手的线决定三个地方：第 4 手的收线词、正文第二格要不要点矛盾、结尾的收线动作。

**标点：每一手末尾一个句号。** 引语、道理、广东、要、合，五手就是五个句号；第 3 手并进第 4 手时少一个，第 3 手写成两句时多一个。一手里面的分句用逗号。引语的句号打在引号里："……福祉。"

## 第 0 手：审题

| 题干长相 | 题型 | 走哪 |
|---|---|---|
| A 是 B 的 X / B 关键在 A / A 关系 B | 关系判断 | 本文件 |
| 做好 A / 推进 A / 激活 A | 任务型 | 另开 |
| A 取得的实效和经验 | 总结型 | 另开 |
| 题干写明"策论文" | 策论 | 另开 |
| 一个人、一种精神（时代新人） | 概念型 | 另开 |

核过：2024—2026 年六套省考卷，关系判断五套（2024 一卷、2024 二卷、2025 县镇、2026 省市、2026 县镇），任务型一套（2025 省市）。三套选调卷是概念型一套、任务型两套。

## 第 1 手：引语

**写：** 习近平总书记指出："[一句话]。"题干用"指出"就写"指出"，用"强调"就写"强调"。

**去哪找：** 题干里的引语 → 题干没有，用材料一里含题干关键词的那一句。

**为什么：**
- 放第一句：先亮出权威判断，站位一眼可见，也给第 2 手留一个能接的词。
- 署名在前：读到句号时，最显眼的是句尾几个字，下一句从那儿接。署名放后面，句尾留的就是"总书记强调"，下一句没法接。
- 只引一句：两句不同场合的话放进一个引号，等于替总书记造句。

核过：参考范文和高分卷里用总书记原话开头的 16 篇，署名全在前；整本高分卷合集里没有一处署名放在引语后面。

**误用：**
1. 署名放后面："……。"习近平总书记强调。——后果：句尾留下的是署名，下一句只能从零起头，读着卡一下。
2. 两句合进一个引号——后果：引用失实。真要用两句，分开两个引号："……"，"……"。
3. 引的话和题干关键词不沾边——后果：第 2 手接不住，只能硬转。
4. 引语超过一行半——后果：开头头重脚轻。截含关键词的那一句。
5. 引语后面打逗号接着写——后果：主语从总书记直接换成别的，一逗到底。引语后面是句号。
6. 用古语代替总书记——能用，但第 2 手要多走一步，把古语接到题干上。默认用总书记。

## 第 2 手：道理

**写：** 句首接住引语里的一个词，说清它为什么成立、是什么意思。后半句把题干的落点 B 带进来；双落点题，至少带进引语里没有的那一头。

**令、机、转变、成效四条线，B 必须在这一手露面。** 这四条线第 4 手的收线词不带 B，第 2 手不带进来，B 就要到第 5 手才第一次出现。两难、短板线的收线词本身连着 B，这一手带不带都行。

**接法三种：**
- 原词接："……底色。"→ 底色，就是……
- 代词接："……产业兴旺是重点。"→ 这为……指明了方向
- 换说法接："……解决农村一切问题的前提。"→ 乡村振兴……最关键的是产业振兴

**内容四种，任选一种：**
- 解释：是什么意思（底色是铺满整幅画布的那层颜色）
- 因果：为什么成立（没有产业的农村，难聚人气……）
- 上位：接到更大的道理（共同富裕是本质特征，区域协调是必然要求）
- 并举：同一个意思换个角度再说（发展经济是为了民生，保护生态环境同样也是为了民生）

**去哪找：** 材料一里引语所在那段的其他句 → 材料一首段、末段的判断句 → 都没有就自己解词。引语里总有一个能解的词：底色、关键、头号、前提、必答题、大文章、最普惠。

**为什么必写（我的判断）：**
- 这是起承转合的"承"。引语是一个大论点，后面直接接广东，就是从普遍的道理一下跳到具体的地方。
- 评分要"思想深刻"，开头只有这一句能拿：它把权威的话变成讲得通的道理。
- 交棒：引语里的词在这里交给后文；双落点题，另一头最好在这里先露面，免得到总论点才第一次出现。

**结论：这一格 100% 要有。** 只有一种情况内容会变：引语本身已经点了广东的短板（比如 2024 二卷"城乡区域发展不平衡是广东高质量发展的最大短板"），这时可以先用一句数据把短板说实，再接道理。格子还在，只是先实后虚。

**材料里有没有（核过）：**
- 2024—2026 年 8 套卷，材料一都有 3—9 句判断句。2020—2022 年材料一的判断句只有 0—3 句，那几年题干也不是关系判断。
- 逐套查了 6 套关系题和任务题，材料一里都有现成的道理句：

| 卷 | 道理句 | 位置 |
|---|---|---|
| 2026 县镇 | 发展经济是为了民生，保护生态环境同样也是为了民生；不仅关系经济发展质量，而且攸关每个人的生活品质 | 材料一第 2 段，和引语同段 |
| 2026 省市 | ……绿色成为普遍形态…… | 材料一第 3 段，和引语同段 |
| 2025 县镇 | 没有产业的农村，难聚人气，更谈不上留住人才…… | 材料一第 3 段，和引语同段 |
| 2025 省市 | 创新是第一动力。创新才能把握时代、引领时代。 | 材料一第 1 段，在引语前面 |
| 2024 二卷 | 全体人民共同富裕是中国式现代化的本质特征，区域协调发展是实现共同富裕的必然要求 | 材料一第 5 段 |
| 2024 一卷 | 康庄大道并不等于一马平川 | 材料一第 3 段；引语那段后面跟的是"要……"，道理在别段 |

材料确实爱把一件事换几种说法反复说：2026 县镇材料一第 2 段，"环境和民生"这一个意思，总书记的话就引了三处。

**误用：**
1. 直接跳到广东——后果：从道理跳到地方，读着断。
2. 把引语换个说法再说一遍——后果：没有新东西，"承"变成了原地踏步。
3. 写成"要……"——后果：做法提前，第 4 手没话说，开头还像策论。
4. 写成例子或数据——后果：那是第 3 手和正文的活（上面说的引语已点广东短板的情况除外）。
5. 写两句以上——后果：开头膨胀。一句就够。
6. 双落点只接一头——后果：另一头到总论点才第一次出现，像临时补的。

## 第 3 手：广东出场（分叉）

**主语必须是广东。** 这一手回答的是：这个论点为什么和广东有关。

### 一共几种：不重不漏

广东和论点的关系，按时间只有三种：已经发生的、还没发生的、应该去做的。前两种再分好坏：

| | 好的 | 不好的 |
|---|---|---|
| 已经发生 | **证**：成效、转变 | **缺**：短板、两难 |
| 还没发生 | **机**：机遇、潜力 | **险**：不做会怎样 |
| 应该去做 | **令**：要求、任务 | |

拆开是七条线：两难、短板、令、机、转变、成效、险。

**有三样东西不是线，只是前缀：**
- 身份："广东作为经济总量连续 36 年领跑的'第一省'……""工业是广东的命脉"
- 大势："当前，全球经济正处在转型的重要节点……"
- 时间节点："站在'十五五'开局的新起点上……"

它们说的不是广东和论点的关系，只是给某条线垫个底。身份最常垫在令和两难前面：是排头兵，所以该带头；工业是命脉，所以绿色转型难。大势按好坏归线：说机遇的归机，说压力的归险或缺。

### 信号词：材料给了什么，就是哪条线

| 线 | 信号词 | 例子 |
|---|---|---|
| 两难 | 如何在……的同时……？既要……又要……；是不是……；有人担心…… | 2026 省市材料四第 2 段："广东如何在保持制造业优势的同时，走出一条产业与生态共荣的绿色发展之路？" |
| 短板 | 短板、薄弱、不平衡、不足、差距、瓶颈、卡脖子、受制于人、尚待；群众的期待、盼望（期待和现状之间的差距） | 2025 县镇材料二首句："广东实现高质量发展的突出短板在县、薄弱环节在镇、最艰巨最繁重的任务在农村。" |
| 令 | 要求、嘱托、寄望、必答题、头号工程、大文章、走在全国前列、"广东要……"；规划目标（"到 2027 年……"）；广东自己的部署（"广东把……作为……"） | 2026 县镇材料二首句："推进中国式现代化的广东实践，建设生态文明是必须答好的必答题。"2024 一卷题干："广东要在提升科技自立自强能力方面继续走在全国前列。" |
| 机 | 机遇、窗口、潜力、空间、新增长点、新赛道、资源禀赋、还没转化的优势 | 2026 省市材料四首段："绿色发展……已成为经济发展的新增长点。" |
| 转变 | 曾经、一度、以前……现在、从……到……、昔日……如今 | 2026 省市材料四第 2 段"也曾面临……挑战"，配材料二"空气质量优良天数比率达 95.8%，创有记录以来最好水平" |
| 成效 | 走在全国前列、居全国首位、连续……第一、不断增厚、累计、突破 | 2026 县镇材料三第 2 段："……走在全国前列，绿色家底不断增厚。" |
| 险 | 不进则退、否则、一旦…… | 核过：39 篇参考范文和高分卷开头共 141 句，一次都没有 |

**材料只给了个案、没有广东层面的句子：** 把两三个个案归成一句成效。比如"从 F 市的南溪河到 E 市的永安乡，……"，走成效线。

### 选哪条：按顺序问，第一个"是"就停

在哪看：题干、理论则、总览则，加上各则开头一两段。读骨架时顺手标出来。

1. 两难
2. 短板
3. 令
4. 机
5. 转变
6. 成效（兜底）
7. 险：不用。真碰到，按短板写。

**为什么是这个顺序（我的判断）：**
- **有矛盾先写矛盾（两难、短板）。** 命题人把矛盾放在显眼处，就是要文章去解它；绕开它，文章就浅。两难排在短板前面，因为两难本身就是一道题，材料往往连问句都出好了，照转换表改成陈述句就能用。
- **没矛盾，写往前看的（令、机）。** 这两条自带"要"，往上扬。令排在机前面：令是上面派的，机是自己看的，令更硬。
- **都没有，才写往回看的（转变、成效）。** 一开场就摆成绩是完成时，后面还得拐回"要"。转变排在成效前面：有前后对比，比干摆数字有劲。
- **险不用。** 材料口吻是正面的，写"不做就会落后"，和材料唱反调。

**按这个顺序判近三年六套（核过）：** 判出来的线，和参考范文实际走的都对得上。

| 卷 | 第一个"是" | 判成 | 参考范文实际走的 |
|---|---|---|---|
| 2024 一卷 | 题干"广东要……继续走在全国前列"；短板只出现在个案里 | 令 | 成就 → 难点 → 落在"广东要……" |
| 2024 二卷 | 材料一"广东要下功夫解决区域发展不平衡问题"、"最大短板" | 短板 | 短板 → 潜力板 |
| 2025 县镇 | 材料二首句"突出短板在县" | 短板 | 短板 → 问句 → 产业是重中之重 |
| 2025 省市 | 题干"继续做好创新这篇大文章" | 令 | 家底 → 竞速赛 → 做法 |
| 2026 县镇 | 材料二首句"必答题"；没点广东层面的短板 | 令 | 必答题 → 家底 → 总论点 |
| 2026 省市 | 材料四第 2 段"如何在保持制造业优势的同时……？" | 两难 | 挑战 → 问句 → 答案 |

### 材料同时给了好几样

主线只能有一条。其余的最多挑一样当铺垫，放在主线前面。第 3 手最多两句，主线放在后一句，因为第 4 手要接它。

| 材料给的 | 写成 | 主线 |
|---|---|---|
| 成效＋短板 | 广东……取得……，但……仍…… | 短板（先扬后抑） |
| 令＋成效 | ……是必答题。答这道题，广东有底气：…… | 令（成效给底气） |
| 身份＋两难 | 工业是广东的命脉……广东既要……，又要…… | 两难 |
| 大势＋机 | 当前，……；广东……优势…… | 机 |
| 短板＋机 | 最大的短板，也是最大的潜力板 | 短板（机只是换个看法） |

### 每条线怎么写

| 线 | 第 3 手句式 |
|---|---|
| 两难 | 对广东而言，这并不容易：[身份]，广东既要[甲]，又要[乙]。（材料里是问句的，照下面的转换表改） |
| 短板 | 对广东而言，这恰恰是短板所在：[短板的一个数]。 |
| 令 | 对广东而言，[材料里派的任务]是一道必须答好的必答题。 |
| 机 | 对广东而言，[A]更是一次难得的机遇：[优势或潜力，一个数]。 |
| 转变 | 对广东而言，这一点体会最深：曾[困境]；如今，[改变，一个数]。 |
| 成效 | 对广东而言，这一点已有实践印证：[家底，一个数，挑能印证第 2 手的那个]。（只写家底，不写"推进 A"，留给第 4 手） |

**开头一律"对广东而言，这……"。** "对广东而言"把话题从普遍落到广东；"这"指回第 2 手说的那件事，不用抄词。令、机两条把"这"换成任务名或 A：说"这是一道必答题""这是一次机遇"，"这"容易指不清。冒号后面放信号句里的原话或一个数。

短板线不再分"然而"还是"而……恰恰"：第 2 手是正面道理（"区域协调发展是必然要求"），"这"指协调，"恰恰是短板所在"就是说广东缺它；第 2 手是反面道理（"没有产业的农村难聚人气"），"这"指农村缺产业，"恰恰是短板所在"就是说广东正卡在这儿。两种都通。

第 3 手很短时，可以并进第 4 手的目的语里："要答好生态文明建设这道必答题，广东必须……"

**误用：**
1. 主语写成"我国""各地"——后果：没联系广东实际。
2. 选错线：材料点了两难或短板，却写成效——后果：浪费命题人给的矛盾，文章浅。
3. 材料没点短板，硬编一个——后果：编造，口吻也和材料拧着。
4. 短板写得太重（"问题严重""形势严峻"）——后果：口吻不对。用"仍有""还面临""曾面临"。
5. 一句堆三四个数——后果：开头变成例子段。一个数够。
6. 两条主线各占一句（既写短板，又写必答题）——后果：第 4 手不知道接哪个。一条主线，另一样当铺垫。
7. 写成"广东坚持……"这种已然做法，后面直接下判断——后果：接不上，见第 4 手。

### 材料里的问句：一律改成陈述句

开头不用问句。问句点名下一句必须是答案，还得照问句的样子答，答句的形式、分量、位置全被锁死。改成陈述句加"要"，往前推的劲儿一样有，后面好接得多。

**原理：问句是一个句尾空着的陈述句。** 疑问词占的位置，就是答案的位置。改的时候三步：
1. 问句里已经说了的（目标、两头、对象），放到句首；
2. 疑问词换成一个连接词；
3. 答案填进句尾。

**转换表：**

| 材料里的问句 | 改成 | 逻辑 | 常落在 |
|---|---|---|---|
| 如何 X？怎样才能 X？ | 要 X，[主语]必须 Y。 | 目标 → 手段 | 第 4 手 |
| 如何在 A 的同时 B？ | [主语]既要 A，又要 B。要做到两者兼顾，必须 Y。 | 两难 → 手段 | 第 3、4 手 |
| X 的关键（密码、出路）是什么？X 靠什么？ | X 的关键，在于 Y。 | 问关键 → 给关键 | 第 5 手、分论点 |
| 为什么 X？ | X，是因为 Y。 | 问原因 → 给原因 | 道理句 |
| 是不是 X？万一 X 怎么办？（担心、误区） | X 不是 A，而是 B。 | 破一个，立一个 | 道理句 |
| 难道……吗？哪里……了？（反问） | 照意思正着说。反问的意思和字面相反 | 去掉反问 | 例子 |

核过：11 套卷的材料里一共只有 8 个问句，其中"如何"5 个。广东层面的问句都是"如何"：2025 县镇"如何将短板变为潜力板？"，2026 省市"如何在保持制造业优势的同时……？"。所以开头只会碰到前两种。

**改完怎么接：要 → 必须 → 正是，一句比一句硬。**
- 要：接住问句里的目标，说的是"想做到什么"；
- 必须：接住问句要的答案，说的是"非这样做不可"。读到这里，读者自然要问"为什么非这样不可"；
- 正是：第 5 手的判断正好回答它。

逻辑上是"目标 → 手段 → 意义"，语气上一级比一级往上走。

两个例子：
- 2025 县镇："如何将短板变为潜力板？"→ 要把短板变为潜力板，广东必须以产业振兴带动人才、文化、生态、组织振兴，推动乡村全面振兴。乡村振兴的关键，正在于产业振兴。
- 2026 省市："广东如何在保持制造业优势的同时，走出一条产业与生态共荣的绿色发展之路？"→ 广东既要保持制造业优势，又要让产业与生态共荣。要做到两者兼顾，广东必须协同推进降碳、减污、扩绿、增长，走绿色发展之路。绿色发展，正是广东高质量发展的底色。

**误用：**
1. 改完还留着疑问口气（"广东该如何……，值得深思"）——后果：答案还悬着，等于没改。
2. 目标和手段顺序反了（"广东必须……，才能……"）——后果：句尾落在目标上，第 5 手的"这"不知道指什么。目标放"要"后面，手段放"必须"后面，句尾是 A。
3. 两难只写了一头（"广东要保持制造业优势"）——后果：矛盾没了，"两者兼顾"接不上。

## 第 4 手：要（固定框）

**写：** 要[收线词]，广东必须[串]，[第 5 手的主语]。

最后几个字是第 5 手的主语：题干是"A 是……"，收在"推进 A""走 A 之路"；题干是"B 关键在 A"，收在"推动 B"。

| 线 | 收线词 |
|---|---|
| 两难 | 做到两者兼顾 |
| 短板 | 补上这块短板 |
| 令 | 答好这道必答题／不负嘱托 |
| 机 | 抓住这一机遇／把潜力变成实力 |
| 转变 | 让这种变化持续下去 |
| 成效 | （前面加"站在新起点"）把这份家底做优做强 |

本人 2026 省市卷用的是问句加"广东的答案是：……"，按现在的定法改成陈述句，见"材料里的问句"。

**去哪找：** 串在总览则里（多是材料二），找"坚持……相促进""协同推进……"那一串，原词照抄。A 在题干里。

**为什么：**
- 用"要"：读者读完"要做"，等的是"为什么要"，第 5 手的判断正好被读成理由；读完"做了"，等的是"然后呢"，判断就像另起一件事。核过：39 篇开头里，最后一两句写到广东做法的 30 篇，23 篇用的是"要"这一类。
- 收线词跟着第 3 手走：第 3 手抛出来的东西，在这里接住。
- 串放这里：预告正文四段，阅卷人读到这里就知道文章怎么走。
- 以第 5 手的主语收尾：这一句的宾语，交棒给下一句的主语。

**误用：**
1. 写成已然（"广东坚持……"）——后果：第 5 手的判断接不上，读着像事情已经办完了。
2. 收线词和第 3 手对不上（第 3 手说短板，这里说必答题）——后果：线串了。
3. "这道""这块"在前面没出现过——后果：指代落空。要么第 3 手先说出来，要么一次说全："生态文明建设这道必答题"。
4. 串改写或换顺序——后果：预告和正文对不上。
5. "必须要"叠用——留一个。
6. 后面再加一句"要……"——后果：开头变成对策。

---

## 第 5 手：合

**写：** 题干原句，谓语前加一个"正"：是 → 正是，在 → 正在于，关系 → 正关系着。主语照抄，或换成"这"。比如"这正是一项关系广东长远发展和民生福祉的重要工程""乡村振兴的关键，正在于产业振兴"。

**为什么：**
- 单独成句，当主张。整篇文章要论证的就是这句，它不能当别人的理由。
- 用"正是"：接住第 4 手的"必须"，读者问"为什么非这样不可"，这一句给答案。
- 放在开头最后一句，阅卷人读开头最后一句就找到了总论点。

核过：39 篇开头 141 句，"因为"只出现 1 次，在解题里解释引语；"因此"出现 3 次，都是引出结论。没有一篇把总论点放在"因为"后面。

**误用：**
1. 挂在"因为"后面——后果：总论点降成理由，主张变成"广东必须怎么做"，正文容易滑去写做法。
2. 改写太多（"绿美建设意义重大"）——后果：阅卷人对不上题干。
3. 后面再接"要……"——后果：开头又落回做法。
4. 双落点只写一头。

## 正文：每段四手

| 手 | 写什么 | 口吻 | 去哪找（第十节） |
|---|---|---|---|
| 分论点 | [串里第 i 个面]，为[B]＋[第三格名词] | 不分时间的判断 | 本块第一段作用词 → 理论则 → 自己拼 |
| 道理 | 这一面为什么管用 | 不分时间 | 本块第一段 → 中间段判断句 → 理论则 |
| 例子 | "近年来，广东……""在某市，……"开头；做了什么、得到什么，带数 | 已然 | 本块中间段 → 总览则数据 |
| 收尾 | 可见／正因如此＋回扣 B | 从已然收回判断 | 本块最后一段 → 中间段收束句 |

**线对正文的影响：** 两难线和短板线，可以在分论点第二格点出这一面解的是哪头矛盾、补的是哪块（比如"……让工业减碳不减速"）。其他线照常写。

**为什么开头用"要"，正文例子却用"做了"：** 开头是提出论点，要往上扬；正文是证明，证据只能是已经做成的事。

**误用：**
1. 分论点写成"要……"——后果：变成策论。
2. 例子写成"要……"——后果：例子是证据，得是做了的、做成了的。
3. 收尾不回 B——后果：段内跑题。
4. 每段都喊一遍第 3 手的关键词——后果：啰嗦。留给结尾收。
5. 例子和分论点说的不是同一面——后果：证据对不上论点。

## 结尾：三手

| 手 | 写什么 | 去哪找 |
|---|---|---|
| 画面 | 一句画面或升华句，最好带着引语 | 总览则末段、各则末段的收束句 |
| 回收 | "这幅画卷里""这背后"开头，接住画面；再写串＋总论点 | 第 4、5 手 |
| 收线＋扬 | 以[A][收线动作]，[广东定能]在推进中国式现代化建设中走在前列 | 第 3 手的关键词 |

| 线 | 收线动作 |
|---|---|
| 两难 | 让[甲]与[乙]相得益彰 |
| 短板 | 补齐[短板] |
| 令 | 答好[必答题]／不负[嘱托] |
| 机 | 把[机遇]变成[胜势] |
| 转变 | 让[变化]从[点]到[面]，从[一时]到[长久] |
| 成效 | 把[家底]越做越厚 |

**为什么：**
- 画面：把正文的证据收成一幅图，比再讲一遍道理有余味；画面里带着引语，首尾呼应。
- 回收：让阅卷人最后再对一次总论点和四个面。
- 收线：第 3 手抛出的线在这里收，全文才闭合。短板线和两难线尤其要收，不收，矛盾就悬在那儿。
- 扬：开头是"要"，结尾也落在"走在前列"这种往前推的话上，口吻一致。

核过：近三年六套参考范文，五篇的结尾段里有"走在前列"；2024 二卷"以头号工程补齐最大短板"、2024 一卷"在提升科技自立自强能力方面继续走在全国前列"，正好收回了各自开头的那条线。

**误用：**
1. 结尾写"已经实现了"——后果：和开头的"要"打架。
2. 第 3 手的线没收——后果：开头抛出的矛盾或任务悬着。
3. 引新材料、新观点——后果：收不住。
4. 只喊口号，没回扣总论点。
5. 画面句和主题不沾边（随手抄一句"岭南处处是春天"）——用带主题词的那句。

## 接口检查：哪里会接不上

**接得上，要三样都在：**
- 词接：句首有一个词接住上一句（原词、代词、换说法）。
- 推接：两句之间只隔一步推理。上一句加一个前提，能得出下一句，或者反过来；隔两步以上，读者就觉得跳。
- 气接：口气从"做了"换到"要做"，或者反过来，中间有词标出来（可见、站在新起点）。

### 例：两难句为什么通用

记号：O(p) 读作"要做到 p"；N(p→q) 读作"做到 p 离不开 q"。

两难问句不管怎么措辞（如何在甲的同时乙、如何兼顾甲和乙、如何平衡甲与乙、如何在不……的前提下……），都预设三件事：O(甲)、O(乙)、甲乙互相掣肘；问的是做什么能让两头同时成立。

用两条道义逻辑的标准规则：
- 合取：由 O(甲)、O(乙)，得 O(甲∧乙)
- 传递：由 O(p)、N(p→q)，得 O(q)

| 步 | 式子 | 依据 | 落在哪句 |
|---|---|---|---|
| 1 | O(甲)∧O(乙) | 问句的预设 | 第 3 手：既要甲，又要乙 |
| 2 | O(甲∧乙) | 由 1，合取 | 第 4 手前半：要做到两者兼顾 |
| 3 | N(甲∧乙→Y) | 前提：两头互相掣肘，各做各的到不了，得有一个 Y 来调和 | 材料给 Y |
| 4 | O(Y) | 由 2、3，传递 | 第 4 手后半：广东必须 Y |

第 1、2 步只用了问句的预设和一条规则，所以"既要甲，又要乙。要做到两者兼顾"对任何两难问句都成立。每两句之间正好隔一步，这就是推接。

**为什么用"兼顾"，不用"兼得"：** 第 1 步只要求两头都是"要做到"的，目标和约束都算，"又不能增加群众负担"也是"要做到"。"兼得"多一个预设：两头都是好处。碰到约束型，"兼得"说不通，"兼顾"没有这个预设。

**第 3 步的 N 不是逻辑给的，是总论点给的。** 关系判断题的总论点，说的就是 A 对 B 必不可少（关键、底色、必由之路、前提）。第 4 手的"必须"，是把总论点先用在广东身上；第 5 手的"正"，再把它说成总论点。所以第 4 手接第 5 手，要满足两条：
- 甲、乙合起来就是题干的 B。2026 省市：保持制造业优势＋产业与生态共荣，合起来就是高质量发展。合不起来，第 5 手的 B 就是凭空冒出来的，这时不走两难线。
- 第 4 手的句尾是第 5 手的主语。

**证明管不到的一处：** 问句里的"在……的同时"是不是真两难。有时它只是背景，比如"在经济下行压力下，如何……"：压力不是"要做到"的东西，第 1 步就不成立，这时按转换表"如何"那一行改。判断办法：问句里的两样，是不是都是"要做到"的。

每一条的完整例子（原来怎么写、卡在哪、改成什么、为什么通）见[《开头写法 · 接口例子》](开头写法_接口例子.md)。

| 接口 | 会出什么问题 | 哪几条线 | 定法 |
|---|---|---|---|
| 1 → 2 | 第 2 手开头没接住引语 | 全部 | 句首放引语里的一个词 |
| 2 → 3 | 从普遍的道理一下跳到广东 | 全部，两难最容易 | 第 3 手一律用"对广东而言，这……"开头 |
| 2 → 3 | "然而"转反了：第 2 手已经是反面道理（"没有……就……"），再说"然而，广东仍有短板"，方向其实没变 | 短板 | 不用"然而"，用"对广东而言，这恰恰是短板所在：……"，第 2 手正反都通 |
| 3 → 4 | 收线词指不回第 3 手（第 3 手列了三处短板，第 4 手说"这块短板"） | 短板 | 收线词照抄第 3 手的核心名词 |

| 段内：道理 → 例子 | 从道理跳到某地 | 正文 | 例子用"近年来，广东……""在某市，……"开头 |
| 段内：例子 → 收尾 | "做了"直接接判断，像另起一件事 | 正文 | 收尾用"可见""正因如此""这" |
| 结尾：画面 → 回收 | 画面之后直接列串，像另起一段 | 结尾 | 回收用"这幅画卷里""这背后"开头 |
| 结尾：回收 → 收线 | 收线用的词和第 3 手不一样，线收不回去 | 结尾 | 收线动作里重复第 3 手的关键词；两难线重复甲、乙 |

## 过渡怎么来：先搬，搬不成再套

**原理：** 材料是写好的成文，相邻两句之间的过渡，原作者已经写好了。作文里挨着的两句，要是在材料里本来就挨着，过渡就跟着一起搬过来，不用想。只有作文里挨着、材料里不挨着的地方（换了段、换了材料），才要自己接；这些地方套固定接头。

考场上每个接口只问一句：**这两句在原文里挨着吗？** 挨着，成对搬；不挨着，套接头。

### 原文里现成的过渡在哪

| 接口 | 先去原文这里找 | 长什么样（真题原句） | 找不到就套 |
|---|---|---|---|
| 引语 → 道理 | 材料一，引语所在那段，引语后面一句 | "其中，'良好生态环境是最普惠的民生福祉'这一原则深刻阐明环境与民生的关系。"（2026 县镇材料一第 2 段） | 抄引语的主语开头 |
| 道理 → 广东 | 跨材料，原文没有现成的 | — | 对广东而言，这……（第 3 手） |
| 广东 → 要 | 信号句那段，后面一两句 | "如何将短板变为潜力板？产业是重中之重。"（2025 县镇材料二第 1 段，问句照转换表改） | 要[这＋第 3 手的名词]，广东必须…… |
| 要 → 合 | 题干原句 | — | 这正是…… |
| 分论点 → 道理 | 本块第一段的判断句 | "独具岭南特色的生态孕育出独特而灿烂的岭南文化，也给文化发展带来更多的生机和绿意。"（2026 县镇材料六第 1 段） | 抄分论点里的面字开头 |
| 道理 → 例子 | 本块中间段的首句（总括句） | "广东还以绿美生态建设为契机，大力推进自然教育。"（材料六第 4 段）；"而在大山深处，森林是生态屏障，也是联结城乡的致富平台。"（材料八第 6 段）；"近年来，广东淘汰落后产能、严控高污染高能耗项目……"（2026 省市材料四第 3 段） | 近年来，广东[动作]：[数] |
| 例子 → 收尾 | 同一段的末句（收束句） | "自然教育基地等设施的建设，为开展多姿多彩的教育和文化活动提供了新阵地。"（材料六第 4 段）；"众多实践背后，是广东以生态倒逼产业升级的战略定力。"（2026 省市材料四第 3 段） | 可见，…… |
| 画面 → 回收 | 总览则末段、各则末段 | "天更蓝、水更清、山更绿的大美画卷徐徐铺展……"（2026 县镇材料四末段） | 这幅画卷里，／这背后， |
| 回收 → 收线 | — | — | 以[A][收线动作]，…… |

核过：11 套卷的材料里，总括句 185 句，62 句在段首，以"近年来""随着""当前"这类词开头的 46 句（"近年来"一个就 18 句）；收束句 125 句，70 句在段末，以"这""如今"开头的 19 句。每块中间段的头和尾，多半已经把进、出写好了。

### 收尾句的五种现成长相

在原文里照着认，原文没有就照着套。

| 长相 | 真题原句 |
|---|---|
| [个案]成为[更大范围]的一个缩影 | H 电子成为 D 县产业绿色转型升级的一个缩影（2026 县镇材料五第 12 段） |

| [做法]的建设，为[B]提供了…… | 自然教育基地等设施的建设，为开展多姿多彩的教育和文化活动提供了新阵地（材料六第 4 段） |
| 众多实践背后，是…… | 众多实践背后，是广东以生态倒逼产业升级的战略定力（2026 省市材料四第 3 段） |
| 如今，…… | 如今，广东城乡"软硬"差距不断缩小，奏响城乡区域协调发展"协奏曲"（2024 二卷材料七） |

### 搬的时候，删掉承上的词

总括句、收束句里常带"还""也""而""此外""最值得一提的是""与此同时"。这些词承的是材料里的上一段；上一段你没搬，它就悬空了。
- 材料六第 4 段"广东**还**以绿美生态建设为契机……"：这个"还"承的是前面第 2、3 段的美术长廊和森林公园。作文里它是第一个例子，删掉"还"。
- 材料八第 6 段"**而**在大山深处，森林是……"：这个"而"承的是前面十五运的场馆。没搬十五运，删掉"而"。

### 走一段：文化兴（2026 县镇，材料六）

> 分论点：文化兴，为民生福祉……（第三格你拼）
>
> 道理（材料六第 1 段）：独具岭南特色的生态孕育出独特而灿烂的岭南文化，也给文化发展带来更多的生机和绿意。
>
> 例子（材料六第 4 段，删了"还"和中间的细节）：广东以绿美生态建设为契机，大力推进自然教育：近年来，全省建成省级自然教育基地 135 家。在 J 县省级自然保护区，小学生们一边观蝶赏花一边翻着科普书，年轻音乐人举办起以花海为主题的自然音乐会。
>
> 收尾（材料六第 4 段末句，加第 7 段）：自然教育基地等设施的建设，为开展多姿多彩的教育和文化活动提供了新阵地。可见，生态美促文化兴，文化资源供给下沉，为民生福祉添上了文化的分量。

四个接口：
- 分论点 → 道理："文化"接"文化"。
- 道理 → 例子：第 4 段的总括句本身就是进例子的接头。
- 例子 → 收尾：同一段里挨着，原作者的过渡整个搬过来。
- 收尾 → 落点："可见"是套的，"为民生福祉添上了文化的分量"是自己补的回扣半句。整段要自己想的只有这半句。

### 走一段：百姓富（2026 县镇，材料八）

> 分论点：百姓富，为民生福祉……（第三格你拼）
>
> 道理（材料八第 1 段）：生态环境保护就是为民造福的百年大计。
>
> 例子（材料八第 6—9 段，删了"而"）：在大山深处，森林是生态屏障，也是联结城乡的致富平台。在 E 市北部山区永安乡，今年国庆期间单日客流一度超过 8 万人次，创下了"小镇大流量"的文旅佳绩；河湖村村民开起特色农庄和康养民宿，2024 年人均年增收 3 万余元，500 多人实现家门口就业。
>
> 收尾（材料八第 10 段，前面补"可见"）：可见，良好的生态环境，是广东永续发展的最大本钱。执此"青绿"，惠民富民的成色才会更加动人。

四个接口：
- 分论点 → 道理："为民造福"换说法接住"百姓富"。
- 道理 → 例子："在大山深处，森林是……致富平台"是原文现成的进口，"致富"又接住"造福"。
- 例子 → 收尾：第 9 段到第 10 段跨了段，原文没有接头，补一个"可见"。
- 收尾 → 落点："惠民富民"就是落点，原文自带。

### 固定接头一览（搬不成对时套）

| 接口 | 接头 | 例 |
|---|---|---|
| 引语 → 道理 | 抄引语的主语开头 | "良好生态环境……"→ 生态环境不仅关系…… |
| 道理 → 广东 | 对广东而言，这…… | 对广东而言，这恰恰是短板所在：…… |
| 广东 → 要 | 要[这＋第 3 手的名词]，广东必须…… | 要补上这块短板，广东必须…… |
| 要 → 合 | [这／主语]，正…… | 这正是一项……的重要工程 |
| 分论点 → 道理 | 抄分论点里的面字开头 | 文化兴 → ……岭南文化…… |
| 道理 → 例子 | 近年来，广东[动作]：[数] | 近年来，广东把绿色资源变成富民产业：…… |
| 例子 → 收尾 | 可见，…… | 可见，绿美广东生态建设正为…… |
| 画面 → 回收 | 这幅画卷里，／这背后， | 这幅画卷里，生态美、产业强…… |
| 回收 → 收线 | 以[A][收线动作]，…… | 以绿美广东生态建设答好…… |

## 全文怎么咬合

**口吻：开头扬（要）→ 正文证（做了）→ 结尾扬（要）。** 开头提出，正文证明，结尾往前推一把。

| 开头 | 正文 | 结尾 |
|---|---|---|
| 第 1 手引语 | — | 画面句里化用 |
| 第 3 手的线 | 两难、短板线可在第二格点到 | 收线动作 |
| 第 4 手的串 | 四段顺序 | 回收 |
| 第 5 手的落点 B | 每段第三格 | 回收 |

## 走一遍

### 令线 · 2026 县镇

开头：
1. 习近平总书记指出："良好生态环境是最普惠的民生福祉。"
2. 生态环境不仅关系经济发展质量，而且攸关每个人的生活品质。（材料一第 2 段。本人第三稿用的是"发展经济是为了民生……"，只带进了民生；令线的收线词不带 B，长远这一头得在这里露面）
3＋4. 要答好生态文明建设这道必答题，广东必须坚持生态美、产业强、文化兴、百姓富相促进，深入推进绿美广东生态建设。
5. 这正是一项关系广东长远发展和民生福祉的重要工程。

正文：生态美、产业强挂长远发展；文化兴、百姓富挂民生福祉。每段"[面]，为[长远发展／民生福祉]＋[第三格]"。

结尾：
- 画面：天更蓝、水更清、山更绿的大美画卷徐徐铺展，生动诠释着"良好生态环境是最普惠的民生福祉"。（材料四末段，带着引语）
- 回收：这幅画卷里，生态美、产业强、文化兴、百姓富相促进，绿美广东生态建设一头连着广东长远发展，一头连着民生福祉。
- 收线＋扬：以绿美广东生态建设答好生态文明建设这道必答题，广东定能在推进中国式现代化建设中走在前列。

### 两难线 · 2026 省市

开头：
1. 习近平总书记指出："绿色发展是高质量发展的底色。"
2. 底色是铺满整幅画布的那层颜色，绿色发展不只是高质量发展的某一部分，更要成为它的普遍形态。
3. 对广东而言，这并不容易：工业是广东的命脉，广东既要保持制造业优势，又要让产业与生态共荣。
4. 要做到两者兼顾，广东必须协同推进降碳、减污、扩绿、增长，走绿色发展之路。
5. 绿色发展，正是广东高质量发展的底色。

正文：降碳、减污、扩绿、增长四段。第二格可以点出这一面怎么让产业和生态两头都赢。

结尾：
- 画面：岭南大地青山常在，绿水长流，呈现出一派逐绿向美、生机盎然的喜人景象。（材料二末段）
- 回收：这背后，是降碳、减污、扩绿、增长协同推进，绿色正成为广东高质量发展的底色。
- 收线＋扬：以绿色发展让制造业优势与生态优势相得益彰，广东定能在推进中国式现代化建设中走在前列。

### 短板线 · 2025 县镇

开头：
1. 习近平总书记指出："产业兴旺，是解决农村一切问题的前提。"
2. 没有产业的农村，难聚人气，更谈不上留住人才，农民增收路子拓不宽，文化活动很难开展起来。
3. 对广东而言，这恰恰是短板所在：县域面积占全省的 71.7%，2022 年县域地区生产总值却仅占全省的 12.39%。
4. 要补上这块短板，广东必须抓住产业这个"牛鼻子"，以产业振兴带动人才、文化、生态、组织振兴，推动乡村全面振兴。
5. 乡村振兴的关键，正在于产业振兴。（题干是"B 关键在 A"，第 4 手收在"推动 B"）

正文：人才、文化、生态、组织四段，每段写产业怎么带动这一面。

结尾：
- 升华：强国必先强农，农强方能国强。（材料一第 1 段）
- 回收：农强，靠的是产业强：人才因产业而聚，文化因产业而兴，生态因产业而美，组织因产业而强。
- 收线＋扬：以产业振兴补齐县域这块短板，广东定能在推进中国式现代化建设中走在前列。
