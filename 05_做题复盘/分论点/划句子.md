# 划句子：从审题到成文

**一句话：** 先审题，把 A→B 定下来；读材料时揣着目标和记号划；动笔前先整理论点句；再写。

这一版按本人的做法定下来。上一版（人用版：一句读完问两件事，看到就用、记得就用）在 git 历史里。

---

## 一、审题

认清论证的是谁跟谁的关系，把 A→B 的 A 和 B 填好。

**上游、下游：** 上游是导致它的东西，下游是它的一部分。

---

## 二、读材料：揣着目标和记号

### 目标（按顺序）

1. 标题
2. 引语
3. 引语的解释道理句
4. 广东现状句（三个时态选一个就行）
5. 广东的做法
6. 最重要的：论点句
7. 其他的道理句、结尾句是附带的

### 记号

手上揣着三样：★、{ }、( )。

| 遇到什么 | 怎么标 |
|---|---|
| 第一段（开头）要用的 | 标序号：① 引语，② 道理句，③ 广东现状，④ 广东的做法 |
| 涉嫌 A 的下游的概念 | ★{ } |
| 涉及结果的、作用的，不管跟 B 有没有关系 | ★{ } |
| 好看的架子，适合分论点的 | ★★{ } |
| 能当标题的 | ★★ |
| 好看的架子，适合结尾的 | ( ) |
| 有点信息量的 | { } |
| 适合普通段结尾的（有精力再打） | ( ) |

---

## 三、整理论点句（动笔前，在草稿纸上）

1. 把所有 ★★ 的句子全部挑出来，选个架子，能套的全部套上。
2. 套完之后，落点能改的，全部改成 B 或者 B 的上游。
3. 剩下的标题句（套不上架子的论点句），从题干改写；改不了，再从 ★★{ } 里面找。

---

## 四、成文

整理完论点句，开始编写文章。

**结尾：** 写个诗句，回扣一下开头，升华。

---

## 五、基本改法

不背句式，只用这几种改法：

1. **去壳：** 广东坚持把绿色发展作为解决生态环境问题的治本之策 → 绿色发展是解决生态环境问题的治本之策。
2. **换主语：** 广东向"高"攀登 → 科技创新向"高"攀登。
3. **缩句：** 一个个案只留一件事、一个数。
4. **问句改陈述：** 如何将短板变为潜力板？→ 要把短板变为潜力板，广东必须……
5. **已然改进行时（回扣用）：** ……惠民富民的成色才会更加动人 → ……成色更加动人，……越来越……
6. **题干加「正」：** 乡村振兴关键在产业振兴 → 乡村振兴的关键，正在于产业振兴。

连接只用「对广东而言」「近年来」「如今」这一类。不套「以……为……，让……」这种现成句式，也不自己造比喻、排比。
