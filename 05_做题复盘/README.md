# 05_做题复盘

先按 2023 → 2024 → 2025 → 2026 顺序做 9 套省考，再做 2024、2025 两套选调。每套先自己作答、再对参考答案和高分卷，逐年修订方向；最后用 55 份真人得分卷核验，得到最终版 v7。

- **先看这个 →** [`备考方向_总结.md`](备考方向_总结.md)（最终方向 v7 + 练习安排）
- `分论点/`：大作文分论点怎么写。方法论一份，四关练习一份，答案单独一份，做完练习再看答案
  - `分论点/句子去哪找_11套卷核验.md`：写作文时句子去哪找，拿 11 套卷核验第十节的规则，附原理和改法
  - `分论点/开头写法.md`：关系论证题从引语一路写到结尾：开头五手、第 3 手七条线怎么选、正文和结尾怎么跟着咬合，每一手都有为什么和误用
  - `分论点/开头写法_接口例子.md`：上面那份里"接口检查"的 14 条逐条例子，每条有原来、卡在哪、改成、为什么通
  - `分论点/划句子.md`：大作文从审题到成文。先把 A→B 定下来；读材料时揣着目标（标题、引语、道理句、广东现状、广东的做法、论点句）和记号划，开头要用的标序号，再用 ★{ }、★★{ }、{ }、( )；动笔前先在草稿纸上整理论点句：挑出 ★★ 选架子、能套就套，落点改成 B 或 B 的上游；结尾写诗句、回扣开头、升华；附六种基本改法
  - `分论点/划句子_逐格.md`：更早一版「来源 × 句式」九格的逐格细看，已被上面那份替代，留作参考
  - `分论点/分论点作答_病根与解药.md`：本人写的分论点，按卷记下原句、病根、解药。最要紧的是切题：每句分论点是一座桥，前半站在题干的 A 上，后半落到题干写明的终点。现有 2024 二卷、2025 省市卷、2025 县镇卷、2026 县镇卷，其他年份写完再补，全部写完统一修正、重写
  - `分论点/缓冲区.md`：还没在卷子上试够的写法，先放这里，试过好用再并进方法论
  - `分论点/论点句名词表.md`：论点句后半句的判断名词。按"这段的道理在说什么"分 11 类，核心 15 个词；每个词写明给谁用、要注意什么，附例句和出处；另有固定提法清单（只能给指定主语的说法）和历年核对。同目录有一份 `论点句名词表.html`，内容相同，单文件，浏览器直接打开，适合发给别人看
- `大作文逐句品读/`：2023—2026 七卷省考大作文（参考范文＋高分卷全文）逐句批注：每句是实（真论证）、仪（文体规矩）还是虚（站不住），凭直觉写不写得出。README 里是每卷一览、这几年怎么变的、直觉流够不够
- `考场推演_2024-2026_大作文.html`：八套大作文合在一页的考场推演，浏览器直接打开。八套是 2024 一卷、二卷、选调，2025 省市、县镇、选调，2026 省市、县镇；每套都是模拟一个普通考生按人用版规则重写的（尽力而为，量力而行，不套模板，只做基本改写），不是本人作答；2026 省市另附本人作答。开头是总览，有三块：一是人用版规则；二是八篇一览，每篇的标题、格子、论点句和考场记录（破例、卡住、顺手）；三是参考范文从材料里拿的句子，模拟考生当时划没划。年份文件夹和 `选调/` 里有单卷版
- `2023/`：县级卷、乡镇卷作答 + 复盘（方向 v1）
- `2024/`：一卷、二卷、三卷（行政执法）作答 + 复盘（方向 v2）
  - `考场推演_2024一卷_大作文.html`、`考场推演_2024二卷_大作文.html`：单卷版考场推演，模拟考生按人用版规则写，不是本人作答
- `2025/`：省市卷、县镇卷作答 + 复盘（方向 v3）
  - `考场推演_2025省市_大作文.html`、`考场推演_2025县镇_大作文.html`：单卷版考场推演，模拟考生按人用版规则写，不是本人作答
- `2026/`：省市卷、县镇卷作答 + 复盘（方向 v4；本年无官方参考答案，对照高分卷合集）
  - `本人作答_2026省市_大作文.md`：本人一段一段写、和 Claude 一起改的大作文，有原稿、成稿、句子来源表和复盘。这份和上面的 `我的作答_*.md` 不同，记下了修改过程
  - `考场推演_2026省市_大作文.html`：上面那篇按考场顺序重走一遍的网页，浏览器直接打开。共六步：读题、划句子、找格子、拼文章、誊稿纸、对答案。材料按"读完多了什么＋句式"逐句判，每句能点开看为什么这么划、后来用在哪；成稿 23 句逐句对回出处。划句子用的是人用版之前的记号，没有 ★
  - `考场推演_2026省市_模拟考生.html`：同一卷，模拟考生按人用版规则重写的单卷版，可以和本人作答对着看
  - `考场推演_2026县镇_大作文.html`：县镇卷的单卷版，模拟考生按人用版规则写，不是本人作答
- `选调/`：2024、2025 选调申论（方向 v5、v6）
  - 每年三份盲做：A、B 按方向作答，C 是没看方法的对照组；每份都逐点对照参考答案，并经过对抗核验
  - `方向核验_真人卷.md`：用 55 份真人得分卷逐条检验方向，以及我对核验结论的复核
  - `考场推演_2024选调_大作文.html`、`考场推演_2025选调_大作文.html`：单卷版考场推演，模拟考生按人用版规则写，不是本人作答

每个 `我的作答_*.md` 都是**做完才看答案**的原始版本，没有事后修改。复盘里后来发现的错误，以"⚠️ 更正"的形式补记在原处，没有删改原文。

**注意**：
- 2021—2023 年的选调考的是选择题（综合能力 / 思维能力测试），没有申论。
- 2024 选调要用 `24广东选调《申论》答案.pdf` 后附的材料，题目 PDF 里的那版是拼错的。
