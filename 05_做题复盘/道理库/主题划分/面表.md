# 申论大作文“面”的边界表

**建议用15个大面管理配对，用小块决定具体落格。** 大面控制规模，小块保存差别。企业不单列为大面，改革不作兜底类；海洋、湾区、县域不与产业、人才并列；绿色、数字、安全则按具体语义判断，不能仅凭修饰词定类。

本表服务于“这一面怎样带出另一面”的道理库，不是给政策体系另做一套官方分类。名字、内容和拆分依据取自官方原文；把它们压成15个互不重复的主索引，是本次为写作检索作出的设计。官方文件在科技、民生、区域等章节中会交叉写同一事项，不能声称官方本来就给出了一棵互斥分类树。

## 先说清楚“一格一机制”

原任务的“每句只能归一面”与附录中的复合句冲突。经用户确认，本版采用：**复合句可拆；一条机制只设一个存放位置。** 这不是说现实中的事项只有一个方面，也不是每段只能涉及一个面。

| 要分清的东西 | 处理方式 |
|---|---|
| 题目、面、目标 | 是当次写作中的角色。2025县镇“产业”是共同起点，“人才”是该段变化的落点；2024一卷“人才”又是实现科技自立自强的起点。面没有固定只站在箭头左边或右边。 |
| 原句与机制 | “生态＋文化→宜居宜业宜游”是两个并列主张，分别记录。只有名词并列而没有不同过程或落点时，不机械拆句。 |
| 因果与定义 | “产业兴旺是产业振兴应有之义”可以归到产业，却没有解释产业如何带来另一个结果，不据此填一条因果道理。 |
| 主因、经过、终点 | “产业→岗位与收益→人才回流”的主格是产业→教育与人才，岗位收益保留为中间机制。不能因句中经过了收入，就把同一条原样复制进三格。若另写“产业→居民收入”，应确有独立的论证任务。 |
| 大面与小块 | 大面用于筛选，小块用于区分。生态保护与绿色转型是同一大面的不同小块；可以互相配对，不能把大面对角线一删了之。 |
| 分类与正误 | 一段能归类，不等于它论证正确。标题说富民、证据却只有村集体营收，仍须补“怎样分到居民”的一步；不能借分类替作者补上。 |
| 缺信息与新面 | “新局面”“潜力股”本身不是面。先读正文；仍无明确内容，就标信息不足。不能为含混标题新建一面。 |

## 落格程序

1. 先写明本段究竟证明什么：A经过什么变化，带来B的什么变化。缺失的环节标缺失，不替原文发明。
2. 区分主体、空间和方式。企业、政府、村党组织是“谁在做”；县域、湾区是“在哪里”；数字化、改革通常是“怎样做”。这些信息保留为标签，不直接代替功能面。
3. 按**直接讨论的功能**分类：是研发能力、人的能力、居民收入、经营规则、生态质量，还是其他？专门领域的制度改革、监管、法治、设施，先看具体功能，再看通用做法。
4. 只有当党组织自身的政治功能和组织能力、企业作为经营主体的成长活力等成为论证对象时，才进入相应小块；不能看到主体名称就定面。
5. 原句有两条独立主张，拆成a、b；前后是同一条因果链，保留中间环节。出现“产业科技融合”等关系表达时，写清两端，不新建“融合”一面。
6. 用正文消除标题歧义，同时记录段内混入或没有证明的部分。全文仍不足以判断时保留“待定”，不按年份主题猜答案。

**公共服务的专门与综合边界：**教育育人、教育公平归F03，公共文化及文明建设归F10；其他具体民生服务归F12。若论证的是跨教育、医疗、养老等项目共同适用的均等化供给机制，且没有分别展开各项专业功能，归F12的综合均等化小块。跨项目的统筹机制与某项服务的具体机制不是同一条，不能原样双存。

**设施也要区分专业功能：**讨论交通、能源、水利、通信等公共网络的承载和连通，归F05；实验室、中试平台讨论研发验证能力，归F02；学校讨论育人或教育可及性，归F03；文化馆讨论公共文化参与，归F10；医院讨论诊疗服务，归F12。建筑物的存在不能把这些内容都吸入“基础设施”。

## 配对规模与记录方式

15个大面形成225个有向主格，其中210个异面格、15个同面格。原12面若保留对角线为144格，增加81格；只算异面格则由132增至210，增加78格。再加一个大面会新增31个含对角线的格子，不宜把每个标签都升格。

225是索引容量，不是下一阶段必须写满的作业量。先从真题出现、材料能证明的关系建条目；某对面没有可靠机制就留空。小块按需展开，不把全部小块再做一张必须填满的平方表。反向箭头必须重新论证，不能把“产业吸引人才”倒过来就当作“人才促进产业”的证据。

每条建议保留：`机制ID｜起点大面/小块｜终点大面/小块｜中间过程｜场景｜行动主体｜方式/属性｜依据｜关系类型`。题目层面的高质量发展、乡村全面振兴等综合目标另记为目标，不为它们增设无所不包的配对行列；须写清通过哪个具体结果支撑该目标。

“能撑200—300字”是写作检验，不是分类公理。一个小块有明确问题、作用过程、材料与落点，也能写一段；缺证据的宽泛大面照样写不成。2024一卷的基础研究、核心技术就是小块成段，不必因此把它们都升成与产业、文化同级的大面。
