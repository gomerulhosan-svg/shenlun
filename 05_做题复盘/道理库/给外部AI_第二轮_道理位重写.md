# 第二轮：把道理位重写得出彩

（给 astra。上一轮的结构改对了，这一轮只动道理位那一栏，作用链和核对两栏不动。）

## 上一轮的道理位哪里不行

结构改对了：关系面和任务面分开了，箭头方向清楚了，作用链挪进"例子要证"也对。问题在道理位：

1. **空。** 很多句子是"X 是 Y 的内在要求""X 是 Y 的宝贵财富""X 是 Y 的基本保障"。形式是判断句，可换到别的面也照样成立，说了等于没说。这是最大的毛病。
2. **原话被改弱了。** 比如"良好的生态环境，是广东永续发展的最大本钱"被改成"良好生态是永续发展的自然本钱"。总书记的原话也被改了："绿色发展是高质量发展的底色"写成了"绿色是高质量发展的鲜明底色"。原话要么一字不改照引，要么换成自己的句子，别改半截。
3. **绿色漏了面。** 2026 县镇卷按"生态美、产业强、文化兴、百姓富"拆，题干的落点是"长远发展和民生福祉"两条线。文化和百姓富要放回关系面，两条线也要补上。这一条是我们上一轮给你的话只写了省市卷的四面，不怪你。

道理句不必出自权威，也不必句句是"是"字句。但要出彩：读着像出题人会写进材料、阅卷人一眼认得的那种话。

## 出彩的道理句长什么样

出彩的句子都有两样东西：一个想透了的道理，加一个固定的句式。

**道理，常见的就几类：**

- **化解一个顾虑。** 大家担心搞绿色拖累增长，就写"含绿量越高，含金量越足"，后面再接"绿色低碳投入并非成本负担，而是竞争力的源泉"。
- **换一个范畴。** 把生态从"代价"挪成"资产"："良好的生态环境，是永续发展的最大本钱"。把生态挪进民生："良好生态环境是最公平的公共产品，是最普惠的民生福祉"。
- **部分带动整体。** "县域强，则全省强。"
- **一个原因带出几个结果。** "人气因产业而聚，人才因产业而兴。"
- **分工互补。** "发展出题目，改革做文章。"
- **不可替代。** "生态环境没有替代品，用之不觉，失之难存。"
- **眼前和长远。** 不仅管现在，更管未来。

**句式，常用的就这些：**

| 句式 | 例句 |
|---|---|
| 越……越…… | 含"绿"量越高，含"金"量越足 |
| A 则 B，顶真 | 县域强，则全省强；强国必先强农，农强方能国强 |
| X 因 A 而……，Y 因 A 而…… | 人气因产业而聚，人才因产业而兴 |
| 并非……而是…… | 绿色低碳投入并非成本负担，而是竞争力的源泉 |
| 不仅……更是…… | 绿色低碳不仅体现在赛场，更是城市发展的未来 |
| A 就是 B | 增绿就是增优势 |
| A 是 B 的〔借来的名词〕 | 本钱、筋骨、底色、压舱石、引擎、试金石 |
| 回环 | 以制造业之强牵引服务业之优，以服务业之优增进制造业之强 |
| 打比方 | 制造业与服务业如同树木的主干与枝叶，根深干壮才能枝繁叶茂 |
| 没有……就没有 / 只有……才能 | 没有产业的农村，难聚人气，更谈不上留住人才 |

## 怎么写出来：两条路

**第一条，读出题人读的东西。** 出彩的句子多半不是命题人凭空写的：

- "含绿量越高，含金量越足"是省级报道的常用说法；
- 2025 省市卷的"向高攀登、向实聚焦"是报道的小标题，命题人重组过；
- "筋骨""主干与枝叶""以……之强牵引……之优"出自省委书记在全省高质量发展大会上的讲话。

所以每一面先去这几处扫：

1. 当年各场全省大会上省委书记、省长的讲话：高质量发展大会、百千万推进会、服务业大会、先进制造业大会、城市工作会议、海洋会议。仓库 `04_文件原文/` 里有一部分（L03—L08、M01—M16、N 开头的几份）。
2. 南方日报、南方+ 的评论员文章，深调研报道的标题和小标题。
3. 新华社、人民日报的评论员文章。
4. 总书记讲话里的生动说法。
5. 往年真题材料里命题人自己写的句子，在 `06_选材因子/上意/` 每张表的第三节。这一轮可以看真题，标上卷别和材料几。

**第二条，扫不到就按配方写。** 先问这一面最常被质疑的是什么，或者它真正的价值在哪；再套一个上面的句式；最后过四条检验：

- **换到别的面还成立吗？** 成立就太空，重写。
- **离开具体例子还成立吗？** 不成立就太窄，往上提一层。
- **有没有那个味？** 官方名词、对仗、四字格，不用口语，不造怪比喻。
- **有没有说过头？** "最""唯一""根本"要有原文先例才用；固定提法只给指定的主语。
