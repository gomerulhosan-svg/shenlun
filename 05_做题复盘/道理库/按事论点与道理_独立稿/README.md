## 三个位置，各做一件事

| 位置 | 要回答什么 | 绿色发展→民生的示范 |
|---|---|---|
| 论点句 | 本段主张A对这一领域有什么作用，如何扣住题干 | 绿色发展改善生活环境，让生态成果成为民生福祉。 |
| 道理句：定性 | 这一面是什么、处在什么地位、为什么值得重视 | 〔原文〕良好生态环境是最公平的公共产品，是最普惠的民生福祉。 |
| 例子要证：作用链 | 例子经过哪几个环节，能够支持论点 | 空气水质改善→环境健康风险减少；公共绿地可达可用→群众获得休憩空间。 |
| 例子要证：核对 | 材料究竟证明到哪一步 | 谁实际受益、受益在哪里；不能只用绿化面积代替群众获得。 |

## 先辨题型，再选面

| 题型 | 分段依据 | 绿色题示范 |
|---|---|---|
| 关系型：A有什么作用、如何支撑B | A保持不变，面取A所作用的不同领域 | 省市入口：产业、生态、民生、生活方式；县镇入口：生态美、产业强、文化兴、百姓富。 |
| 怎么做型：如何推进A | 面取实现A的不同工作任务或条件 | 修复生态、治理污染、推动生产转型、倡导绿色生活等。 |
| 指定两者关系：A与C相互促进或统筹 | 按题干方向分别证明，必要时写回向作用 | 生态→民生与民生参与→生态，是否都写由题干和材料决定。 |

**不能把“人才支撑产业”拿去回答“产业怎样带动人才”，也不能把“居民节约促进绿色发展”直接拿去回答“绿色发展怎样改变生活方式”。** 同一个词出现，不代表同一条关系。

任务表中的举措可以进入关系段内部，解释A怎样产生某种作用；它不因此自动成为关系题的另一个并列面。隐藏面、周边面也标明方向：A的外溢作用可按材料升格；支撑A的条件优先用于任务题或例证桥。

00是总纲定位，不虚构一个统一A来凑四段。05科技与新质生产力、06人工智能与数字广东、07内需与投资于人、15安全与法治等相邻主题，均须先取准题干实际给出的A。

## 定性句怎么用

道理句用身份、地位、价值、重要性判断或对句。它可以先判断本段作用领域的价值，不必机械重复总〔B〕；论点和例证桥再把它接回题干。例如县镇卷“良好的生态环境，是广东永续发展的最大本钱”保留题中表述；保护修复怎样维护持续供给能力仍放例证桥。

来源逐句标明：〔原文〕用于原文件或讲话，〔报道〕用于媒体报道、评论中的句子，〔真题〕用于试卷原材料，〔自拟〕用于本稿创作。前三类都保留引用文字，不改半截。自拟可以用官方概念和判断句式，不能冠以领导讲话名义。真实原话也要保留原有主语与范围，不能随便把“根本保证”“第一动力”等套给别的对象。

这些是候选句和候选面。上场先看题干和材料，不把全表背成一篇固定作文。题干〔B〕改变时，必要时连同论点谓语、定性落点一起调整。

## 使用顺序

1. 圈定题干的A、B和方向，进入相应专题的关系表或任务表。
2. 按材料选出作用领域，为每段确定论点和定性句。
3. 用“作用链＋核对”找例子、析例子，补齐从材料到论点的桥。
4. 检查几段是否重复同一作用，是否混入反向条件，是否都扣回题干。
