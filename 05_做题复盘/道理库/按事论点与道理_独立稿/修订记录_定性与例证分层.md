# 修订记录：定性、作用链与拆面方向

修订日期：2026-11-03。对应用户纠正：原道理句保留为例证桥，道理位另写定性；关系型题按A对领域的作用拆面，工作任务拆法用于怎么做题。

## 三个位置重新分工

首版多数道理句解释“怎样起作用”，有论证价值，但没有完成“这一面对B是什么、重要在哪里”的定性。本轮保留其内容，改变其位置，并逐格另写定性句。

| 位置 | 现在承担的功能 | 绿色发展→民生示例 |
|---|---|---|
| 论点句 | 提出本段主张，扣住A与该领域的联系 | 绿色发展改善生活环境，让生态成果成为民生福祉。 |
| 道理句 | 判断价值、地位与重要性 | 〔原文〕良好生态环境是最公平的公共产品，是最普惠的民生福祉。 |
| 例子要证·作用链 | 把材料事实连接到论点 | 空气水质改善，降低居民环境健康风险。公共绿地提供日常休憩空间。 |
| 例子要证·核对 | 检查例子实际证明到哪一步 | 空气水质、公共绿地、健康环境怎样惠及群众。 |

示例中定性原文见[12的S12-04](12_绿色发展.md#source-12-5)；作用链逐字保留首版12“生态与民生转化”行。其余示例句为自拟。

定性句允许用对句，不要求句句“是”；但不能只把作用链缩短后放回道理位。定性也不必机械重复总B，可以先点明本段领域的价值，再由论点与例证桥扣回总B。

## 关系面与任务面分开

| 情形 | 本轮处理 |
|---|---|
| 关系型题 | 先固定题干A，分别判断它对哪些领域产生作用。12绿色主表按产业、生态、民生、生活方式拆。 |
| 怎么做型题 | 原主面保留为“任务面备用”，如森林修复、污染防治、绿色生产、绿色生活。 |
| 隐藏面、周边面 | 逐项或逐组注明是A的外溢作用，还是支撑A的条件。支撑条件不能冒充外溢成效。 |
| 两者统筹、相互促进 | 单列配对关系，不把正向、反向与共同条件混成同一道单向关系题。 |
| 总纲及相邻主题 | 00作上位定位；05、06、07等先选实际A；15的安全与法治分表，不把两个A交替使用。 |

**判断方向的例子：**“产业振兴带动人才发展”应证明产业机会怎样吸引人才、提供成长空间；“人才支撑产业振兴”则证明人才怎样解决产业问题。两者都可成立，但不能只换主语而沿用同一个例子。[09](09_乡村全面振兴.md)专设产业振兴对人才、文化、生态、组织的限定入口。

关系表是候选领域，不是固定四段模板。跨领域的环境、落实效能可能和经济、治理段共用机制，16已将其另列备选，避免重复。18的人口与公共服务适配移到协调关系；17的教育作用与教育科技人才协同、20的健康状态与健康保障也分别注明适用边界。
