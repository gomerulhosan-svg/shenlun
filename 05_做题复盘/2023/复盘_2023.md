## 二、这两套卷子让我看清的"广东申论"特点

1. **答案几乎全部来自材料原词。** 参考答案里自造的只有 4～8 字的小标题（"发挥示范作用""提升响应速度"），后面跟的都是材料原话压缩。仓库里 `_归档/07_句子层/out/汇总.md` 也统计过：定稿大作文自造字只占约 10%。**申论不是写作文，是"找要点 → 归类 → 压缩"的信息处理。**
2. **小题的标准答案形态是固定的：** `序号 + 小标题（动宾短语，4～8字）+ 材料具体做法`，4～6 条，每条互不交叉。参考答案说明里反复强调"各条要点相互并列，没有交叉"。
3. **分条的依据通常是材料自己给的：** 按主体（企业家/技能人才/高端人才……；百岭村/塘头村/羊角村）或按做法类型。材料怎么组织，答案就优先怎么组织。
4. **题型分布（2023）**
   - 县级卷：概括(20) + 分析(30) + 策论文(50)，三道题。
   - 乡镇卷：概括(15) + 概括(15) + 对策/经验(20) + 启示(20) + 公文提纲(30)，五道小题，**没有大作文**。
5. **策论文 ≈ 把材料里的对策重新组织。** 分论点就是"XX 方面要 XX"，段内是材料里的具体做法和数据，最后一句升一下意义。开头只需"背景 + 问题（材料二的专家点评） + 总论点"，结尾一两句收束即可。
6. **"分析""启示"这些看起来要思考的题，在广东卷里也主要按要点给分**，要点仍然在材料里。

## 三、诚实说明：我做题和你做题的差别

- 我没有时间压力，能一字不差地回看材料；你在考场上 150 分钟要读近万字、写近 2000 字。**我"命中率高"不代表这是你最难的地方——你最难的大概率是时间和手写速度。**
- 所以下面的方向会把"限时"放在很前面。

## 四、方向 v1（做完 2023 后）

**核心判断：先把小题练成"流水线"，大作文先学"搬材料搭框架"。**

1. **练"要点提取"，不练"文采"。** 每做一题，先在材料上标出：主体 / 做法（动词）/ 效果 / 问题 / 总结金句。答案只从标出来的东西里写。
2. **固定小题格式**：`1.小标题。具体做法（材料压缩）。` 小标题用"动词+名词"4～8 字；每题 4～6 条。
3. **分条先看材料怎么分**：材料按人/村/部门写的，就按人/村/部门分；材料是一堆做法混在一起的，再按"政府/企业/社会"或"硬件/软件/机制"自己归类。
4. **材料里的总结句优先抄**（如"农文旅一体化，游养买一条龙""没有好土壤，就长不出好庄稼"），放在开头或结尾。
5. **启示/对策题要写成能做的动作**，别只写"提高认识""加强重视"。
6. **大作文（县级以上卷）先按"策论文"练**：开头（背景+问题+总论点）→ 3～5 个对策分论点（每段：对策句 + 材料做法/数据 + 意义）→ 结尾。
7. **下一步验证**：看 2024 年（一卷、二卷、行政执法卷）题型是否一致，特别是大作文是议论文还是策论文。
