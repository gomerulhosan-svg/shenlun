    读题

    读的时候划什么

    一句读完问两件事：读完多了什么，好不好看。句式（是什么、做了什么、做成了什么、要什么）只帮你想它去哪。

    记号什么时候划先往哪放
    { }面多了一个道理；宽的「做了什么」（没有数字、地名、个案）也算论点、道理
    /面多了一件具体的事：带数、带地名、带项目例子
    ★加在 { } 或 / 上：又好看又有料。/★ 只标数字亮眼的事显眼的地方：标题、论点、开头、结尾；能架几面就当架子
    ( )面没多什么，但好听，说的是一面段尾回扣
    ( )尾没多什么，但好听，说的是整个广东或更大标题、开头、结尾
    ③广东干得好的、干得不好的、成效、要答的题开头·对广东而言
    ①④总书记原话；材料给的一串做法开头·引语；开头·做什么
    不划没多什么，也不好听；或者太碎—
    • 好看认长相：对仗或同一句式重复、比喻、并非……而是……、不仅……更……、诗句俗语、画面。
    • 按分句判：长句的尾巴上常挂着好用的半句。好听但只说一个个案的，不另划，跟着例子走。
    • 拼的时候找句子：看到就用，记得就用；找不到看附近；附近也没有，翻开头（材料一、二）。
    2

    划句子

    一句读完问自己：脑子里多了什么？多了一件具体的事，划 /；多了一个道理，或者一句宽的「做了什么」，划 { }；什么都没多但好听，打括号；又好看又有料的，再加个 ★；广东的事打序号。什么都没多也不好听，不划。

    或者点任意一句，看它为什么这么划。

    判定卡

    点左边任意一句，这里写出：读完多了什么、好不好看、记号、为什么这么划，以及后来用在成稿哪里。

    • 多了一件具体的事/
    • 多了一个道理{ }
    • 没多什么，但好听( )
    • 没多什么，也不好听不划
    3

    找格子 · 摆料

    划完先找格子：材料里一定给了，要么一句话列全，要么一块材料一格。拿例子去嵌，每组例子都有地方放、不用硬塞的那套就是。再扫一眼有没有能架几面的句式，有就用，没有就算。

    誊稿纸

    誊到方格稿纸上。一格一字，标点占一格，两个数字或字母挤一格，标点不落在行首。点任意一句，看它从哪来。

    点稿纸上任意一句，这里显示它在文章里干什么、用了哪几块料、怎么改的。
