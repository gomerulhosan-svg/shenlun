# 大事图（样例）：产业体系

> 小题要看清的是一件小事由哪几块组成；大作文要看清的是一件大事里，几个中事各站在什么位置、谁撑着谁。这张图就是给大作文用的。
> 中事取自 `18_训练/中事/_草稿/A_产业和新基建.md`，绿色那一块取自生态。引号里的词都是原文里的说法，已在 `17_原文净本/` 里核过。

## 二、每个中事站在哪，身份词是什么

身份词是这个中事往上挂到"产业体系"时的身份。写作文时，分论点里那个"是……"就填它。

| 位置（身份词） | 中事 | 一句话 | 手上的小事 |
|---|---|---|---|
| **根基**："实体经济为本、制造业当家的根基" | 老行当换活法 | 老行当不砍，从靠便宜换成靠好 | F 市陶瓷厂从 400 多家减到 60 家，产值反而涨了三成多 |
| **增量**：新动能，"老树发新芽" | 新东西从老根上长出来 | 机器人、无人机、新能源车，都是从做手机、做家电的老底子上长出来的 | 无人机、新能源车产业集群 |
| **源头**："创新是第一动力" | 题目从车间里来 / 样品到产品中间那截 / 头一单 | 科技要先问厂子要什么，中间那截要有人接，新东西要有第一个敢用的人 | L 县柚子厂想牵头"揭榜挂帅"却没资格；G 市成果转化卡住了 |
| **主体**："强化企业科技创新主体地位" | 小厂单干不起的事，凑起来干 | 干的是企业，大厂带小厂，小厂抱团 | 佛山几十家陶瓷企业联合起来定行业标准 |
| **附加值**："为实体经济注入源头活水" | 车间外面那几段 | 钱越来越多在车间外面挣：设计、检测、法律、品牌 | 潮州五金厂请律师堵住收款漏洞 |
| **空间** | 腾地方 / 带着链往外搬 | 地用完了，旧地要腾，大块生产往两翼和县里放 | 顺德村级工业园改造；C 县产业转移园 |
| **保障**："人才是第一资源"、"有效市场和有为政府相结合" | 人跟着机器升级 / 让做生意的人省心 | 机器换了，人也得换本事；规矩稳，老板才敢投 | 刘工和小郑；"亮码入企" |
| **底色**（挂在生态） | 让生产本身变绿 | 干的方式不能走老路 | H 电子绿色工厂 |

## 三、图里夹着的几对矛盾

好作文不是把这几块并排摆出来，而是写出它们之间在拉扯什么、怎么被统一起来。

- **老和新**：老产业养活的人多，砍了不行；新产业要长，可地、钱、人都有限。统一的办法是新芽从老根上发出来，所以不砍老树，让它换活法。
- **实和虚**：服务越来越值钱，可"中国式现代化不能走脱实向虚的路子"。统一的办法是让服务长进车间，替制造挣钱，不是离开制造。
- **政府和市场**：新东西没人敢用，政府要当头一单的买家；可选哪个赢，最终得市场说了算。统一的说法是"有效市场和有为政府相结合"。
- **集中和外放**：珠三角要腾地、要升级，两翼和县里要接产业、要发展。统一的办法是研发和总部留在中心，大块生产往外放，带着链一起走。

## 四、往上挂的那根线

产业体系往上挂到哪里，作文的开头和结尾就从哪里起笔：

- 往广东挂：是"立省之本、强省之基"，现代化产业体系是那个"载体"。
- 往全国挂：是中国式现代化的"物质技术基础"；工业、农业、服务业和基础设施是现代化产业体系的"四梁八柱"。

## 六、拿到一个新题干怎么用这张图

1. **找落点**：题干里的关键词落在图的哪一块，是一个点（"科技自立自强"）、一条线（"创新"），还是一整片（"做优做强制造业"）。
2. **判断方向**：任务型写怎么做，往下拉；关系型写起什么作用，往上挂。比如"绿色是高质量发展的底色"，就是问绿色在图里站什么位置。
3. **拉线成分论点**：沿着落点拉出三四条线，每条线是一个分论点。每个分论点配一个身份词和一件小事。
4. **首尾挂上去**：开头和结尾用第四部分那根线。
