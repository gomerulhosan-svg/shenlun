# 预注册：申论高分因子假设（在编码和统计之前写定）

> 写于数据编码之前。目的：先把"要检验什么、预期方向是什么、怎么算"定下来，避免看了数据再挑好看的结果讲故事。
> 后面的分析报告会逐条回到这里，标明"支持 / 不支持 / 无法检验"。

## 数据

- 样本：`21-26广东申论高分答案合集.pdf` 中 68 份带总分的真人卷（考后回忆 / 誊写版），分数 77—93.5。
- 分组：按"同一套卷子"分为 16 个考试单元（如 2026 一卷、2026 二卷……）。不同卷子的分数不可直接比较（阅卷尺度、题目难度不同）。
- 结果变量：**总分**（没有分题得分）。

## 分析口径（定死）

1. **组内比较**：每个因子都先在同一套卷子内部去均值或转秩，再合并各组，计算组内 Spearman 相关（等价于"同一套卷子里，这个因子高的人分数是不是也高"）。
2. **显著性**：组内置换检验（只在同一套卷子内部打乱分数），重复 10000 次；多个因子一起检验时，用 Benjamini-Hochberg 控制错误发现率（FDR 10%）。
3. **效应量**：报告组内 Spearman ρ 和 bootstrap 95% 置信区间。
4. **缺失**：因子缺失（该题没录）就不进入这个因子的计算，不补值。
5. **阅卷噪声**：真人卷分析认为同一水平的卷子分数浮动约 ±2 分。组内分差小于 2 分的比较不作单独解读。

## 假设（方向为预期符号）

| 编号 | 因子 | 预期 | 依据 |
|---|---|---|---|
| H1 | 第一题一级条数 | + 弱 | "多写一两条不吃亏" |
| H2 | 第二题问题条数、对策条数 | + | "条数压缩一定吃亏" |
| H3 | 第二题对策中"工具级"比例 | + | 2026 县镇 87—90 分卷对策都到工具级 |
| H4 | 第二题问题中"写出具体表现"的比例 | + | "缺乏人才"四字条 vs "缺运营管理和复合型人才" |
| H5 | 第二题自补对策数、误读数 | − | 自补、张冠李戴扣分 |
| H6 | 作文观点句中显性出现题干落点词的比例 | + | 落点显性 |
| H7 | 作文用到的材料块比例 | + | 材料没用完的 78.5 |
| H8 | 作文用材料外例子替代材料的次数 | − | 81.5、82 分卷 |
| H9 | 作文分论点个数 | 0（无关） | 两段、三段、四段都到过 87—90 |
| H10 | 第一、二题对参考答案要点的覆盖率 | + 弱 | 照搬机构答案只到 80—83.5 |
| H11 | 答案与材料的字面重合度（自动计算） | + | "答案来自材料原词" |
| H12 | 泛化动词占比（加强、完善、推动、提升……不带具体对象） | − | 对策要具体 |
| H13 | 作文超长（仅限全文） | − | 超长扣分 |
| H14 | 卷别效应：县镇 / 乡镇卷的组均分高于省市 / 县级卷 | 描述性 | 90+ 集中在二卷 |
| H15 | AI 盲评分数与真实分数的组内相关 | 探索，无预期 | 检验 AI 能否当你的练习反馈 |

## 已知的局限（事先承认）

- **选择偏差**：合集只收 77 分以上的卷子，研究的是"80 分怎么变成 90 分"，不是"60 分怎么变成 80 分"。
- **回忆偏差**：卷子是考后回忆的，不是答题卡原件；字数、措辞会失真，有的作文只剩提纲。
- **样本小**：可用于组内比较的每套卷子多为 5—11 份，统计功效低，"不显著"不等于"没作用"。
- **只有总分**：无法把分数拆到每道题上。
- **因果**：这是观察数据，相关不等于因果；"能力强的人同时做对很多事"是最大的混杂因素。
